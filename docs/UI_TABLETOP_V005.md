## 历史权限与恢复

纯 C# 核心在成功指令后记录变化，拒绝、预览和相同指令重试均不会追加历史。历史数据不含完整手牌、牌库顺序、未揭示地图或随机状态。公开产出、费用和交易使用具体资源图标；购买发展卡、偷取、弃牌及部分进步卡的种类按观看者权限投影，无权查看者只见允许公开的数量。

窗口按玩家筛选的是当前人类席位已经获准看到的记录，不会切换为该玩家的私有视图。多步选择的知情者来自权威待决，不能通过伪造指令中未使用的目标字段让第三人读取私密转移。破坏卡的弃牌明细仅弃牌者可见；行会征费、婚礼、商业港口和间谍的私密转移按实际双方授权。

权威存档原本包含已确认命令，加载时通过确定性回放重建相同历史，因此不更改规则版本、场景版本或存档格式。四种规则的旧格式保存／恢复与后续执行均有独立历史测试。显示缓存随新的对局绑定重置，并按已确认事件数更新；AI 的 PlayerView 不因显示历史而取得其他玩家权限。

## 美术来源与复现

桌面位图由 [生成脚本](../tools/art/generate_tabletop_finish_v005.py)使用固定种子的多尺度噪声计算，不依赖外部照片或图像模型。来源、文件 SHA-256 和工具版本在 [清单](../art/source/ui-tabletop-v005/manifest.json)，材质密度、法线强度、导入、灯光和倒角参数在 [v005 配方](../art/recipes/ui-tabletop-v005/recipe.json)。

显示网格沿用已有板块尺寸、底面中心轴心点和照片 UV，每块使用 48 个三角形形成厚度和倒角；原 FBX 和来源照片不被改写。原 v004 的 8K 木纹仍保留，但不是 v005 当前运行桌面的材质。新 2K 色彩／法线图表达表面颜色和微表面，不应登记成新的三维地形模型。

```powershell
python tools/art/generate_tabletop_finish_v005.py --output art/source/ui-tabletop-v005 --size 2048
```

该命令需使用配方所需的 Python 与 NumPy 环境。生成图复制到 `Unity/Catan/Assets/Resources/TabletopUI/v005`，由 `TabletopFinishTextureImporterV005` 固定导入参数；`M6Build` 配置独立 v005 渲染管线。
