# 手牌、弃牌与 AI 动画 v012

日期：2026-10-16（Asia/Shanghai）。游戏名为《卡坦岛之三国争霸》，沿用内测版1.4。本轮用户要求微信文字公告，没有要求发布可玩压缩包，因此不自动增加发行版本号。

## 本轮行为

1. 资源页签与玩家列表采用实体资源牌背，显示当前数量／保护线，超线红色。资源和商品合并计数；城市与骑士／组合的保护线随城墙变为 `7 + 2 × 城墙数`。
2. 发展页签及玩家列表采用贸易、政治、科学三色牌背扇形，显示数量／限额。进步卡限额4张，基础版／航海家的发展卡没有数量上限，显示 `∞`。公开胜利点进步卡不计入可持有的进步手牌。
3. 收取发展／进步卡增加飞牌与逐张插入。骰点产出的资源／商品从实际对应地块起飞；交易等非地块来源仍从银行收取。观察对手时，飞牌全程只画牌背。
4. 移除“拖拽地图 · 滚轮缩放”说明及最底部的本人席位／得分；分数构成仍可在玩家列表查看。
5. 玩家列表改用奖杯、实体商品图案和牌背图标；悬停显示说明。沿用已有照片资产，新增奖杯为程序绘制图标，未生成或冒用3D模型。
6. 单人开局提供慢速、标准、快速三档 AI 操作速度，随本地存档保存，旧存档默认标准。AI 建造使用已确认的公开棋子网格，从头像飞到对应点／边，落地前隐藏目标模型，本回合建造保持脉动发光，换席清除。联机播放公开棋子变化；联机 AI 的调度间隔仍由服务器控制。
7. 掷7弃资源／商品、强制进步弃牌及破坏等本人交牌选择，直接点击手牌，再点右下角。未选够时按钮为“选择弃牌”，恰好选够时为“确认”，并显示已选／应选。主动回合进步卡超过4张时，允许先使用卡牌；点结束回合后进入同一弃牌流程，减到4张后可结束回合。行会征费选择的是获准查看的对手手牌，仍在原有专用面板中完成。

## 规则与边界

本轮修改展示与指令适配，不改变规则裁决、AI策略或权威存档格式。速度是本地展示设置，写入客户端存档信封；权威规则存档原有的规则版本、场景版本、随机状态与待决选择保持。

资源牌的“上限”是掷7的弃牌保护线，不阻止继续获得资源。依据本地固定版 `catan-base-2025-en.pdf` 第6页（掷7与弃牌）、`catan-cities-knights-2025-en.pdf` 第6–8页（资源／商品及城墙）与第10页（进步卡）。来源目录：[本地规则索引](../assets/references/rules/README.md)。基础发展卡规则见 `catan-base-2025-en.pdf` 第9页，不新增不存在的7张发展卡限额。

卡牌动画只使用所属玩家的 PlayerView、已授权历史和公开棋盘，未读取其他玩家隐藏手牌、牌库顺序、未揭示地形或随机状态。首次绑定、换局、读档只接收基线，不重播旧收牌／建造。同批联机同步若合并多次“发明”，既有公开历史未记录每次的两个交换目标，中间产出暂从银行飞入，下一份公开快照恢复正确地块；不推测未知的中间棋盘。
