# 局域网连接流程与搜索修复

日期：2026-10-18。适用版本：内测版1.6的本次修复构建，未发布新的公开发行版。

## 为什么需要房间服务

房间服务是这桌游戏的统一裁决者，负责创建和保存房间、验证加入密码与玩家身份、裁决指令、同步各玩家可见的局面、调度 AI，以及保存断线恢复材料。房主自己的客户端也通过这个入口操作，其他客户端不能自行决定掷骰、扣资源或修改对局。

局域网不需要互联网服务器：Windows 游戏目录内的 `Server/Catan.Server.exe` 可以在房主电脑上承担这些工作。Android 当前作为加入端，连接 Windows 上的服务。

“服务已启动”“发现服务”“连接服务”“加入房间”是不同步骤。服务已启动并不表示已创建房间，也不表示玩家加入了任何房间。搜索使用 UDP，无须先建立连接，更无须在自己电脑创建一桌。选择房间后，客户端自动连接该房间所在的服务并申请加入，玩家不再手动执行连接服务。

每台 Windows 进入局域网页面时会自动准备本机托管服务，方便随后创建房间；所有平台同时自动搜索好友房间。这两个工作独立执行，本机服务启动失败或较慢也不阻止加入其他电脑的房间。自动准备本机服务不会把玩家切换到本机服务，也不会自动合并不同主机的大厅。

## 玩家操作与网络步骤

| 游戏层面的步骤 | 网络层面实际发生的事情 |
| --- | --- |
| 进入局域网 | Windows 自动准备随包服务；客户端同时发送 UDP 搜索。Android 只搜索和加入。 |
| 自动显示房间列表 | 向 UDP 47772 发送发现请求，接收主机地址、HTTPS 端口、协议版本和证书指纹；随后通过 TCP 47771 上的 HTTPS 读取房间列表。对活动局域网网卡增加定向广播，降低 VPN 默认路由对发现的影响。 |
| 选择房间 | 无密码房间直接申请加入；需要密码时弹出输入框。取消输入不会离开当前房间。进行中对局可用本设备的有效身份恢复；未开局大厅退出后席位已释放，再次加入需要重新输入密码。 |
| 加入并选择建筑颜色、准备 | 客户端自动连接目标服务，绑定搜索得到的证书并校验 TLS；服务验证密码、身份和席位，返回本设备的恢复凭据。密码通过加密连接传输，输入框和公开日志不展示明文。 |
| 房主开始对局 | 服务检查准备状态并创建权威规则状态，向每个玩家发送其权限范围内的视图。 |
| 掷骰、交易、建造 | 客户端提交带唯一编号的指令，服务校验、执行和同步。优先使用 WSS；运行环境不支持时使用同样严格校验证书的 HTTPS 每秒同步。 |
| 玩家掉线或重连 | 服务仍运行时由 AI 接手，原玩家用设备保存的房间身份重连，并在下一次自己的回合恢复操作。 |
| 托管服务退出 | 该服务上的房间无法继续联网；恢复托管服务后再连接。单个玩家的断线与托管服务整体退出需要分别判断。 |

服务端固定监听 TCP 47771 与 UDP 47772；搜索客户端使用系统分配的临时 UDP 端口接收回应。无需在每个客户端独占 UDP 47772。验收程序使用独立端口和目录，避免干扰玩家现有对局。

## 本次根因与修复

旧客户端在发送局域网广播的同时向 `127.0.0.1:47772` 探测。本机未监听该端口时，Windows 可能把 ICMP 拒绝转换为 UDP 接收异常 10054。旧代码直接终止搜索，统一显示“检查网络与防火墙”。先创建房间会启动本机监听，碰巧绕开这个错误，造成“必须先创建才能搜索”的现象。

现在将本机无人监听引起的 UDP 重置／拒绝视为可忽略探测结果，继续等待其他主机，搜索超时后关闭并观察未完成的接收任务。某个网卡发送失败或某台主机的 HTTPS 列表读取失败时，保留其他成功结果，并展示失败环节。不同服务的相同房间号分别识别；本机地址与局域网地址指向同一证书服务时能正确显示“已加入”。

已加入的房间仅显示“已加入”，不提供重复加入按钮。列表不再常驻密码输入框；密码弹窗使用独立临时字段，确认或取消后清空，避免混入创建房间密码。

## 异常说明

提示包含发生环节、错误码、已知原因与下一步建议。搜索成功但无人回应属于空结果，不直接认定防火墙异常。发现主机但无法读取列表时显示该主机地址；密码错误、协议不一致、证书失败、超时、连接拒绝、网络不可达、目录权限和服务端口占用分别提示。

启动服务时，服务端返回受控错误码，区分 TCP 端口占用、存档目录被其他进程使用、证书问题、目录权限和房间存档读取失败。UI 不直接回显异常原文，避免把请求、身份凭据、密码或私有路径带入公开说明。长提示可在状态区滚动查看。

## 验证边界

验证包括正式发现源码的真实 UDP／HTTPS 回归和独立 Unity 客户端菜单流程；结果、构建入口及待验事项统一记录在 [农场主手记](../The%20Farmer's%20Log.md)。本机与回环接口验证不代表已在朋友电脑、不同路由器或安卓真机复验；M7 阶段退出条件仍未全部满足，不修改路线阶段。
