# AI 逻辑 2.0 补丁（内测版 1.6.8）

本轮完善四套现有启发式策略，适用于本地 AI、房间 AI 及掉线接管。指令继续走相同规则验证入口，不更改建造、胜利或卡牌效果。

| 用户要求 | 本轮行为 |
| --- | --- |
| 多岛与沙漠 | 以真实相连陆块区分海岛与沙漠彼岸；穿越沙漠中提高新海岛收益，使可登陆多个岛时优先登陆，继续保留路径成本和实际产出评价。 |
| 临近胜利交易 | 使用公开分数与可见建设机会估算近期得分距离，包含连接分段夺最长路、骑士截路夺奖、最大军队、大都会、登岛及奇观四级；一步可赢则主动报价和回应全部禁交易，两步或三步分别提高交易收益门槛。自己也接近终局且可补齐建设目标时，仍可能向两三步的对手报价。 |
| 蓝卡及强盗 | 将一步／两步终局威胁纳入目标评分；自己的立即胜利优先，其后先执行能实际干扰临近胜利者的蓝卡及骑士截路动作。 |
| 六分领先 | 与第二名的分差达到六分时，禁止主动报价与接受交易；总分六分、或仅比末名高六分不触发该禁令。商业港口的自愿交换也遵守禁令，被强制要求交商品的待决仍按规则完成。 |
| 骑士卡位 | 在合法招募、移动、驱逐候选中评估道路／船的延伸口、登岛落点及最长路线被截断的效果；移走原卡位也扣除损失。 |
| 中间席位初设 | 四人局第一轮的实际第二、第三行动位适度偏向集中／肥沃砖木及砖港；更高的多资源产出仍可胜出，不按玩家颜色硬编码。 |
| 主教 | 主教对应内部 Taxation；比较解放己方产出、压制对手产出和每位可掠夺对象，不再把无收益沙漠作为固定落点。 |
| 海盗 | 同时评估已有船和对手下一两段可延伸的空船边，允许在船到达前封锁登岛；计入自己的航运损失，仍遵守首次蛮族攻击等原规则限制。 |
| 对手手牌 | AI 专用视图提供对手全部资源／商品、蓝黄绿进步卡数量与基础发展卡总数；报价只选择确实持有所需资源的对手，不透露具体隐藏卡。 |

## 信息权限

这是 2026-10-19 用户明确指定的 AI 信息优势，不再声称与人类完全同权限。四种会话使用 `GetAiPlayerView` 给 AI 投影，而人类界面、网络席位和公开日志继续使用原权限。`OpponentHands` 还被网络序列化器显式排除，客户端不能注入该字段。

这次专用手牌扩权不额外透露对手具体发展／进步卡；间谍等合法卡效临时揭示的具体卡仍遵守原规则。AI 不接收权威状态、牌库次序、未揭示地形或随机状态。普通视图仍支持原有隐藏信息非干扰测试；专用视图中的数组与资源袋为独立副本，修改视图不会修改权威局面。新权限不增加存档数据，载入后重新投影。

近期胜利距离是有限的、偏保守的局面评估，不是对所有牌序与多回合行动的穷举证明。一分之差会先拒绝资助，即使对方暂时缺材料；不会猜测其具体隐藏卡；已有足够出骑记录且仍持发展卡时，会保守防范下一张骑士取得最大军队。不会保证阻断所有赢法、固定回合结束或实测胜率提升。

实际自动验证、双端构建及未验事项统一记录于[农场主手记](../The%20Farmer%27s%20Log.md)。本轮不改变 ROADMAP 的阶段状态。
