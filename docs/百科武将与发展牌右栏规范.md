# 百科武将与发展牌右栏规范

适用于武将、基础发展卡和城市与骑士进步牌。沿用现有左右分栏和页底关联入口。左栏只展示武将立绘或带正式标题与描述的完整卡面。现有词条按此规范制作。每项技能与每张牌各绑定一张专属局面插画。图内呈现本例的人物、动作和结果，图注由 Unity 单独排版。

## 信息顺序

| 位置 | 武将 | 发展牌 |
|---|---|---|
| 顶部 | 姓名为主标题，势力与称号同行。技能名作为该技能内容的标题。 | 用这张牌的具体操作作标题，如「逐段放置」「选择资源」「结算得分」。牌名、牌组与完整效果已由卡面及导航表达。 |
| 上半部 | 按发动顺序写时机、可选动作、目标和结果。需要付出代价或受数量限制时，在对应动作旁写清。通常用一至三行。 | 只写完成操作需要的补充信息，如先后依赖、合法目标、资源来自何处或何时公开。通用牌组规则放关联入口。 |
| 下半部 | 用一个局面演示当前技能。画面表达谁发动、对谁生效、什么发生了变化。 | 用一个局面演示当前牌。选择类画可选对象与选中结果，建设类画合法落点，得分类画计分变化。 |
| 页底 | 放与当前技能直接相关的既有词条。 | 放与这张牌的目标、棋子或特殊时机直接相关的既有词条。 |

## 尺寸与排版

以现有 1672 × 941 逻辑画布为基准，在 1920 × 1080 实机验收。右栏保留当前纸面位置，内侧左右各留约 36 个逻辑像素。标题区约 80 像素，规则区按实际文字取高；可用高度优先留给示意。标题约 38–44，正文约 26–29，图注约 22–26。正文左对齐，图注跟随所指画面。短词条允许留白，空字段直接省去。

## 示意图与例外

- 一个示例回答一个问题。单一选择或即时效果用一幅图；有先后依赖时，用同一视角的两幅图，中间以箭头连接。图注指出具体变化，避免仅写「第一步」「第二步」。
- 左栏保留正式卡面与立绘。右栏示意使用独立彩墨人物、资源和场景插画。目标用轮廓或指向标明，新增或移除的棋子要能与原局面区分。箭头指向应符合实际操作或物品转移方向。隐藏手牌用牌背。
- 多技能武将在身份行下按游戏原顺序显示技能名。一次展开一个技能及其示例，默认首项；切换时正文和图同步更换。长文优先允许右栏滚动，保持字号。
- 简单被动或即时计分用单幅状态图或紧凑的前后数值。说明和图中数字必须能由当前游戏规则复核。素材制作记录可标待补，玩家界面不放占位图、制作状态或提示。
- 技能名、正式效果、牌组归属和例外取自对应游戏定义。基础「道路建设」与进步牌「兴建道路」按各自牌组核对。

## 两个样板

**张辽 · 突袭**：顶部为「张辽　魏 · 登锋陷阵」。技能名下先写「任意回合的摸牌阶段开始时」，再写可少摸的数量、从几名不同玩家处各取几张，以及少摸数受本次可摸数限制。下方用两名目标各一张牌背演示，牌从目标流向张辽；图注只说明本例的交换数量。

**道路建设**：右栏标题为「逐段放置」。正文写「放好第一段后，再按更新后的棋盘选择第二段的位置」。下方保持同一处聚落与地形，左图标出第一段合法落点，右图保留第一段并突出新增的第二段。页底关联「道路」「船」。

## 验收

在基准对局原尺寸检查四件事：能否快速找到时机或操作；能否从图中认出目标与结果；正文是否补充了卡面之外的信息；切换技能、进入关联词条再返回时能否回到原处。先验收代表性的选择、建设、取牌与计分类，再批量制图。
