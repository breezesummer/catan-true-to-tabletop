# 固定分区、逐张手牌与胜利分数 v008

2026-10-13 按八项反馈更新 M6。继续使用当前优化 AI，所有当前启动入口统一指向本版；不再维护原策略新版。历史程序、原始照片、既有验收记录和用户存档保留。本轮是 M6 可玩迭代，未推进 M7/M8 阶段状态。

## 本轮行为

1. 棋盘、银行、三侧备件、本人棋子、城市设施和骰子保持同一连续木桌，斜视／俯视同步切换观察角度。地图透明绘制在中央分区，缩放不侵入周边区域；地图外禁止拾取裁剪掉的节点，港口标签也裁剪在中央范围。没有独立背景面板。
2. 分数详情增加标题、正文、说明行高度并取消标签内边距，避免中文被切掉。本人暗分和对手明分继续来自原有权限投影。
3. 手牌取消左右摆动和上下周期摇晃。悬停平滑上移约 10 逻辑像素，选中额外上移 22；周边牌各向外展开约 24。悬停牌保持原叠放顺序，按具体牌序号选中，再点同张取消。静止光标使用进入时的命中锚区，防止牌底边抬起后交替命中下层牌。
4. 鼠标遮挡只阻止底层输入，不再让绘制进入全局禁用颜色，避免移动到棋子、设施或手牌时全屏文字和数字变灰。
5. 移除银行、棋子与设施上的额外悬停标题和说明段；建造费用以“名称：资源图标 × 数量”呈现，缺少数量标红。实际拿取仍由共同规则入口校验。
6. 历史下方增加固定的蛮族／防御状态框，包含帆船、七格航程、盾牌和双方力量，地图缩放不改变其位置与尺寸。
7. 开局增加胜利分数设置和恢复剧本默认。目标分数进入权威存档及 PlayerView，AI 按实际目标判断胜利。旧存档恢复原默认值；航海剧本的奇观、堡垒和布匹结算条件继续生效。
8. 骑士状态由已有头盔模型表示，取消旁边的黑色／金色球。数字改为地块中心的实体薄牌，参与三维深度，不再以屏幕文字覆盖建筑；沙漠不生成标牌，6／8 保留红色。

## 素材与复现

三张用户原图完整保存在 [参考清单](../assets/references/ui-v008/sources.json)，包括后续黄色背景／空白点数回归截图。正式卡面不重绘、不改变源像素；资源费用复用既有卡面图标。

点数的 512×512 数字贴图由 [排字脚本](../art/recipes/ui-tabletop-v008/generate-number-tokens.ps1) 生成，是程序排字位图；完整导入配置和专用导入器固定为 Texture2D，避免简化配置误导入 Cubemap。圆形牌芯和厚度由 `TabletopNumberTokens.cs` 生成真实网格。状态框的船／盾图标是运行时程序图形，不是三维模型。米制估算参数和来源记录见同目录配方；不声称实测实体尺寸。
