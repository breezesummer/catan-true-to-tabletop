# 中世纪写实二次元主页与分层菜单 v002

日期：2026-10-16。游戏名称：卡坦岛之三国争霸；版本沿用内测版1.4。本轮按用户要求发送微信文字通知；未要求发布可玩压缩包，因此不递增版本。

## 本轮变化

主页以中世纪海港为主题：石砌城堡、村镇、木帆船、远山、金色麦田与牧场，采用写实二次元环境插画与暖光。背景保持原图比例，使用缓慢运镜和光尘；文字、按钮和配置由 Unity 实时绘制。

左侧主菜单固定为：开始游戏、加载游戏、局域网联机、在线游戏、设置。首次进入只显示风景、标题和主菜单。主菜单使用轻量悬停反馈、选中标识及提示文字，子页面配合象牙白纸面、森林绿与旧金色。

- 开始游戏分为选择玩法、选择地图、同桌设置三个步骤；四规则、九个航海家剧本、两个组合剧本、人数、本人席位、AI 节奏和胜利目标沿用既有入口。
- 加载游戏独立显示最近存档与完整备份的规则、人数、本人席位和保存时间；无存档时显示空状态。预览只读取本地元数据，不公开权威存档内容。恢复前仍由既有入口完整验证。
- 局域网与在线游戏使用各自的服务地址。联机页面分为连接服务、加入房间、创建房间；创建房间再分房间信息、规则与地图、同桌设置。建立房间后，席位、房间设置、恢复连接分开显示。
- 在线入口于 2026-10-19 更新为公网 IP 的 HTTP/WS 大厅：房间列表、创建房间、当前房间和服务器地址分层显示；保存一次地址后自动连接。未配置或服务器不在线时在大厅中央提示并提供设置／重试，不显示虚构房间。
- 设置分为声音和桌面外观；三路音量、静音、桌面主题沿用原有持久化实现。
- Esc 逐级返回、关闭确认框或继续当前局。已有对局时重新开局提供保存后继续、直接继续与取消；加载当前存档时避免“先保存”覆盖待加载文件。

菜单动画只读取展示时钟；规则、当前 AI 策略、随机状态、指令权限与权威存档格式沿用。菜单中不调度本地 AI。新局集中清理旧菜单标志，防止从联机入口转回本地对局后遗留面板。
