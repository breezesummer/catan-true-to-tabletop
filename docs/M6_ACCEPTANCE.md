# M6 本地 AI 对手验收记录

2026-10-09（Asia/Shanghai），完成 M6 工程验收与窗口检查。路线图的四项退出条件均有以下实际证据；用户本人整局试玩与策略强度确认仍单独保留。

## 交付范围与退出条件

单人人类席位加 2–3 个本地 AI，支持基础版、航海家九剧本、城市与骑士，以及已经开放的“驶向新海岸”“穿越沙漠”组合。可选择 3/4 人与任一人类席位；其余席位自动行动。提供暂停、规则菜单、版本化保存与恢复。入口为 `tools/development/Play-M6.ps1`，场景为 `Unity/Catan/Assets/M6.unity`。

| 路线图退出条件 | 本次证据 |
| --- | --- |
| AI 只读 PlayerView | 独立 Catan.AI 程序集的四个 Decide 入口只接收对应 PlayerView；API/字段边界、隐藏信息非干扰和输入不变测试；集成代码独立复核 |
| 可合法完成对局 | 产品 AI 从正常开局完成四类规则包、13 种规则/剧本配置的 52 局，逐条通过共同 Execute 入口及状态不变量检查 |
| 不因等待选择死锁 | 交易接收者、弃牌、金矿和扩展待决按真正应决策席位调度；完整局、固定待决案例及独立 Windows 恢复验证 |
| 记录策略质量缺口 | [策略说明](M6_STRATEGY.md)登记短期规划、保守报价、进步卡/海盗/骑士策略和有限种子覆盖等限制 |

规则逻辑与存档版本沿用 M2–M5；没有修改 Core 源码，也没有新增美术资产。AI 与人类使用同一权威指令入口。AI 不持有游戏会话、权威存档、随机状态或越权预览接口；规则允许的卡牌窥看仍按席位权限投影。详见 [架构](M6_ARCHITECTURE.md)及[试玩说明](M6_PLAYTEST.md)。

## 真实窗口检查

通过 computer-use 技能操作实际 Windows 窗口和鼠标/键盘，没有用测试辅助方法代替以下步骤。默认窗口约 825×545，随后最大化为 2194×1234，本次实际操作以最大化窗口为准。

1. 基础版选择 3 人、人类 P2，启动后其余席位自动放置初始建筑和道路，到 P2 时等待输入。
2. 用右侧“拿起开局定居点”及棋盘绿色顶点完成 P2 定居点，计 1 分；随后通过道路按钮和绿色边完成 P2 道路，进入蛇形开局的下一次人类选择。
3. 暂停 AI 后保存；点击 P1 席位只显示公共提示，人类私有面板始终为 P2。
4. 读取存档后建筑、道路、人类席位、暂停设置与第二次开局定居点待决保留。
5. 最终构建检查组合菜单切换“穿越沙漠”、4 人和 P4 席位选项；从该菜单读取原基础版存档，恢复实际保存的基础版 3 人 P2 配置。修正沿用旧多人换座流程的提示，并在最终窗口确认。
