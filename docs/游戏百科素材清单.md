# 游戏百科素材清单

本轮覆盖[首页及四张详情页原型](../artifacts/游戏百科原型/)。首版截图取自四人「穿越沙漠」对局；后续制作按当前模式分类。表内数量指独立样式或画面，同一素材在不同页面出现时复用。现有文件已核对路径，裁切、清晰度和材质匹配度待实机打样。

## 一、五页共用的界面组件

| 组件 | 拆图与数量 | 制作、复用与状态 |
|---|---|---|
| 窗口与桌面 | 木质外框 1 套、绿桌呢 1 张、框外棋桌背景 1 层 | 木框四角固定、四边延展；桌呢平铺。优先用当前棋桌虚化作背景。 |
| 顶部横幅 | 杏色纸横幅 1 套、田园风景饰画 1 幅 | 两端固定，中部可延展。饰画独立，首页及详情共用；「游戏百科」实时排字。 |
| 导航 | 搜索框、路径栏、返回木钮各 1 款 | 首页用搜索框，详情替换为路径栏。放大镜、左箭头、右尖角各 1 枚。搜索框含聚焦态；按钮含常态、悬停、按下。 |
| 内容容器 | 金边大图框、纸面正文框、规则行底板各 1 款 | 各做无字底板，固定角部雕花，可九宫格伸展；规则行图标、标题、正文独立排版。 |
| 名牌与标注 | 标题名牌、地图标注牌、窄图注牌各 1 款 | 名牌随字宽伸展；地图引线和端点独立绘制。总标题、势力、卡类沿用实时文字。 |
| 入口按钮 | 首页大分类卡、玩法横条、页底关联词条各 1 款 | 图标与底板分离，右尖角复用。互动反馈共用材质变化，按下时保留字形清晰。 |
| 正文细件 | 细分隔线、菱形项目符、步骤箭头各 1 款 | 程序绘制或透明图标；文字用游戏现有中文字体。步骤箭头与导航尖角用途分开。 |

## 四、打样和扩充顺序

1. 先做无字外框、横幅、纸面框、返回钮和一行玩法入口。在 1920×1080 基准画面与[菜单设计与实现模板](菜单设计与实现模板.md)对照，核对端头、文字留白和木边受光。
2. 先取三类容易影响规则理解的画面：带标注坐标的四人地图、道路建设两步同机位示意、张辽技能的玩家与牌背示例。棋盘图保留无标注底图，标注与正文可独立修订。
3. 补齐首页五类入口和四个详情样板的图标。插画出无字透明图，保留接触影的安全边距；正式卡面沿用游戏牌面。逐页检查每个相关词条是否有可辨认的小图。
4. 扩充时按词条计量。每个扩展准备一幅玩法主图和各核心机制小图；每张地图按不同布局准备底图及对应标注；每位武将绑定立绘、势力框和必要的技能示例；每张发展卡绑定正式牌面，有先后结算关系时再补步骤图。共享棋子、牌背、导航与底板只维护一份。

## 首页第一版实机打样

| 位置 | 本版使用的素材 |
|---|---|
| 本局地图 | 打开百科时由独立相机取一次公开棋盘，避开手牌与操作区，复用当局地形、湖泊、渔场及港口模型。地图资源预览用于无棋盘相机的情形。 |
| 本局玩法 | 帆船、城堡、三国和海港直接复用开局菜单的模式图标；捕鱼图案取自首页原型。这是首版取材记录；后续将码头与鱼篓用于同一个「海港与捕鱼」入口。 |
| 武将与卡牌入口 | 将正式静态武将肖像目录 `GeneralUI/v001/Portraits/` 中的周瑜、张辽、关羽，以及现有基础发展卡「丰收」「道路建设」「骑士」分别合成牌组插画。 |
| 框体与其余入口 | 从已确认原型提取木框、绿桌呢、纸牌、地图名牌、搜索框、返回钮、扩展卷轴、地图地块和棋子组合。页面标题、地图名、玩法名、栏目名由 Unity 绘制。 |
