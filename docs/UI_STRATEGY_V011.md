# 相机与操作界面修整 v011

2026-10-15，按本轮九项反馈调整当前 M6。游戏名称为**卡坦岛之三国争霸**，发行版本保留**内测版1.2**；本轮仅要求微信公告，未要求向微信发布可玩压缩包，因此不自动增加发行版本号。工程界面批次记为 v011。

当前程序：[CatanM6.exe](../.local/m6-ui-v011/Builds/Windows/CatanM6.exe)。`Play-M6.ps1` 与 `Play-AiStrategy.ps1` 均指向本版。请先保存退出旧程序再启动。规则、权威存档结构和当前 AI 策略沿用，M7/M8 状态保留。

## 本轮行为

1. 地图放大时连续降低俯视角，默认 58°，最近为 32°，最远为 68°；“切换俯视”模式额外增加 10°。地图缩放、拖动仍不改变固定 HUD 的位置和尺寸。
2. 左侧建筑栏缩小，保留真实网格。建筑正面横向观察，城墙使用俯视；每项模型与数量独立排放，配深色内衬、金属边框和装饰角。
3. 资源卡、发展卡、整理手牌采用磨砂金属纹理、双层镶边、专属图标、悬停和选中反馈。
4. 贸易、政治、科学设施分别打开对应建设板，展示其等级、能力和升级费用。
5. 银行与玩家交易的付出区只列本人已有资源；专属港仅列对应资源，通用港列已有资源。获得区保留当前规则允许换入的资源／商品；无可付出资源时显示空态，不默认越界选择。
6. 蛮族航程内显示最长道路奖励持有者与公开长度；尚无持有者时显示“暂无归属”。基础版、航海家在同位置显示道路奖励信息。
7. 主题切换移入 Esc 菜单，三套主题仍即时切换并保存在本地偏好中。
8. 当前扩展与剧本移入 Esc 菜单，移除对局画面的常驻扩展文字。
9. 回合与当前玩家置于顶部正中的金属铭牌，包含回合编号、玩家头像、行动状态与阶段。

## 实现与边界

交易、建造和设施升级仍提交至原有指令验证入口。最长道路信息仅来自各类 `PlayerView.LongestRoadPlayerId` 及对应玩家的公开 `LongestRoadLength`，不在显示层重算成就，不读取隐藏手牌。航海模式长度沿用规则核心的最长航线定义。

本轮未导入新照片或生成位图资产。模型只调整展示姿态；控件的纹理、边框和图标由显示代码绘制，原始参考与三维资产保留。

相关规则来源保持既有基线：`catan-base-2025-en.pdf` PDF 第 7 页（银行／港口交易）；`catan-cities-knights-2025-en.pdf` PDF 第 7–8 页（商品与城市改良）、第 12 页（组合）；不更改规则条款。
