# M2 本地基础版试玩

在仓库根目录启动：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\development\Play-M2.ps1
```

程序位于 `.local/m2/Builds/Windows/CatanM2.exe`，旁边的 Data、Mono 和 Unity 运行库目录须一起保留。需要重新构建时运行 `Build-M2.ps1 -VerifyPlayer`。当前是本地 3–4 人轮流操作；AI、联机及扩展内容按后续里程碑开发。

## 开始一局

默认创建 4 人局；点击「新开一局」可选择 3 人或 4 人。地形随机、数字按 A–R 螺旋排列，港口随官方六块海框整体洗牌；先手由核心为各席位掷骰决定，同点继续决胜。地图仍用稳定 Tile / Vertex / Edge ID。它使用正常自由开局，不是 M1 的固定验收走法，也不是规则书的新手预摆地图。

1. 将设备交给提示的席位，点击「我是 P… · 查看手牌」。其他玩家暂时移开视线。
2. 点击「拿起开局定居点」，选择棋盘绿色目标并单击放置。
3. 点击「拿起开局道路」，放到刚建定居点旁的绿色边。
4. 正序各放一组，再倒序各放一组。第二个村领取相邻地块的资源。

单击非法目标会拒绝；右键或 Esc 可取消拿起。Tab 切换斜视/俯视，鼠标滚轮缩放，「地形显隐」切换山地装饰。窗口可最大化；「隐藏提示」可腾出上方棋盘区域。

## 正常回合

「行动」页先掷骰，再任意顺序重复交易、建造和购买发展卡，最后结束回合。建路需木砖各 1，建村需木砖羊麦各 1，城市升级己方村需谷物 2、矿石 3，发展卡需羊麦矿各 1。村之间须至少间隔两条边；道路连接不能穿过对手的建筑。

「交易」页默认以自己港口可用的最优比例交易。选择给出的资源与收到的资源，点击确认；银行有限，不能取不存在的牌。切换到玩家交易后，用加减按钮设置双方交换内容并选择对象。对方确认席位后接受或拒绝；发起方可换回自己席位取消，再重新报价。非当前玩家也可向当前玩家报价；两个旁席不能互相交易。不能赠送资源，也不能在交换两边包含相同资源。

「发展卡」页显示自己持有的卡。行动发展卡购买当回合不能使用，每回合至多一张，可以在掷骰前使用：

- 骑士：移动强盗、选择相邻对手随机偷一张；不触发弃牌。
- 道路建设：免费放两条合法道路；库存或合法位置不足时按可放数量结算。
- 发明（丰收）：从银行选择两张资源，可选同种；银行总数不足两张时选择剩余张数。
- 垄断：选择一种资源，收取其他玩家该类型的全部资源。
- 胜利点：平时保密，可在购买当回合计入自己的胜利。

掷出 7 时，各个资源超过 7 张的席位弃掉一半，向下取整。界面会依次引导换座；在自己的弃牌面板选择准确数量。所有弃牌完成后，当前玩家移动强盗至另一地块，再选择相邻对手偷取。可选空手邻居，这时没有资源可偷。强盗所在格停止产出。

最长连续道路至少 5 段、最大军队至少 3 张已使用骑士，各值 2 分。自己的回合达到 10 分立即获胜；他人未公开胜利点不显示在公开席位分数中。

## 保存、恢复与隐私

任意阶段可保存，包括开局待放路、弃牌、强盗移动/偷取、道路建设和交易提案。点击「载入存档」后重新确认需要行动的席位。加载失败会保留当前局面。

M2 格式版本为 `2`；本机默认文件是 Unity `persistentDataPath` 下的 `m2-authority-v2.json`，通常为 `%USERPROFILE%\AppData\LocalLow\CatanDevelopment\Catan M2\m2-authority-v2.json`。已有文件替换时保留 `.bak`。M1 使用独立入口；不能用 M2 读取 M1 存档。

本地权威存档含完整手牌和随机状态，仅供主持端恢复。换座遮罩保护屏幕上的手牌，不能代替多台设备联机的身份与权限机制。

## 建议试玩检查

完成开局、掷骰、银行交易、玩家提案与拒绝、建路、升级城市、一次弃牌与强盗流程。分别在待决和回合之间保存、退出程序、重新启动并载入；检查行动席位、棋子和待选内容一致。继续游玩至胜利，记录难理解的提示或难点击的目标。

实际自动检查、完整对局证据与鼠标检查范围见 [验收记录](M2_ACCEPTANCE.md)；规则与案例的逐条对应见 [规则清单](M2_RULES_CHECKLIST.md)。这些检查不代表用户已经亲自试玩或确认美术样板。
