# 局域网房间与玩家信息修复 v001

日期：2026-10-17（Asia/Shanghai）。沿用内测版1.6，本轮为修复与交互更新，未创建新的公开发行版。

## 当前行为

- 进入局域网联机默认打开左侧“房间列表”，自动发现同网服务并取得真实房间列表；可重新搜索，选择房间即可加入。客户端自动绑定发现返回的证书，HTTPS／WSS 仍须匹配该证书，玩家无需手动抄录和核对指纹。在线服务继续使用系统证书信任链。
- 左侧“创建房间”保留三步规则、地图与同桌配置，Windows 自动准备随包房间服务。Android 支持加入，不能运行 Windows 随包主机服务。
- 主动加入另一房间会释放旧桌连接；旧主机不可达或正在自动重试时，玩家仍可换桌。每房间独立保存恢复身份，局域网按服务器证书和房间号识别，同一服务从回环地址换到局域网地址或更换 IP 后仍能恢复。
- 未开局最后一位玩家退出时结束大厅；断线大厅位置默认保留45秒，超时回收。无在线人类或已结束的房间不进入公开列表；私有存档保留，不显示成永久历史房间，也不阻止创建其他房间。
- 本设备保存过身份的进行中房间，即使全员离线，也可在发现同一服务后显示为“我的进行中对局／重连”。客户端只查询自己的恢复记录，已关闭大厅、找不到或已结束的房间不显示，其他玩家看不到这份恢复列表。
- 已开局后退出、掉线或心跳超时，由服务端 AI 接手，包括待决选择；全部人类离线时仍继续，前提是权威服务运行且未因保存失败或命令上限暂停。重连立即恢复本人视图，在下一次本人行动回合交还操作；开局蛇形摆放的每次行动分别识别。仍在线的连接替换不额外等待。
- 重新入桌以当前本人快照的事件序号作为展示基线，先建立棋盘再分页读取旧历史，不等待整局历史或回放重连前的全部出牌；后续新事件继续按历史和动画顺序显示。
- 玩家名称统一在“设置 → 玩家”修改，本地即时显示，联机防抖同步本人名称。颜色 ID 保持稳定；红、蓝、橙、米白代表建筑颜色。先手沿用规则的开局掷骰结果，头像按真实顺序排列，开局显示红字“你是第n个行动的玩家”。
- 独立 AI 的姓名从哈基米、吃白饭的大肥鲸、糖包、我是奶龙中随机且不重复，本地随存档、联机随房间保存。托管原人类位置保留玩家姓名，控制状态另行公开。

## 城市设施根因与修复

四规则的建造快照曾把 `IsHumanTurn` 写入缓存的 `Available`。该属性包含菜单、城市替换动画等临时展示阻塞；阻塞期间首次缓存后，即使视图和资源满足升级要求，缓存仍不可用。交易恰好产生新视图，因此看似必须先交易才能升级。

现在快照只缓存规则目标、费用与库存条件，点击准备时每帧检查当前交互权限；展示解除无需交易或更换规则视图即可操作。M4／M5 三种设施另有直接升级、费用不足拒绝、预览不改状态及资源／商品守恒案例。没有改变设施费用或升级规则。

## 身份与兼容

Windows 恢复材料用当前用户 DPAPI 加密；Android 使用 AndroidKeyStore 的不可导出 AES/GCM 密钥、随机 IV 与认证标签，原子覆盖密文文件，不回退到明文。忘记身份会清除对应房间恢复文件。恢复凭据不进入截图、公开摘要或提交。

网络协议号升级到2，旧客户端明确提示协议不兼容；旧协议1私有房间档按已知格式兼容恢复，下一次事务提交迁移，未知版本拒绝且保留原件。规则版本与权威规则存档格式未改变，公开视图仅增加既有开局先手 ID，不公开随机状态。
