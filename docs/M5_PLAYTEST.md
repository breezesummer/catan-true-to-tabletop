# M5 双扩展组合试玩

启动已构建的 Windows 程序：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\development\Play-M5.ps1
```

场景为 `Unity/Catan/Assets/M5.unity`，程序为 `.local/m5/Builds/Windows/CatanM5.exe`。M2、M3、M4 的独立入口保留。重新构建并运行独立保存/恢复进程：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\development\Build-M5.ps1 -VerifyPlayer
```

## 剧本与席位

右下角「新开一局」可选“驶向新海岸”或“穿越沙漠”，再选三人或四人。两者使用官方 2025 固定地图，均为 16 分获胜，保留在每个异乡奖励区域首次定居的额外 2 分。[兼容表](M5_SCENARIOS.md)说明其他七个航海家剧本本阶段未支持的原因。

这是本地轮流操作版本。按「我是 Pn」确认席位后才能看本人资源、商品和进步卡；轮到其他人的回合、弃牌或待决时自动遮蔽。右下角也可手动换座，换座会清空当前卡牌查看和棋盘选择。产品 AI 与好友联机留在 M6、M7。

## 开局与组合规则

先正序放定居点，再逆序放城市。每处建筑后放道路或沿海船；开局城市只领取相邻地块各一张资源，不领取商品。选择对应动作，点击「目标 · 点棋盘」，选择交点或边，然后确认执行。

每回合先结算事件骰、蛮族攻击或进步卡，再结算资源骰。首次蛮族攻击完成前，强盗与海盗都不能移动；七点仍会要求弃牌。首次攻击完成后海盗进入外框，之后七点可选择移动强盗或海盗。全地图城市与激活骑士参与同一次蛮族攻击。

城市在森林、牧场、矿山产一张资源加一张商品；田地、丘陵产两张资源；金矿只产自选资源，村一张、城市两张，不能领取商品。金矿待决使用资源加减按钮，配足数量再确认。

## 船、骑士与进步卡

- **行动页**：建船花一木一羊；移动船先选起点边，再选目标边。普通移动每回合一次，不能移动本回合新建船、海盗旁的船或封闭船线中的船。不能通过移船让己方骑士失去必要连接。
- **骑士页**：沿己方道路和船招募、移动或驱逐骑士，移动可穿越陆海交点并停在空海上顶点；敌方建筑和骑士阻断路线。驱逐海盗先选其相邻的可行动激活骑士，再完成海盗移动和偷牌。
- **最长航线**：己方骑士能封闭船线，但不能代替建筑连接道路与船的计分。敌方骑士截断最长航线，不会使截断两旁的船自动变成可移动船。
- **道路建设**：免费建两条道路、两艘船或各一。待决面板选择建设类型并逐个放置。
- **外交**：可以移除开放道路或开放船，自己的棋子只能按同类型免费补建。外交可移除海盗旁的开放船，但新的放置目标仍受海盗阻塞限制。
- **征税与商人**：征税只能移动强盗，不能移动海盗；商人不能放在金矿。其他进步卡和商品交易操作见 [M4 试玩说明](M4_PLAYTEST.md)。

非法目标由纯规则入口拒绝，不扣费、不消耗卡。待决操作只能由所属席位完成；面板显示其选项和资源数量。银行/玩家交易支持资源和商品，港口、三级贸易改良与商船队会影响兑换比例。

## 保存与镜头

「保存」记录全部规则、待决、有限供应、船龄、骑士状态、牌堆和随机状态。「恢复」验证成功后才替换当前局，并重新要求确认席位。存档 `m5-authority-v5.json` 位于 Unity `Application.persistentDataPath` 下，替换前保留 `.bak`；不接受 M2、M3、M4 存档作为组合局。

Tab 切换俯视与斜视，棋盘区域滚轮缩放，「地形显隐」减少山地遮挡，Esc 或右键取消目标选择。组件为可复现实际网格占位，尺寸仍为估算；这不代表用户已确认收藏版成品美术。实际运行证据和未验收事项见 [M5 验收记录](M5_ACCEPTANCE.md)。
