规则、来源快照和覆盖顺序见 [M5 组合规则](M5_COMBINATION_RULES.md)。地图与稳定 Tile/Vertex/Edge ID 直接沿用 [M3 地图基线](M3_SCENARIOS.md)的 `official-2025-v001` 固定图；使用独立的组合规则版本识别权威存档，不把 M3 或 M4 存档直接解释为 M5。

## 开局与入口约束

四个交付组合分别为两个剧本乘以 3/4 人。每个组合正常开局均为第一轮定居点、逆序第二轮城市；道路或船按落点地形选择。开局城市每个相邻产地只领取 1 张对应资源，不领取商品；港口与地图内容沿用 M3。游戏开始时海盗暂不在地图上，按原文放在蛮族轨道最后一格；首次蛮族攻击结束后进入剧本初始 `frame`。该状态必须在公开视图中与通常“海盗在边框”区分。

场景选择只提供支持清单中的组合。规则工厂和存档加载也须验证相同清单；隐藏 UI 选项不能代替核心拒绝。不支持 ID 的失败不得悄悄替换成首个支持剧本。额外随机地形变体、5–6 人和 3D 收藏版特殊规则均未纳入本次清单。

## 阶段退出证据

退出需逐个完成这四个组合的正常完整对局及组合专项案例，并通过 .NET 回归、固定 Unity 版本编译、独立 Windows 运行与保存恢复。既有 M3 的 18 局或 M4 的两局不能代替四个 M5 组合局。玩法驱动器可以通过 PlayerView 进行本地多席位验收，但不因此成为 M6 AI 产品，也不等于用户本人整局试玩。

地图来源复用已经核验的 M3 固定图；组合时另核对开局限制、城市初始产出、海盗阶段与 16 分门槛。实际次数、回合数、测试数量和构建结果由 M5 验收记录登记；本兼容表本身不声称这些运行已经完成。
