- GitHub 在清理前报告 `size = 1562955 KiB`，约 1.49 GiB；该统计包含历史，不能与当前文件大小直接等同。
- 本地 Git 对象文件清理前合计 2806.83 MiB，约 2.74 GiB。它还包含其他分支、stash、取消提交留下的对象及临时对象，不能当作远端大小。
- 用户随后明确授权“备份后继续清理全部历史”。本轮先生成并验证完整 Git bundle，再在隔离副本中清理全部 11 个远端分支和 2 个标签，覆盖 117 个原提交、1329 个不同路径；每个分支和标签的 Unity、src、tests、tools 与规则来源子树均逐项比对一致，`git fsck --full --strict` 通过。
- 隔离副本的独立 Git 对象为 969922498 字节（924.99 MiB），较清理前 GitHub 统计约减少 39%。该值是过滤并重打包后的实测体积，不是实时 GitHub 后台占用；新增说明提交只增加少量文本。
- 远端更新使用全部目标引用的旧对象编号校验与原子推送，保留分支和标签名称。GitHub 后台统计可能在垃圾回收后才更新，旧提交缓存也可能暂时存在。检查时未发现 `refs/pull/*` 引用。
- 只获取当前版本仍可使用浅克隆，例如 `git clone --depth 1 --branch dev-2.0 https://github.com/breezesummer/catan-true-to-tabletop.git`。
