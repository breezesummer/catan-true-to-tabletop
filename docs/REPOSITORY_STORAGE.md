# 仓库存储与本地资料

Git 保存游戏源码、测试、制作脚本、配方与来源清单、规则资料、Unity 工程设置、运行资源和验证摘要。Unity 资源与对应的 `.meta` 一起维护。

## 美术与验证资料

- 原始照片、音频参考、非运行导出、预览、文档截图和原始测试日志保存在本地同名路径。重建或核查前，按[本地资料清单](verification/repository-size-2026-10-24/本地资料清单.json)恢复对应文件并核对内容。
- Unity 客户端直接使用 `Unity/Catan/Assets` 下的正式资源。美术制作与复现要求见[实体资产美术规范](实体资产美术规范.md)。
- 本地开发环境、签名材料、权威试玩存档与原始诊断留在忽略目录。公开证据只记录验证所需信息，保护其他席位的手牌、牌库顺序与随机状态。
- 截图或原件仅在本机保存时，验收记录中的路径用于定位原件。仅获取源码的工作副本需要另行恢复这些资料。
