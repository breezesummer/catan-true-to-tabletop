- 本地 Git 对象文件清理前合计 2806.83 MiB，约 2.74 GiB。它还包含其他分支、stash、取消提交留下的对象及临时对象，不能当作远端大小。
- 本次删除是当前分支的新提交，旧提交、其他分支及标签未改写。完整克隆仍会下载可达历史中的旧资料，GitHub 的历史体积不会因此立即下降。只获取当前版本可使用浅克隆，例如 `git clone --depth 1 --branch dev-2.0 https://github.com/breezesummer/catan-true-to-tabletop.git`。
