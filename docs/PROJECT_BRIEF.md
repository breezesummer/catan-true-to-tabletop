# 工程约定

客户端使用 Unity，规则在独立的纯 C# 核心执行。棋盘以稳定的格、点、边 ID 表达位置；剧本决定初始摆放、地图机制和特殊计分。鼠标、触控、本地 AI 和远程操作共用规则校验入口。

| 修改对象 | 职责与边界 |
| --- | --- |
| 玩家操作 | Command 携带玩家意图和唯一命令 ID。规则核心校验费用、目标和待决窗口后更新 GameState；碰撞与动画只负责交互和展示。 |
| 状态与可见信息 | GameState 保存权威局面、随机状态、供应和待决。PlayerView 按席位授权投影，Event 按观看权限提供已确认的历史。[AI 专用视图](AI_PATCH_2_0.md) · [联机同步](ONLINE_STATE_SYNC.md) |
| 规则依据 | 从[规则来源](RULES_BASELINE.md)查官方版本，再查对应地图或扩展裁定。实体尺寸缺少实测时标记为估算。[参考与尺度基线](REFERENCE_BASELINE.md) |
| 平台与操作 | Windows 鼠标键盘和 Android 横屏触控共用规则、资产和桌面布局。UI 采用[项目约定](../AGENTS.md)规定的组合打样，按任务检查相应输入方式。 |
| 开发与验收 | 先确定玩家能观察到的结果，再按改动路径验证。用户决定玩法、视觉和试玩取舍，工程证据标明平台、人数和场景。[待验范围](ROADMAP.md) |
