# 九张海洋地图的城市骑士组合

2026-10-21，按用户明确要求，双扩展支持全部九张航海家地图的三人、四人配置，并保留各自专属机制。部落奖励与战舰升级的冲突处理由用户于同日明确确认，属于项目变体，不宣称是官方组合条款。

## 项目变体与优先顺序

- 部落卡牌奖励：到达奖励边后，自选贸易、政治或科学颜色，按进步卡抽取流程领取一张牌；公开分数卡、手牌上限和隐私沿用城市骑士。没有增加基础发展卡牌库。
- 海盗战舰：行动阶段失活一枚己方已激活、非本回合激活且本回合尚未行动的骑士，升级己方进攻航线上的一艘普通船。每次仅升级一艘，骑士留下并记录已行动；升级不影响船只总供应。
- 布匹开局保留三轮，城市骑士的第二轮建筑为城市，第三轮为定居点，最后一轮领取每个相邻产地的一张资源。布匹标记与商品布牌使用独立账本。
- 海盗地图保留预放村船和堡垒占用的一枚村庄，随后使用一村一城开局。首次蛮族攻击后才启用巡逻海盗；巡逻奖励先结算，再执行骰点产出或七点弃牌。七点保留原剧本选其他玩家偷牌的方式。该图没有强盗，依赖强盗落点的主教卡没有合法目标。手牌损失包含资源与商品。
- 海盗与布匹剧本保留不使用最长航线；奇观地图保留没有海盗。其余城市骑士功能照常运行。
- 原有两个剧本的地图生成与存档内容保持原值。新增剧本采用单扩展各自的地图生成方式，不强行将所有地图套入主岛随机化算法。

## 实现与验证边界

本地菜单、规则工厂和联机房间使用同一地图清单。专属账本保存在权威状态，公开视图仅提供当前已揭晓地形、公开设施和本席位可用操作；隐藏资源池、点数池和随机状态不进入 AI、人类或网络投影。

测试入口为 `CombinedAllScenarioTests`、`M6FullGameTests` 的全部组合地图配置，以及联机房间规则矩阵。构建后用 `Test-CombinedMaps.ps1` 检查 18 种配置的实际新局、保存恢复和地图渲染。实际运行结果见 [工程验收](verification/combined-all-1.7.3/README.md) 与 [开发日志](../The%20Farmer's%20Log.md)。
