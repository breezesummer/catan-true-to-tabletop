# 整桌交互修复 v003

2026-10-12，修复用户提出的六项桌面交互问题。范围为当前 M6 的基础版、航海家、城市与骑士及双扩展组合；沿用统一规则入口和所属玩家的 PlayerView。

## 启动

运行 `tools/development/Play-M6.ps1`，默认启动 `.local/m6-ui-v003/Builds/Windows/CatanM6.exe`。新版独立构建，旧 `.local/m6` 程序保留。场景仍为 `Unity/Catan/Assets/M6.unity`，规则和存档版本保持原有值，可读取原 M6 存档。

## 六项修复

| 用户反馈 | 当前行为 |
| --- | --- |
| 手牌位置错误 | 手牌放在自己面前的屏幕下方，旋转、阴影和选中上移均留在画面内。只有一种手牌时整体居中；同时持有两种时发展／进步牌在左、资源／商品在右 |
| 高级橡木大桌子 | 使用保留原图的橡木色彩贴图，宽拼板、天然木孔与哑光清漆；实际桌面网格和灯光由 Unity 场景生成 |
| 费用浮窗过大 | 悬停时只显示一行小弹框，例如“木头 木头 木头 羊毛 铁矿”。每份费用分别显示，仅缺少的份数标红；免费项显示“免费” |
| 建造物被整组选中 | 按单枚棋子的可见轮廓命中，重叠时选最上层；只有这一枚上移并出现金色脚环。名称和整组空白处没有拿取入口 |
| 城市与骑士缺事件骰 | 城市与骑士／组合显示红骰、白骰和事件骰；基础／航海显示两颗骰子。点击骰子掷骰，播放约 0.95 秒旋转与弹跳，停止后显示规则确认的骰面。事件面为蛮族船或黄／蓝／绿城堡 |
| 操作提示统一 | 屏幕中央的大红字，每条显示 1.5 秒。正常回合开始依次提示“你的回合”→“请掷骰”；拿取、放置、缺料、待决和保存恢复使用同一提示入口 |

费用展示、单枚选择和动画只改变显示状态。最终骰点由规则核心生成；动画结束与否不裁决规则。自动 AI 调度暂候骰子展示，存档、待决和权威结果仍由原规则入口管理。公开画面只显示其他玩家的公开库存、牌背与数量。

## 资源来源与复现

橡木原图为内置 `image_gen` 生成的 **1254×1254 位图**，不是用户实物照片，也不是新增三维模型。原图存于 `art/source/ui-tabletop-v003/oak-table-albedo-v001.png`；Unity 使用 `Assets/Resources/TabletopUI/v003/oak-table-albedo.png` 副本。

生成提示词、哈希和导入步骤见 [橡木配方](../art/recipes/ui-tabletop-v003/README.md)。保留旧原图和旧版本资源。棋子缩略图沿用旧网格渲染结果，32 份导入设置开启透明通道读取，用于单枚轮廓命中；导出脚本同步此设置。
