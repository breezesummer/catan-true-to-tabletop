# M1 本地试玩

本版本是 v0.1 固定验收切片。它包含 19 个地块、4 个本地席位、开局摆放、产出、银行 4:1 交易、道路建造、回合和权威存档；不是完整基础版。规则版本为 `catan-m1-slice-v1`，地图为原有 `m1-fixed-four-seats-v001 / 1.0.0`。实体参考尚未提供，所有模型尺寸仍为估算。

## 启动

在仓库根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\development\Play-M1.ps1
```

也可以直接打开 `.local/m1/Builds/Windows/CatanM1.exe`。可执行文件须与同目录的 `CatanM1_Data`、`MonoBleedingEdge`、`UnityPlayer.dll` 等配套文件一起保留。启动脚本使用项目日志目录。

从源码重建：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\development\Build-M1.ps1 -VerifyPlayer
```

脚本先编译 .NET Standard 2.1 核心，再复制规则 DLL、原有场景和版本化 FBX/材料清单到正式 Unity 工程；执行实际 Unity 导入、编译和 Windows Mono 构建，最后在两个独立 Windows 程序进程中验证保存和恢复。正式工程为 `Unity/Catan`；`Start-Dev.ps1 -Tool Unity` 打开该工程，`-Tool UnitySmoke` 保留 M0 环境验证工程入口。

## 鼠标与席位

- 启动或换座时先出现遮罩，点击“我是 Pn · 查看手牌”。换座前旧席位的私有视图、目标预览均已清除。
- 点击“拿起定居点”或“拿起道路”，将鼠标移到棋盘目标。绿色小点表示当前合法落点，鼠标靠近时棋子吸附并显示稳定 ID。单击落下；红色预览会被拒绝并退回。
- 右键或 Esc 取消拿起，不改变游戏局面。棋盘空白处落下也会退回。
- 滚轮缩放；Tab 或顶栏按钮切换俯视/斜视。“地形显隐”便于检查山体附近节点，网格不拦截逻辑目标。
- 左上向导显示固定验收目标，右侧“操作帮助”可关闭。四个公开席位按钮允许手动换座；非活动席位的指令仍由核心拒绝。
- 交易按钮轮换交出/取得的资源类型，点击“确认交易”才提交。道路费用为 1 木材 + 1 砖块。

## 固定流程

每行先放定居点，再放道路；轮到其他席位时先确认遮罩。

| 次序 | 席位 | 定居点 | 道路 |
| --- | --- | --- | --- |
| 1 | P1 | V42 | E60 |
| 2 | P2 | V15 | E17 |
| 3 | P3 | V29 | E41 |
| 4 | P4 | V40 | E56 |
| 5 | P4 | V32 | E48 |
| 6 | P3 | V18 | E27 |
| 7 | P2 | V49 | E69 |
| 8 | P1 | V09 | E08 |

全部开局道路落下后才发第二定居点资源。P1 有 3 木材。依次：

1. P1 掷骰，结果 2+3=5，手牌变为 5 木材。
2. 交 4 木材、取 1 砖块，余 1 木材 + 1 砖块。
3. 拿起道路并落到 E65，手牌归零，道路库存为 12。
4. 结束回合，轮到 P2，先出现隐私遮罩。
5. 保存，关闭程序，重新启动后载入，确认 P2，再掷骰。结果 1+1=2，P2 有 1 砖块 + 2 谷物。

此后受控骰子队列已用尽，再次需要掷骰时会明确拒绝；不会循环队列或自动引入未实现的强盗规则。

还需在 P4 刚放 V40、尚未放 E56 时，以及 P1 首次掷骰后，分别保存并载入。前者应继续要求 P4 连接 V40 的道路，后者不能再次领取首次产出。详细账本、负例及重试约定见 [原验收规格](acceptance/V0_1_ACCEPTANCE.md)。

## 存档

本机路径为 `%USERPROFILE%/AppData/LocalLow/CatanDevelopment/Catan M1/m1-authority-v1.json`，由 Unity `Application.persistentDataPath` 定位。重复保存采用临时文件替换，上一份保留为 `.bak`。未知版本或损坏存档会拒绝加载并保留当前对局。此文件包含全部私有手牌、随机继续信息和去重记录，是本地权威存档，不是公开同步数据或玩家视图。

自动验收使用 `.local/m1/verification` 的独立文件，不覆盖手动试玩存档。按类型手牌仅显示当前确认席位；不要把权威存档内容当作公开日志展示。

## 用户验收反馈

阶段正式关闭仍需要用户亲自完成上面的流程并确认样板和操作体验。请记录：能否选中相邻点、缩放后目标是否清楚、山体是否遮挡、取消和非法落点是否直观、三种存档时机是否恢复正确。自动规则测试与代理窗口检查的证据记录在 [M1 验收记录](M1_ACCEPTANCE.md)，不作为用户已试玩的证明。
