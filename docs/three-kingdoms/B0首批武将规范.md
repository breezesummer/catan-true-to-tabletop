首批是定稿与实现批次，不是自动可运行的完整四人将包。按原发 4／5 张、各留 2 张的规则，三人正常开局至少 9 张全技能将，四人至少 11 张；四人正常局还须纳入至少 2 张完成全部技能的后批武将，不能用空技能将填池。详见主规范 §1、§3。

本文件中的“手牌”仅为五类资源与三类商品；发展牌为三色未使用发展牌，公开 1 分牌另属计分区。所有原始牌名与 W 编号均可回到百科核对。“回合”用真实回合实例识别，“阶段”用阶段实例识别，“任次”用本次登场实例识别；恢复不会创建新任次、刷新次数或重新投随机。

案例中的甲为当前技能持有者，乙、丙为其他玩家；未明确设为 0 的供应均足够，未明确设置的禁令均不存在。`H甲` 表示甲的资源／商品手牌总数；发展牌不混入这个数。随机案例给定已保存的抽取结果序列，是独立夹具输入，不允许产品玩家指定随机结果。

每个技能下方的案例都是后续实现必须达到的**预期**。B0 仅检查这些输入输出是否确定，不将其写成“游戏测试已通过”。

### 共同结算合同

1. **阶段与供应。** 每个实际回合只有一个全局摸牌阶段。按主规范 §5 先为正常生产（含金矿选择）处理短缺并预留，再确定固定增量与互斥替代；放弃预留后不重算别人已确定的常规产出。突袭拟放弃的牌须继续预留，直到与实际取牌同次原子提交才释放；降低 x 时由原预留领取恢复的额度。技能奖励只使用未预留存量。突袭、涉猎、天妒不能对同一主分配重复替代；独立得失牌奖励与水渠补偿不在可替代额度中。
2. **水渠。** 本阶段主分配含主动替代最终实得 0 张、正式骰点非 7 且有科技资格，才另处理水渠；独立牌流奖励不改变资格，禁摸仍挡水渠。不得用主动放弃后又拿回原分配的方式结两次。
3. **次数。** 同一候选按事件＋技能＋任次只发动一次。未写次数的主动技不添加隐藏上限；限定“回合／阶段”的计数按对应实例保存。隐退后在场能力停止，已经正式发动的效果继续；重抽登场新建任次，不追溯旧事件。
4. **选择与短缺。** 自选由实际获得者选择；资源只可选五类，资源／商品可选八类。只显示有可用库存且未被禁止的选择；没有选项时自动结算为 0，不生成死待决。技能奖励不足取实际数量，0 张不产生获得事件。自选与随机两段按牌文顺序分配，合并为该技能本次获得批次后再触发后续获牌技能。
5. **费用与结果。** 费用先全部验证并原子支付，处理实际失牌产生的子链，再恢复父效果后续步骤；不能用费用后的补牌补齐原本不足的费用。一次双向交易以整次提交前后手牌判断连营，内部扣牌中间态不作规则状态。
6. **失效与取消。** 正式发动前可放弃可选技；主动非法操作不扣牌、次数或随机。发动后的选择不能用关闭窗口撤销已提交结果。具体可重选的目标按逐技规定处理；通用重验不能把已发出的收益回滚。
7. **隐私与恢复。** 保存候选、所选项、预留、临时牌、费用、随机状态、已结算批次、次数、父步骤和窗口。重连只向有权者显示待决；同一命令重试返回原回执，旧窗口命令拒绝且状态不变。以下每个恢复案例同时要求连续运行与恢复运行的最终权威状态、随机状态、公开历史一致。

这些共同合同与主规范 §3–6、§9 一起适用于下面全部分支。原模式生产、科技与发展牌基线来自 `catan-cities-knights-2025-en.pdf` PDF 第 6–8、10 页；金矿与船的组合覆盖见同文件 PDF 第 12 页。原件路径见[本地规则索引](../../assets/references/rules/README.md)。本文件对武将的规则是项目自定义，不称为官方 PDF 规则。

## 2. W01 张辽：突袭

来源：[百科 W01](../三国争霸游戏百科.md#01张辽登锋陷阵魏)原文与建议。规范采用“本阶段自己的实际可领取额度”，含正常产出及固定阶段增量，不含之后的技能奖励、水渠或其他替代所得；有限供应先按共同合同处理。

| 项目 | 确定规则 |
| --- | --- |
| 输入／时机 | 张辽在场；任意实际回合的全局摸牌阶段进入替代选择；本人的主分配已有具体牌种与数量，未领入手。未被禁摸或禁止该次替代。 |
| 选择 | 可不发动；发动时选整数 `1≤x≤实际额度`，选要少领的 x 张具体分配牌，再选 x 名互不相同的其他玩家。每个目标此时至少有 1 张可被取得的手牌，不能选自己。目标的预留产出不是其手牌。 |
| 费用／次数 | 不额外弃牌，少领 x 张是替代。每次主分配只选择一次突袭，不把取来的牌再替换；不另设每轮次数。 |
| 输出 | 正式目标窗口及其子效果结束后再重验，目标手牌不冻结。每目标按其当前可被取得的真实手牌按张数随机取 1，不查看。全部原产出预留保持到此时；成功取多少张才原子释放多少拟放弃牌，余下原分配与全部偷取在同次提交中完成；甲有一个合并获得批次，各被取者各有自己的实际失牌批次。 |
| 失效 | 提交前目标空手、取得禁止或被动失牌保护令其不再可取时，重新选择目标或降低 x，同时还原不再放弃的原分配；可降到 0 取消替代，领取保留额度。不能先少领再让偷取无偿失败。已正式发出的目标响应不回滚，同一技能使用不再向同一人重复发目标事件。 |
| 供应为 0 | 自己实际额度为 0 且没有阶段增量时不能发动，即使他人有牌；银行不足不凭空形成额度。固定增量提供有效额度时可以替代。盗取不消耗银行。 |
| 任次／恢复 | 隐退前已经正式发动的突袭继续；新任次不能再次替代同一份分配。保存分配原额、减领选择、目标确认记录、取牌随机结果与提交标识；恢复不重抽。 |

| 案例 ID | 输入、操作与预期 |
| --- | --- |
| W01-N | 甲预留木 1、砖 1、布 1，乙有羊 1，丙有矿 1。选 x=2、少领木砖、目标乙丙：甲本批得布羊矿各 1，木砖释放回可用银行；乙丙各失 1。 |
| W01-I | 选择自己、同一玩家两次、空手者、x 大于额度或少领不在分配中的牌，均拒绝，分配、手牌、随机和次数全不变。 |
| W01-Z | 正式骰点 7、甲无阶段增量，额度 0：不出现可执行突袭；仍有摸牌阶段。若合同夹具有 1 张合法固定增量，x=1 可行，但该夹具不表示后批英姿已实现。 |
| W01-B | 已选乙后，目标子效果使乙受到被动失牌保护。甲改选有牌丙，或 x 从 1 降到 0 并领取原分配；不得吞掉原额。 |
| W01-T | 甲在自己摸牌窗口发动后换将，父突袭结完；重抽张辽不能对已提交主分配再偷一次。未发动就隐退则旧候选消失。 |
| W01-R | 保存于目标响应完成、尚未原子取牌的待决；恢复用相同合法选择后偷取的类型、余下银行、目标手牌及随机状态与不断线运行相同。 |

## 3. W06 曹仁：据守

来源：[百科 W06](../三国争霸游戏百科.md#06曹仁国之柱石魏)。将“回合结束”明确为**自己的实际回合结束阶段**；翻面跳过机会不产生据守窗口。此技能的禁摸是首批真实产生的有期限效果。

| 项目 | 确定规则 |
| --- | --- |
| 输入／选择 | 曹仁在场，自己的结束事件尚未处理该任次候选。本人选择发动或放弃；发动后必须领取 `min(4,当前合法可用资源总数)` 张，自选各张类型，可同种，不含商品；有足够供应不能主动只取0–3张。 |
| 费用／次数 | 无手牌费用，每次结束事件一次可选机会。不是主动无限次按钮；换入新将不追溯本已建立的结束事件。 |
| 输出 | 先一次获得实际可给的 0–4 张并处理其结果子链，再在玩家身上建立禁摸记录。记录从此刻到该玩家下一次正常或额外行动机会开始；翻面跳过的机会也先解除。 |
| 禁摸范围 | 在其他玩家回合阻止从银行／发展牌库的无偿收获、技能摸资源／商品、摸发展牌，以及突袭等摸牌替代；不阻止非摸牌的他人给予、普通玩家交易或直接偷取。有偿银行交易按交易原因分类，不因为来源为银行就称为摸牌；本技能不授予原本没有的回合外银行交易权限。不同的“禁止获得某类牌”须另按公共合同检查。 |
| 供应为 0 | 已发动据守取 0，仍建立禁摸，不产生获得事件；部分供应只领实际数，不因不足取消代价。 |
| 任次／恢复 | 隐退、重抽不提前解除旧记录；同一未到期禁摸范围不叠加额外期限。保存已领取批次和明确的到期玩家／机会条件，恢复不能再发 4 张。 |

| 案例 ID | 输入、操作与预期 |
| --- | --- |
| W06-N | 甲自己结束时选木 2、矿 2，先入手 4，再建立禁摸；乙回合甲普通产出 2 和技能银行奖励 1 都为 0。若乙为刘备，其在自己回合合法发动仁德给甲羊 1 可完成；不据此给普通玩家新增单向赠予能力。 |
| W06-I | 乙结束时甲请求据守、甲选择商品、旧结束窗口重复发动，均拒绝且不变更。 |
| W06-Z | 银行五种资源全 0：确认发动后领 0，禁摸仍有效；剩木 2 时最多取 2。 |
| W06-B | 甲下一机会是额外回合或翻面跳过的正常机会：均在开始边界解除；若跳过，不再生成新的据守。 |
| W06-T | 甲据守后在同一结束结算安全窗口隐退，再抽回曹仁：旧禁摸仍到甲下一机会开始；不因新任次取消，不追溯旧结束事件再领牌。 |
| W06-R | 保存于 4 张已领取、尚待获牌子链完成的步骤；恢复只续子链并建立 1 份禁摸，手牌不重复增加。 |

## 4. W09 郝昭：镇骨

来源：[百科 W09](../三国争霸游戏百科.md#09郝昭死守陈仓魏)。每次使用明确为**现在补一次＋指定目标的下一次实际出牌阶段开始前补一次**，不是持续每回合追平。

| 项目 | 确定规则 |
| --- | --- |
| 输入／选择 | 郝昭在场，自己的真实回合结束窗口；可放弃，或选择一名其他玩家。自己当前手牌不少于目标也可以发动，以建立第二次机会。 |
| 费用／次数 | 无费用；本结束事件本任次最多一次，后续正常结束可另建独立标记。 |
| 第一次输出 | 完成该次使用的合法目标响应后，快照甲、目标当前手牌数，`n=max(0,H目标−H甲)`；从可用资源池随机取至多 n 张，作为一个获得批次；不弃甲多出的牌。此次数量确定后不因派生获牌重新计算。 |
| 第二次输出 | 建立独立延时记录，绑定玩家身份，不绑定其武将或固定座位。到该目标下一次**实际进入**的出牌阶段开始前，按同一公式另拍快照并补一次，随后消耗记录。这里续结原使用，不再建立新的成为目标事件。 |
| 跳过／多份 | 翻面整回合跳过不消耗第二次；额外实际回合可以提前命中。多个标记按建立顺序各快照、各结算，不能覆盖成一份；后一个会看到前一个已完成的获牌。 |
| 供应／禁摸 | 不足只取实际数；无资源或甲禁摸时取 0。本次到期的第二次机会仍消耗，不因为取不到而延期；第一次取不到也照样建立第二次。 |
| 任次／恢复 | 双方隐退、重抽不取消已建立的记录。新任次可在未来新结束事件另发动。保存目标玩家、标记序号、是否已完成第一次、第二次是否到期及随机状态。 |

| 案例 ID | 输入、操作与预期 |
| --- | --- |
| W09-N | 甲结束时 H甲=1、H乙=4，第一次随机得 3；到乙实际出牌前 H甲=2、H乙=5，再得 3并移除标记。各次补至快照数，不因补牌子链新增所得反复补。 |
| W09-I | 自选自己、他人结束时请求发动、重复提交已处理的第二次窗口，均拒绝且无变化。 |
| W09-Z | 第一次需 4、资源仅 1，则得 1并留第二次；第二次资源 0 则得 0并消耗。H甲≥H乙 时不弃牌且不生成获得事件。 |
| W09-B | 乙下一机会翻面跳过，记录仍在；随后乙额外回合真正到出牌阶段才结第二次。两份同目标记录依建立序执行，后份以新牌数算差，不重复领取旧差值。 |
| W09-T | 第一次后甲隐退、乙也换将，标记照常命中乙下一实际出牌；甲重抽郝昭不删除旧标记。 |
| W09-R | 保存于第一次已得牌且第二次待触发的状态；恢复不再执行第一次，并在相同目标、相同阶段入口取得相同第二次牌序。 |

## 5. W12 留赞：奋音

来源：[百科 W12](../三国争霸游戏百科.md#12留赞灵魂歌王吴)与 G13。比较对象明确为**自己本次出牌阶段内、该任次在场期间上一个成功建造的建筑类型**，不读取全场或旧阶段历史。

| 项目 | 确定规则 |
| --- | --- |
| 输入／时机 | 留赞在场，自己出牌阶段发生成功建筑事件；正常付费或免费均可。先完成建造及原模式必须重算，再处理奋音。 |
| 建筑分类 | 道路、船、村庄、城市、城墙各为一类。村升城记城市；同一类型的不同位置仍相同。科技设施、骑士、修复、移动船、激活、初始摆放均不计。海盗要塞收复、战舰、奇观等场景行为依九图合同，不仅凭名称视为普通建筑。 |
| 选择／次数 | 第一次只记类型，不奖励；以后类型不同则强制产生一次自选 1 资源的奖励。无独立费用、无额外限次。连续建造多个对象逐个成功、逐个比较，不能按整张牌数量只记一次或重复记同一建筑。 |
| 输出与记录 | 每个成功事件先用旧类型比较，再把记录更新为本次类型，即使奖励因供应或禁摸为 0 也更新。修复／非法建造不覆盖上一个类型。 |
| 供应为 0 | 建造仍完成且记录照常更新，奖励 0；银行恢复后不能补领漏掉的奖励。 |
