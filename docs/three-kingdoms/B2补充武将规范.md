# 三国争霸 B2 补充武将规范

日期：2026-10-22（Asia/Shanghai）。规范版本：`three-kingdoms-b2-supplement-v1`。

本文件为 B2 四人正常开局补足两张全技能武将，采纳百科 W33、W43 的建议作为工程合同，不追记为用户曾逐条确认。首批九张的全部技能仍按 [B0 首批规范](B0首批武将规范.md)，公共合同仍按 [B0 规则定稿](B0规则定稿.md)。这里只解除 W33、W43 的规则隔离；其他 43 张后批武将仍须整将完成才可进入正常包。原始 54 将、97 技能及用户原答复保持不变。

正常 B2 包的目标清单为 `tk-g01/tk-g06/tk-g09/tk-g12/tk-g15/tk-g22/tk-g23/tk-g28/tk-g33/tk-g37/tk-g43`，共 11 将、15 个具名技能。每张进入包前必须实现下文全部分支；本规范本身不构成实现或测试通过证据。三人／四人仍逐人发 4 张、末席发 5 张、各选 2 张，不少发候选、不用空技能填池。

## 1. 来源与共有边界

两张均来自项目自定义原文 [三国争霸游戏百科](../三国争霸游戏百科.md) 的 W33、W43 原文与建议答复，不属于官方武将规则。城市骑士发展牌的颜色、抽牌、公开分牌、合法使用与容量基线来自 `catan-cities-knights-2025-en.pdf`，PDF 第 6–8、10 页；组合模式覆盖见同文件 PDF 第 12 页，原件入口见 [本地规则索引](../../assets/references/rules/README.md)。

资源指五种资源，商品指三种商品。随机资源按当前未预留银行中各类真实张数加权抽取；无放回更新库存。自选资源／商品只可选择可给的真实库存，不能消耗其他玩家已预留的普通生产。0 张收益不生成获得事件，不悬挂无选项待决；已命中的勤政仍推进指针。曹仁旧据守禁摸同样阻止这两将的银行／发展牌库奖励。

按事件 ID＋技能 ID＋任次 ID 去重，不按动画、调用次数或一次根因果的总次数去重。真实投掷的用途、最终结果、来源事件、已经发给各人的发展牌、奖励进度与任次均须可保存。未提交候选、落选候选、固定结果、预览和重放已有命令都不能伪造新投掷。骰子后奖励在原骰局对应事件结算完成后进入技能队列，不再次执行普通产出、事件骰发牌或入侵。

## 2. W33 黄月英：集智、奇才

稳定定义 `tk-g33`；技能按原文顺序为 `tk-g33-s1` 集智、`tk-g33-s2` 奇才。

原文：

> 集智：每次骰子被投掷后，若不为海盗入侵且你未获得发展牌，你摸一张任意资源牌。当你打出发展牌后，你摸一张随机资源牌。
>
> 奇才：你的发展牌没有上限和使用限制。

### 集智首段：骰局后自选资源

| 项目 | 确定合同 |
| --- | --- |
| 资格 | 黄月英在场，正常／额外真实回合掷骰阶段的一次正式骰局已经真实投出并最终确认。任意玩家的该种骰局均可触发，不限本人回合。 |
| 检查时点 | 此次事件骰及其发展牌发放、必要容量子流程全部结束后，读取该骰局期间黄月英实际获得的发展牌数；不得读取整回合曾得牌的累计。 |
| 条件 | 事件不是黑色入侵，且本人在上述发牌中实际获得 0 张发展牌。黑色只是推进入侵尚未攻击，也不符合。颜色库为空导致实际 0 张，仍符合。公开 1 分牌实际入账也算本次得过发展牌。 |
| 输出 | 强制自选 1 张可用资源，不含商品；无可用资源或禁摸时为 0。合格骰局只奖励一次，没有额外费用。 |
| 排除 | 判定、比大小、观星落选组、洛神中间候选不触发；固定数字／颜色未真实投掷不触发。正常数字合计为 7 不单独排除；若事件非黑且未获发展牌，完成正式骰局事件后仍可奖励，不能据此产生普通 7 点生产。 |
| 任次与失效 | 候选建立后尚未正式发动就隐退，旧候选失效；已经正式发动并进入待选资源的奖励继续。新任次不追溯旧骰局。 |

### 集智第二段：发展牌用后随机资源

成功使用发展牌的全部效果与必要选择结束后，强制从可用资源随机取 1 张。合法实体或虚拟发展牌均适用，未来虚拟牌来源未整将完成前不提供虚构入口。使用合法但目标随后免疫，仍算成功使用；初始声明非法、取消未发动、单纯弃牌／交换、抽到即时公开的 1 分牌均不视为打出发展牌。每次独立使用一次，和骰局奖励彼此独立。

无资源或禁摸则取 0；0 张不得抽取随机，也不产生得牌事件。保存牌使用 ID、主体已完成标志和奖励状态。恢复不能再执行原牌效果或再抽一次奖励。技能已发动后换将仍结完，未开始的旧任次候选不保留。

### 奇才：容量和使用权限

黄月英在场时，未使用三色发展牌无容量上限。只豁免原模式确实存在的统一使用次数或新获牌等待限制；当前城市骑士与组合模式本来允许同回合使用新获牌且没有统一每回合一张限制，不凭空新增再删除限制。

奇才不豁免合法阶段、行动者、目标、分数条件、资源费用、效果前提、必要决策或牌种身份；不授予回合外出牌权，也不能免除非容量原因的明确弃置／失去。1 分牌仍即时公开并计分，不积存在隐藏手牌。

隐退后恢复普通上限：回合所有者在当前出牌阶段结束检查，非回合所有者在移除能力的容量检查点立即检查；若克己保护正在阻止被动失牌，则挂起检查，到保护解除时补查。重抽同将恢复无上限，不删除本已合法发生的弃牌。容量待决和挂起状态必须恢复一致。

## 3. W43 骆统：勤政

稳定定义 `tk-g43`；技能 `tk-g43-s1` 勤政。

原文：

> 每当骰子点数为3/5/6/8/10/12时，你按顺序循环摸一张随机资源牌/资源牌/商品牌/资源牌/发展牌。

保留用户已经明确的解释：六种点数中任意一种命中，都推进相同的五项奖励循环；不是六种点数各对应一项奖励。重抽同将重新建立任次并从第一项开始。

| 指针（从 0 起） | 本次奖励 | 选择权 |
| --- | --- | --- |
| 0 | 随机资源 1 | 权威随机按可用实体数量加权 |
| 1 | 资源 1 | 骆统所有者自选五类可用资源 |
| 2 | 商品 1 | 骆统所有者自选三类可用商品 |
| 3 | 资源 1 | 骆统所有者自选五类可用资源 |
| 4 | 发展牌 1 | 骆统所有者选有牌的颜色，抽该色库顶，不得指定牌名 |

每次正式命中快照当前指针，确定本次奖励并推进为 `(指针+1)%5`，随后完成该奖项；一份待决不重复推进。指针跨阶段、跨回合保存，同次任次不重置。供应不足、全部供应为空、旧禁摸挡住奖励，都以实际 0 张结算并推进；不存在欠下次补领。

观察任意玩家真实投掷各组的最终数字合计，包括正常／额外正式骰局、判定和比大小各组。观察结果独立于事件颜色，黑色不排除勤政。观星落选组、洛神舍弃的中间结果不计，单次改点不产生另一次投掷；固定点数未真实投掷不计。未命中集合的最终合计不推进。后批改骰、判定和比大小没有整将实现时，仅保留这一公共入口合同，不开放半技能按钮。

第五项遵守正常发展牌归属、即时公开分牌和容量检查；勤政不附带奇才权限。颜色全空时自动以 0 完成并回到指针 0。奖励已正式开始后骆统隐退仍完成旧帧；新任次指针为 0，旧帧不改写新任次计数，也不重放旧投掷。

| --- | --- |

| W43-B | 骰色黑而点数 6 仍命中；一次比大小两组合法最终点数均命中则各推进一次；判定不导致普通生产／入侵／科技抽牌。 |

| W43-R | 在第 2、3、4 项选类型和第 5 项选色时分别保存；恢复候选与选色合法性相同，只领一次、只推进一次，同随机状态继续一致。 |

## 4. 包与退出证据

11 张正常包必须保存明确包版本、内容哈希与已启用技能清单。不得把 B1 的 54 张开发骨架存档无声解释成 B2；旧模式和旧骨架继续使用各自规则，版本不匹配须明确拒绝或走已有旧解释器。

本次补充将至少须通过上表正常、非法、无供应、次数／循环、任次、恢复案例，以及与据守禁摸、普通容量、预留库存、同一事件去重的交叉案例。完整局必须使用正常随机候选、产品 AI 和正式胜利条件，覆盖三人／四人城市骑士及组合模式；运行预算仅用于发现死锁，不能当胜利条件。

验收时记录真实测试数量、失败和既有基线差异。仅有合同夹具不表示后批骰子技能完成；仅有自动局不表示真实设备、像素检查或用户试玩通过。
