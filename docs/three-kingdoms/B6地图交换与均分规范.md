# B6 鲁肃地图交换与均分

日期：2026-10-26（Asia/Shanghai）。本轮采纳百科 G18／W47 的建议作为 B6 工程合同；规则来源为[三国争霸游戏百科](../三国争霸游戏百科.md)鲁肃牌文与板块交换注释。普通道路、船与海岸基线参照 `catan-seafarers-2025-en.pdf` PDF 第2–3页；稳定地块、顶点、边身份属于项目架构约定，三国覆盖规则不是官方卡坦规则。

## 榻谟

自己的出牌阶段可选择两块现有地块，整次成功后消耗本任次限定次数。金矿、未揭示迷雾不可选；涉及海洋或沙漠时两端不得含6／8。地形与数字整体互换，空数字同样随地形移动；坐标及 Tile／Vertex／Edge ID 不变。

预检把道路、建筑、骑士及相连棋子作为完整连通组件。仅当组件所有点、边均在一个目标六边形边界上、不连接外部棋子、不接触其他陆块时，组件才随地块移动。船保留原位；与船相连的组件也不搬。城墙、大都会、倒塌城市保留标记随宿主建筑移动。损害与实付记录同步更新空间引用，不重新给棋子计费。

依第一块旋转0至5、第二块旋转0至5的固定顺序，选首个整体合法结果；建筑距离、重叠、骑士占点、道路陆地支持和船的海边支持都在预览副本验证。海图外沿仍按原航海家规则视作可航行海边。强盗、海盗、商人随地形内容迁移，保持地形合法，不引发偷牌。

港口仍合法时保留；失去海陆边时按原端点到候选海岸的最短边距重建，并以 Edge ID 排序打破平局。新港口不能与其他港口共用端点；无完整合法结果即整次拒绝，地图、随机源、库存、次数和历史都不改变。

九图保留剧本专属玩法。未揭示迷雾、要塞及其出发点与登陆点、奇观预留点、部落奖励边与港口、布匹村庄、固定海盗巡逻路线和预留登陆禁区作为锚点；涉及这些锚点的板块不可成为交换目标，入侵航线接触的板块也不可选。已揭示的普通迷雾格可交换。地图验证继续检查固定几何身份、地形总数和数字总数，迷雾未发出的池子计入守恒。

登岛奖励在首次取得时保存玩家、地区、当时支持该建筑的地块及分值。交换使原奖励来源不再有合格建筑时扣回，保留曾经登岛记录；移回、搬迁和重新建造都不重复颁发已撤回的首次奖励。旧奖励在首次地图交换前补齐来源记录。部落奖励与城市骑士分数不当作登岛奖励撤回。

## 智盟

只在鲁肃拥有者的回合结束事件询问，可放弃；目标是另一名玩家。双方资源与商品进入权威洗牌，鲁肃取得向上取整的一半，另一方取得剩余部分，不混入发展牌。

洗牌实体保留原拥有者，因此分回原主不产生虚假的失牌和获牌；即使同种牌互换，发生所有者变化的实体仍各记一次真实转移。所有转移先一次提交，再按双方各一批生成响应。给予奖励不把此次强制均分当作主动赠予。

禁失牌、禁摸牌、克己、联盟禁贸及司马师禁获牌在随机消耗前检查；不允许先随机看到结果再判定能否成立。目标响应后再验一次，失效则不再分牌。貂蝉自愿交易等量限制不用于这项强制移牌。零手牌且无可分配对象时不询问；选择、放弃和后续随机状态都可恢复。

## 实现与验证入口

`B6MapTransaction` 是无宿主随机源的纯事务预检；`IThreeKingdomsB6MapHost` 连接城市骑士与双扩展实体；`B6MapSkillEngine` 接入既有待决、技能历史和牌流队列。M4／M5 的港口及登岛记录随存档保存，未新增 UI 专用规则状态。首次蛮族前尚未入场的强盗／海盗也记录随板块迁移后的入场格，交换不会提前放置标志物，正式入场时不再读取已经改变的原始地形位置。

每次列出交换目标只计算一次资产连通组件和各港口的几何最短距排序，候选地形共用这些只读结果；不跨存档缓存，不占用随机状态。九图三／四人初始局面在本地专项运行中的单次枚举为 3—46 毫秒，仅鲁肃本人处于合法出牌阶段且限定技未使用时枚举。

专项位于 `ThreeKingdomsB6MapTests`：九图各三／四人、城市骑士宿主、保留锚点、海陆限制、组件附着物、固定顺序旋转、全失败回退、港口距离、代号稳定、限定次数、幂等、私密均分、同种实体归属、禁牌与恢复。测试结果并入 B6 总验收记录，不替代界面、真机或多人外网验收。
