# 三国争霸 B6 实现说明

2026-10-26。B6 在原城市骑士和九图双扩展宿主内复用同一规则核心，开放剩余五名武将。规则合同见[B6规则定稿](B6规则定稿.md)，具体执行结果见[验收记录](../verification/three-kingdoms-b6/验收记录.md)。

## 核心与宿主

| 模块 | 主要入口 | 保存与事务边界 |
| --- | --- | --- |
| 包身份 | `GeneralCatalog`、`ThreeKingdomsEngine` | B6独立版本与内容哈希；54将97技能完整目录；旧身份保持 |
| 代操 | `B6Control`、`M4/M5ThreeKingdomsControlB6` | 真实提交者与资产席位分离；私密视图按授权切换；末尾容量待决完成后撤权 |
| 地图 | `B6MapTransaction`、`B6MapSkillEngine`、两宿主 `MapB6` | 纯副本预检、固定旋转顺序、组件和港口整体提交；登岛来源记录可保存 |
| 联盟 | `B6AllianceModels`、`B6AllianceSkillEngine`、两宿主 `AllianceB6` | 来源关系及共同胜利名单；骑士实体所有者不变；退盟归位待决可恢复 |
| 座次／交易 | `B6SeatTradeSkillEngine`、两宿主 `SeatTradeB6` | 固定座位游标；私密看牌；真实禁获类型；建造支付前可恢复的造价选择 |

`B2SkillEngine` 统一接入登场、机会开始／结束、回合末、动作枚举和待决解析。可变状态加入 `ThreeKingdomsEngine.Clone`；M5事务复制保留港口、登岛、联盟、代操及归位信息，预览不能改变权威状态、随机源或技能次数。

原生银行交易、产出、金矿、引水渠、强盗、发展牌与 B2–B5 技能牌流接入景略限制。选择获得他人牌时先计算可获得的实牌数量，避免禁止的牌被拿走后退进银行。仁德、条件转移、下书、伏骑等整批移牌在目标响应后再次验证，不产生部分付费或免费后续效果。

科技共享作用于有效能力查询、事件骰抽牌、商品兑换及骑士晋级；个人设施、大都会竞争和分数保持各自所有。骑士共享覆盖普通移动、激活、晋级、铁匠、驱盗及战舰操作，费用由行动者支付，供应、入侵贡献和奖励归实体主人。多骑士退盟逐次重验空位，无位置回供应。

## 界面、AI与网络

M4／M5投影同时携带 `PlayerId`（当前资产视角）与 `ViewerPlayerId`（真实阅读者）。本地与网络提交、预览和AI按同一投影填写代理命令。自己的响应优先于代理视图；手牌、技能、暗将和棋盘选择使用当前资产视角，账户席位与本地重开配置仍使用真实玩家。

底栏补齐十个技能的时机、费用和次数。地图通过两个地块直接选择，败移通过两个头像，景略使用授权私密牌带，伏骑与条件结盟使用真实手牌／声明牌带。界面从合法投影开放盟友骑士、港口和有效科技；锻造复用合法目标组合，允许任意点击顺序，避免每帧排列预检。玩家栏显示同盟及共同胜利，终局显示完整共同获胜名单。

棋盘刷新签名包含地形、点数及港口位置，交换同类地形的点数或迁移港口也会更新。地图候选每次共享连通组件和港口距离预计算，不跨权威快照缓存。九图三／四人专项中的一次换地枚举约3–46毫秒；这不是四人外网延迟或客户端帧率验收。

AI只从本席／授权投影的合法动作选择，补齐有限主动技能及B6必选响应，保留主动技能由真人自行决定的规则。联机包握手识别B6版本与哈希；房间命令验证、同时选将令牌、保存与幂等沿既有链路。重连恢复按真实回合操作者判断，不按临时响应者错误交回。

## 检查入口

- `ThreeKingdomsB6ControlTests`：授权、私密投影、真实付款、保存、重试、伪造拒绝、末尾弃置与撤权。
- `ThreeKingdomsB6MapTests`：城市骑士及九图三／四人、海陆合法性、组件、港口、登岛和均分。
- `ThreeKingdomsB6Alliance*Tests`：协商、隐藏库存、共享能力、实体所有权、入侵、共同胜利和退盟归位。
- `ThreeKingdomsB6SeatTrade*Tests`：换座游标、次数、私密景略、期限、禁获和真实造价。
- `ThreeKingdomsB6GainSkillTests`、`ThreeKingdomsB6NativeGainTests`：景略与既有技能／原生牌流的交叉边界。
- `ThreeKingdomsB6SessionTests`：正常54将包、产品AI、默认胜利目标的20场完整局；逐命令不变量及Save/Load重放。
- `ThreeKingdomsB6RoomTests`：四配置开局、独立选将、包校验、授权代操、重连与命令幂等。

测试夹具与正常完整局分别记录。已有包的完整局不因新增B6自动重复全部执行；原模式按本轮触及范围进行回归。Windows实际程序与Android构建证据另列，未执行的真机和用户试玩不记通过。
