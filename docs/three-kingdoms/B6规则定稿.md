# 三国争霸 B6 规则合同

日期：2026-10-26（Asia/Shanghai）。规则身份 `three-kingdoms-b6-v1`，武将包 `three-kingdoms-special-54-v1`。游戏版本保持内测版2.0.2。本轮在 B5 与 B4.5 直接交互基线上补齐貂蝉、麹义、鲁肃、司马师、钟会五将十技能，正常包共54将97技能。

## 来源与适用范围

依据[扩展实现方案](../三国争霸扩展实现方案.md)和[游戏百科](../三国争霸游戏百科.md) G17–G19、W04、W46–W48、W50 的牌文及建议实施。本文件与三个模块规范将本轮涉及的建议固定为版本化工程合同，不表述为用户曾逐项确认；百科原始牌文和答复保留。

基础交易、建造与强盗分别参照 `catan-base-2025-en.pdf` PDF 第6–8页；骑士、科技和入侵参照 `catan-cities-knights-2025-en.pdf` PDF 第3、8–12页；船与港口参照 `catan-seafarers-2025-en.pdf` PDF 第2–3页。来源文件及指纹见[本地规则索引](../../assets/references/rules/README.md)。下列技能覆盖属于本项目自定义玩法。

新局默认使用 B6 完整包，沿用 B4.5 的主动技能自主发动、手牌／头像／棋盘直接选择和实际事件响应。B1、B2、B3、B4、B4.5、B5、B5直接交互包仍按原身份和哈希恢复，不将旧存档直接扩成54将。

## 貂蝉

惑心在任意真实回合开始前提供可放弃的响应，包括本人回合；每任一次，放弃不消耗，同一行动机会不重复询问。确认后貂蝉玩家代操目标的完整回合，包含掷骰、手牌支付、发展牌、暗将、候选选将、换将和待决响应。目标回合所有者、资源、棋子、分数与账户均不改变，只转移当前操作权限。

操作者可以阅读该目标在授权期内本可见的私密信息；被操控玩家仍可阅读自己的资料，但不能提交自己的行动。旁观席位不获得目标手牌、暗将和私密候选。操作者自己的真实响应仍由本人作答，视图优先展示这些待决，处理后恢复目标视图。

授权持续至回合全部结束结算及容量弃牌完成，再在实际交接行动机会时撤销；结束阶段的选牌不会提前交回。提前隐退不终止已建立的整回合授权。游戏结束或新行动机会开始时清理残余授权。保存与重放保留来源任次、目标、操作者和行动机会。

涉及被代操资产的自愿玩家交易、主动赠予要求双方总张数相等，资源与商品合计，允许2换2。银行贸易按普通比例，伏骑、智盟等强制技能移牌不作为自愿交易。联盟禁贸、禁失牌和景略禁获等限制仍须满足。

闭月只在貂蝉本人拥有的回合结束事件获得两张自选资源，不能取商品。操控其他人的回合不会额外触发闭月。选择受真实银行库存及禁获限制；库存不足取可得数量，全部无牌时直接结束，不制造空待决。

## 联机与验收边界

网络命令的 `PlayerId` 是实际提交席位，`ActingAsPlayerId` 是本次操作的资产席位；服务器先按账户验证真实席位，再按当前授权、窗口与待决验证资产操作。客户端填入代理字段不产生授权。重复命令沿既有幂等合同返回原结果，新的过期代理命令被拒绝。

代操中断线仍沿用原房间合同：本回合由 AI 按现有授权继续，重连不抢回已接管的本回合；下一允许边界按实际回合操作者交回。临时响应玩家不改变这一回合归属判断。

本轮工程验收覆盖规则、私密投影、原生宿主、保存重放、正常完整局和开发客户端。完整像素交互、Android真机、四人外网及用户试玩单独登记在 B7，不能以自动检查替代。实际执行证据见[B6验收记录](../verification/three-kingdoms-b6/验收记录.md)。
