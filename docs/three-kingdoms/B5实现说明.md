# 三国争霸 B5 实现说明

本轮在两个规则宿主中加入棋盘状态能力，不把 Unity、网络或动画引入规则核心。[规则合同](B5规则定稿.md)规定含义，[验收记录](../verification/three-kingdoms-b5/验收记录.md)记录实际证据。

| 层 | 实现与用途 |
| --- | --- |
| 版本与生命周期 | `GeneralCatalog` 独立49将列表、版本及内容哈希；B5复用B4自动生命周期；关羽、华雄、庞统退出保留留置身份。 |
| 棋盘接口 | `IThreeKingdomsB5Host` 枚举合法对象及完整用途，`B5BoardState` 保存损害、实付、科技扣置、永久效果、入侵和延后操作。M4／M5各自适配原生实体与规则。 |
| 技能队列 | `B5MilitarySkillEngine` 与 `B5Civil*` 扩展既有B2帧及目标／费用／牌流事件；比大小挂起原队列后恢复，复制链保留根事件。 |
| 原生接入 | 建设、产出、连通、分数、发展牌、强盗／海盗与入侵按B5版本接入。旧包保留原分支，发展牌容量按玩家效果计算。 |
| 产品与联机 | 新局默认B5；客户端及房间核对成对的版本／哈希，同时支持旧B4。沿用独立选将令牌、恢复及重复命令处理。 |
| 界面 | 现有棋子的姿态表达横置与倒塌，公开状态列出损害及有效骑士等级，合法动作提供修复；沿用资源牌面的支付与选牌。手牌展示读取已过滤的投影。 |

Unity显示组件只在投影刷新时恢复并重设损害姿态，不创建新的棋子模型、不以每帧扫描替代规则状态。新增公开棋盘数据只发送损害及等级差异。AI使用同一合法动作集合；通用完整局验证不会绕过阶段、选将、供应或费用。

AI试算中的B5状态使用逐字段深拷贝，覆盖嵌套帧、数组、实体用途和虚拟牌，避免反复JSON往返；等价性与可变引用独立性单独检查。虚拟牌合法性试算保留限制和库存，只在副本内暂停推进当前技能队列，防止疑城枚举带费起重机时递归进入同一帧；该暂停标记不入存档，实际支付照常触发响应。原生外交与海盗要塞移除棋子时同步清除损害和实付记录。

B5专项覆盖独立技能及两个真实宿主；正常包完整局覆盖城市骑士与九张组合地图，各三／四人；房间专项覆盖包不匹配拒绝、同时提交、重复提交、保存及重连恢复。自动测试、客户端构建、实际界面、真机和外网多人证据分别记录，不互相替代。
