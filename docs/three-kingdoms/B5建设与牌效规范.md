## 武将合同

| 周瑜 | 每个实际回合的全局摸牌阶段均触发英姿，含普通产出为零：自选一资源或商品，再随机一资源；禁摸优先。反间每个自己的出牌阶段一次，先由其他目标声明八类真实手牌之一，再随机给出自己一手牌并公开；猜错由周瑜选择目标一道路，开放移除、封闭横置。无道路仍完成赠牌并消费次数。 |
| 贾诩 | 帷幕阻止蓝色发展牌对自己或资产的直接部分，包含有利效果，不撤销使用者对其他对象的效果。隐退后保留一次可选残留，放弃不消费，无有效部分不询问。乱武每任限定一次，按下家起锁定其他人的次序；各人支付完整两砖，或由贾诩处理其一道路，缺路处罚为空。间书每任限定一次指定两个不同他人，各在其下一实际摸牌开始暗选非空手牌、声明矿石数、由另一人猜真假并公开；猜中者胜，否则声明者胜。按原文由败者随机弃胜者一手牌，败者本回合禁摸。两次延时分别消费，源将隐退不取消。 |
| 黄盖 | 苦肉自己出牌阶段不限次；可拆己方村、路、船、墙、城市升级层或一项科技最高层，不含骑士。按该层历史实付资源／商品张数自选领取，初始与免费层为零，折扣取实付。城市降正常村不留黄忠损坏；附带城墙返供应但不计退款。大都会无迁移城市时不能选择。 |
| 吴甘宁 | 奇袭所有选项共享本出牌阶段三次，只选其他玩家：一砖随机弃一手牌、两砖随机弃一未使用发展牌；公开一分牌不在其中。拆设施支付该轨实际等级数量的砖，降一层，临时扣置不降低费用。费用原子提交后再处理目标响应与效果。 |
| 董卓 | 崩坏只在自己回合结束时检查权威总分；不是唯一最高即可选择任意玩家（含自己）一道路处理。自己回合保留全桌摸牌阶段，仅董卓不领取该阶段产出及增量。其他人摸牌开始前快照手牌和总分，任一为唯一最少即可横征：放弃自己整个本阶段主分配，随机取得每名其他玩家各一手牌；空手、免疫或禁止失牌者不产生虚构牌流。 |

| 李儒 | 焚城每任一次，选择任意席为起点并锁定正常方向完整一圈，含自己。每人选弃严格多于上位本分支实际弃牌数的手牌（至少一），或完整处理两条不同道路，否则选自己的合法城市整座焚毁。上位未弃牌则下位门槛回到一。城市连墙移除，不留村或残骸；大都会必须先能迁移。对象不足不制造债务。绝策只在自己回合末可选发动，锁定全部零手牌者，由各人自选道路或未使用发展牌及具体对象，没有可执行对象则跳过。 |

## 共有状态与恢复

破军的数量倍增按每个实际受作用目标单独计算。锻铁匠的两个不同骑士上限翻为四个，每枚仍只晋升一层、每回合至多晋升一次，并受政治科技与真实供应限制；结算按原等级从高到低处理，释放低一等级所需库存，不因点击顺序造成同一组选项一会可用一会不可用。商港对每位目标的一次交换额度按该目标倍数变为一或两次，打牌主体时锁定并保存；每次独立交一资源、收一商品，费用不倍增，不够交费可结束回合，剩余额度随本回合结束清除。枚举与虚拟用牌遵循同一额度和实体限制。

建设与损害使用稳定 Tile／Vertex／Edge 身份。原生和免费建造分别保存实际支付层；免费不会写入标准价格退款。倒塌村仍占位但不生产、不计分；横置路／船仍占边但不参与连通。黄忠城市降村保存待修城市层，修复恢复城市但不免费恢复原城墙。开放路和死亡骑士回供应，不留可修实体。黄忠损坏的同类建筑必须先修复，再允许该资产主人普通或免费新建；他人的建造不受此记录阻止。

结姻、先辅、间书、帷幕残留、永久分、除痂、科技扣置、技能计数及烈弓类别均入权威存档。技能帧保存所有者、当前决策者、原事件、所选牌、目标、预算与步骤，恢复不重新抽样或重新支付。私密子集只随有权者的选择投影；公共历史只记录公开的声明结果、数量和棋盘变化。关系根事件与每次实际动作事件分离，既阻止同一关系循环，也保留其他关系与独立动作的合法响应。

虚拟用牌用途及支付后的合法性只在隔离副本试算。副本保留真实队列、库存和持续限制供校验，内部暂停推进技能帧，避免支付试算重新进入正在选择用途的疑城等技能；暂停标记仅随内存副本复制，不进入存档或投影。真实执行没有此标记，费用和失牌引发的实际响应照常结算。
