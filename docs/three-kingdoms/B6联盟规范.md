# B6 钟会联盟与共享规则

2026-10-26，规则身份 `three-kingdoms-b6-v1`。本模块采纳[游戏百科](../三国争霸游戏百科.md) G17／W50 的建议细则作为版本化工程合同；不将工程选择表述为用户逐项确认。普通骑士和科技能力以 `catan-cities-knights-2025-en.pdf` PDF 第3、9–11页为基础，海上骑士以第12页和 `catan-seafarers-2025-en.pdf` PDF 第2–3页为基础；文件索引见[本地规则索引](../../assets/references/rules/README.md)。联盟为本项目三国覆盖规则。

自立和排异作为同一登场事件的两个技能，由玩家选择先后。自立从钟会下家开始询问，每名其他玩家可请求结盟或宣战；钟会可同意、拒绝，或提出一次即时资源／商品转让条件。条件可要求对方向钟会转让，也可由钟会赠予对方，逐张选定具体牌种数量，由申请者确认。条件确认前不转移牌、不公开申请者库存；确认时同时重验人数、真实库存及得失牌禁令，条件不可执行时只能拒绝，不发生部分支付。

结盟的即时单向转让也受惑心的等量交易限制：任一参与方处于代操期间时，不提供单向给牌或取牌条件；已提出的条件在确认时再校验。无条件结盟仍可执行。此处只应用代操限制，不因合并前双方属于不同阵营而阻止结盟。

联盟保存来源任次及成员连接。成员之间传递，合并后最多 `1 + floor(参局人数 / 2)` 人。满额及拒绝者为各自独立阵营，不因共同敌人自动结盟；任一来源存在时不同阵营不能自愿交易。来源武将隐退仅撤销自己的连接，其他来源不被拆掉，已经获得的牌和分数保留。

共享港口比例及各科技最高有效能力，包含事件骰抽牌、引水渠、商品2:1和政治三级晋级资格；个人设施、扣置量、大都会和分数仍归原主。共享骑士只有一枚实体，盟友在自己的合法行动窗口操作并支付费用，激活、晋级、行动记录仍附于实体，库存与入侵贡献归实体主人。移动使用联盟道路／船的连续网络；铁匠、驱海盗及战舰转换复用同一骑士授权。联盟解除后，失去合法网络的骑士由主人逐枚选择空顶点归位，无位置退回原主供应。

定向与群体负面技能对盟友不执行；有益修复、结姻与同阵营自愿转让保留。排异分别取蓝、黄牌库顶各一张，空库不造牌；对敌人的可数量化发展牌效果乘2，免疫先处理，不加倍费用、胜利点、期限。已有破军倍率继续相乘。

个人分数不相加。按原剧本胜利时机与门槛获得胜利的成员，使所属联盟共同获胜。城市骑士和海洋剧本均保存共同胜利名单，原生主获胜者继续保留，避免改变剧本的首获胜者和行动席位校验。

测试使用独立技能宿主及真实 M4／M5 会话，检查条件恢复、错误确认、隐藏库存、退场和重入、图连接、实体骑士费用与库存、科技与港口、群体负效、牌库与共享胜利。完整局、网络和界面证据由本轮总验收记录汇总，不以模块自动检查替代真机或用户试玩。
