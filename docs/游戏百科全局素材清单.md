# 游戏百科全局素材清单

范围为首页及「扩展与模式、地图玩法、武将图鉴、卡牌图鉴、棋子与规则」五栏。按玩家看到的素材计数；同一图片在多个词条出现只制作一次。链接指向实际文件。**已接入**指现有绘制代码使用该素材，**可复用**指已找到源文件，**待补**指仍需制作或打样。逐页实机验收目前覆盖首页、航海家、穿越沙漠、张辽和道路建设。

## 已确认的呈现方式

| 页面 | 左栏 | 右栏 | 复用原则 |
|---|---|---|---|
| 首页 | 本局公开棋盘取景 | 当前启用玩法 | 底部五个图鉴入口共用导航 |
| 扩展 | 玩法场景图 | 核心规则行配小图 | 帆船、港口等实物符号可用于关联入口 |
| 地图 | 对应人数的剧本图和区域引线 | 开局范围、特殊行动或计分 | 三人、四人分别核对指向 |
| 武将 | 仅正式立绘 | 姓名、势力、称号、技能；按需要配时机示例 | 同名武将按角色 ID 区分 |
| 卡牌 | 仅完整游戏卡面，含正式标题和描述 | 使用时机或操作示意 | 不复述牌效。插画使用百科原色材质，卡面文字按屏幕像素绘制 |
| 棋子与规则 | 单个棋子或相关组件 | 放置、移动或结算示例 | 道路用独立红木图标，多视图素材须先取单个视图 |

## 下一批可直接开工的素材

1. 第一批补「城市与骑士」「三国争霸」「海港与捕鱼」三个玩法的主图及各自的关键示意，沿用航海家详情模板。
2. 第二批补地图专属标注。先用现成的三人、四人底图定位落点，再制作迷雾探索、首次登岛等需要前后状态的图。
3. 第三批补棋子与规则详图。先复用正式棋子缩略图，优先处理港口计分、海盗封锁和骑士激活。武将与卡牌按具体结算需要补示例。

实机复核时，按当前开局可选配置核对四人「穿越沙漠」地图，并检查「海港与捕鱼」以一个模式入口显示。色彩以原贴图与 Unity 截图同一区域取样对照。已有样板与材质拆分见[首批素材清单](游戏百科素材清单.md)。
