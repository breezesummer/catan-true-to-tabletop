# 安卓与 PC 界面统一 v001

2026-10-15，按用户最新要求取消上一轮独立手机 UI，安卓直接使用 PC 的完整桌面界面。沿用卡坦岛之三国争霸内测版1.4，安卓 `versionCode` 从 10400 升至 10401；仍使用原包名和稳定内测签名，支持覆盖安装。本轮只重建并交付 APK，未请求微信发送。

## 界面与操作

- 安卓与 PC 共用开局菜单、桌面 HUD、左侧常驻建筑、逐张手牌、骰盘、四方席位、银行、玩家交易、三类城市设施、历史、分数详情、收牌动画与各扩展待决弹窗。不再保留另一套手机绘制代码。
- 所有共用控件沿用 PC 的逻辑尺寸、字号和布局；安全区只影响整体画布位置。地图与实体 HUD 相机使用同一个安全区，防止刘海区域造成模型和触点偏移。
- 触控保留单指平移、双指缩放、点选或拖放棋子、点骑士打开动作、点船改道以及历史／待决滚动。拖动滚动区不会触发经过的按钮。
- 点顶部正中回合铭牌打开与 PC 相同的游戏菜单，可保存、恢复、暂停 AI、切换视角、主题或新开局。Android 返回键仍先取消选择，再打开菜单。
- 当前规则、存档结构和 AI 策略不变。Android 继续使用已固定的移动渲染质量和打包中文字体；UI 共用不表示两端 GPU 阴影质量、系统字体光栅化完全相同。

## 构建与验证

构建根目录 `.local/m6-android-pc-ui-v001`。`Build-Android.ps1` 与 `Package-Android.ps1` 默认指向此目录，发行名称明确标注 PC 同版界面，以免误装旧 APK。

可重复入口：

```powershell
./tools/development/Build-Android.ps1
./tools/development/Package-Android.ps1
# 仅对开发模拟器开启双指事件注入权限；普通手机安装运行不需要此步骤。
& 'D:/Development/Android/Sdk/platform-tools/adb.exe' -s emulator-5554 root
./tools/validation/Test-AndroidTouch.ps1 -Mode Exercise
& 'D:/Development/Android/Sdk/platform-tools/adb.exe' -s emulator-5554 unroot
```

最终已运行结果和 APK 校验值见 [公开验证摘要](verification/android-pc-ui-v001/summary.json)。截图与权威验收存档只保存在本机 `.local`，不进入发行包。模拟器原有存档在触控验证前备份，验证后恢复；PC 默认存档另行检查保持不变。

相关 .NET 测试 203 项通过；最终 Unity Android 与 Windows 构建通过，PC 四类规则的独立保存／恢复通过。最终 APK 在 Android 15 模拟器的四模式运行检查 547 项、独立恢复检查 323 项通过，分别生成 27 张截图。模拟器实际触控验证通过 28 项断言、生成 12 张截图，覆盖菜单、移动缩放、建造取消与落子、存档恢复、手牌页签和两类交易。已抽查代表性的开局、完整桌面、资源手牌、交易、设施与菜单画面，修正银行及玩家交易标题和“海盗”标记的中文字形裁切。最终 APK 为 302,390,513 字节，发行副本与已验收 APK 的 SHA-256 一致；原模拟器存档及备份恢复并核对哈希，PC 原有两份存档未变。

真机整局、所有设备分辨率与长期性能仍需用户试玩；模拟器验证不能替代这些验收。M7/M8 阶段状态不变。
