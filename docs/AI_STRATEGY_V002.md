# AI 策略优化 v002

本轮按用户的四人双扩展打法建议优化本地启发式策略，重点是用较少资源尽快得分、前期保城，以及有回报的登岛路线。基础版与三人模式仍保留；没有改变胜利条件、卡牌、蛮族或成就规则。

## 行为与可观察结果

| 需求 | 实现方式 |
| --- | --- |
| 富裕初设 | 按骰点概率评价产出，优先让开局建筑覆盖至少一个 6 或 8；已有高频地块后补资源种类和骰点。没有合法高频位置时使用当前合法候选。 |
| 木羊与砖港流 | 航海开局羊、木权重最高，小麦和矿石次之；砖港必须有足够对应产出才有价值，避免只有港口没有砖。港口权重为砖、小麦、其他专港。 |
| 快速排水渠 | 城市与骑士第二处开局城市考虑木地产纸；科学三级按剩余生产时间估价，后期提高贸易的兑换价值。 |
| 得分先于囤料 | 对可立即获胜的建城、建村、登岛、夺大都会及部分卡牌和最长路线行动优先执行。其余动作比较确定性分数、剩余产出与建造成本。 |
| 登岛与回本 | 从已公开地块连接关系识别新区域；分别计算村庄与新区域奖励。每段路／船计两张牌、村庄计四张牌，额外绕行的未来产出须补偿成本。 |
| 比赛剩余时间 | 以约 100 次玩家回合为粗略先验，并根据公开领跑分和比赛节奏缩短；这是评分参数，不是强制终局或保证结束的回合。 |
| 骑士保城 | 按全岛城市数、活跃兵力、易受劫玩家最低兵力计算最低有效防御；缺激活麦子时避免继续囤闲置骑士。 |
| 保卫者与大都会 | 保卫者只在近期可低成本争取时考虑；设施区分可领取、可抢夺、防守与已被五级锁定的情况。 |
| 阻止领先者 | 强盗／海盗考虑公开产出、领先分、航线和己方损失；组合中已有连接点可进行低成本卡位。最长路线以末盘短距离争奖为主。 |

AI 仍只接收所属席位的 `PlayerView`，不读取权威会话、完整对手手牌、隐藏地图、牌库顺序或随机状态。相同视图保持确定性；返回指令仍通过人类玩家相同的规则入口验证。已有存档不新增策略状态。

## 与当前规则的差异

- 本仓库尚未启用海港大师。AI 会利用港口兑换及港口产出配套，但不会虚构海港大师分数。
- 当前蛮族轨道在第七次推进结算进攻；海盗阻航与蛮族劫城是不同机制。
- 四级大都会可能被他人的五级抢走；五级才锁定。未争得唯一最高兵力的并列保卫者按当前规则获得进步卡，不能当作必得一分。
- 新区域奖励按剧本处理，不能将所有剧本或每次重复登陆都视为额外两分。“穿越沙漠”按沙漠分隔区域判断。
- 城市与骑士／双扩展使用进步卡机制，不能照搬基础版不断购买发展卡的策略。

## 验证与限制

独立启动入口为 `tools/development/Play-AiStrategy.ps1`，程序目录为 `.local/m6-ai-v002`。重建使用 `tools/development/Build-M6.ps1 -OutputRoot .local/m6-ai-v002 -VerifyPlayer`。本轮在独立检出与独立分支验证、提交，保留并行界面工作的修改；不更新 M7／M8 进度。

独立固定局面用于检查战略选择，并通过真实执行入口验证关键动作、错误席位拒绝、输入不变和状态不变量。以 `a244e447` 为基线的独立检出已完成 **652/652 项测试**，包含 **59 项策略案例和 52 个正常完整 AI 局**；24,546 条指令合法，44～131 次玩家回合结束。最终测试耗时 6.77 分钟。Unity 6000.3.25f1 构建 31.0 秒、两个独立 Windows 保存／恢复进程 15.1／9.1 秒，均通过。证据见 [独立验收摘要](verification/ai-strategy-v002/isolated/summary.json)。

开发检查曾暴露无建筑局面漏报价和海盗群岛规划非法西岸落点导致卡局；均已修复并增加回归。两次中止的开发跑局与失败尝试不计入上述最终通过结果。

这仍是有限路径和公开局面评分，不是多回合博弈搜索。不能保证必定覆盖 6／8、登陆三个岛、夺取某项成就、阻断对手所有选择或按固定回合结束。船移动、进步卡组合、对手未来路线预测和多人交易仍存在策略质量空间；不把自动测试当作胜率提升证明或用户本人对战验收。
