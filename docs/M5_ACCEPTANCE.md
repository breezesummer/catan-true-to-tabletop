# M5 双扩展组合验收记录

2026-10-09（Asia/Shanghai），完成 M5 工程验收。路线图的两项退出条件均已满足：标为支持的四个组合均可本地启动并从正常开局到胜利；组合专项案例通过。当前入口为 `tools/development/Play-M5.ps1`，场景 `Unity/Catan/Assets/M5.unity`，Windows 程序 `.local/m5/Builds/Windows/CatanM5.exe`。

## 交付范围与来源

支持官方推荐的“驶向新海岸”“穿越沙漠”，各 3 人、4 人固定地图，胜利目标均为 16 分。船、海盗、金矿、异乡奖励与城市骑士的商品、改良、骑士、蛮族、25 种进步卡、城墙和大都会共同生效。其余七个航海剧本未开放组合，单扩展入口保留；不声称它们在规则上无法组合。具体范围见 [兼容表](M5_SCENARIOS.md)。

组合依据为已锁定的官方 2025 城市与骑士 PDF 第 12 页，配合航海家通用条款和官方 FAQ。原始 PDF 未改写；新增网页快照、访问日期、哈希和条款映射见 [组合规则](M5_COMBINATION_RULES.md)及 `assets/references/rules/m5-v001/sources.json`。旧 FAQ 名称只作一致条款的补充，执行名称与效果采用 2025 版。

规则独立于 Unity，所有席位通过 `Execute`，合法目标预览使用隔离的事务副本。权威保存格式 5，带规则/场景版本、场景指纹、待决和随机继续状态。公开视图、事件与本次公开证据不包含完整权威存档；特定卡牌依法授权的窥看仅向有权席位投影。架构见 [M5_ARCHITECTURE.md](M5_ARCHITECTURE.md)。

## 真实窗口检查

使用 computer-use 技能通过实际 Windows 窗口与鼠标/键盘检查，未直接调用测试辅助方法代替这些操作。默认窗口约 825×545，随后最大化为 2194×1234；以下以最大化窗口实测为准：

1. 驶向新海岸四人局启动显示 P2 交接遮罩；确认席位后显示本人开局面板。
2. 目标未选时按确认，显示“请选择有效顶点”，仍在开局建筑阶段。
3. Tab 切换俯视；先点目标按钮进入拾取，再点击沿海 `V1:5`，确认后出现定居点并计 1 分。
4. 选择“开局船”，通过目标按钮和棋盘点击选中 `EV1:5|V2:4`，确认后船可见，自动切换 P3 遮罩，私有面板消失。
5. 遮罩下点击保存、恢复，均显示成功；建筑与船保留，仍需 P3 确认席位。证据为 [恢复遮罩截图](verification/m5-2026-10-09/m5-ui-restored-curtain.jpg)。
6. 打开新局菜单，切换为穿越沙漠，确认兼容范围及 3/4 人按钮；实际启动三人局，显示正确地图、16 分目标及 P1/P2/P3 三席。见 [菜单](verification/m5-2026-10-09/m5-ui-scenario-menu.jpg)与[三人新局](verification/m5-2026-10-09/m5-ui-desert-three.jpg)。

URP 六图不包含 OnGUI，不能当作完整 UI 截图。真实窗口暴露的现有表现限制包括：拾取模式中大量稳定 ID 会互相重叠，地块号码/港口标签在部分角度与山体重叠；这些标签和基础网格尚不是最终界面与美术。实际顶点/边选择和确认可完成。未声称逐一人工操作所有进步卡、所有分辨率或用户本人完成四个整局。
