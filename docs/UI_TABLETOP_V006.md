本轮于 2026-10-13 北京时间 11:25 开始，根据五项界面反馈迭代 M6。旧 v005 程序、照片、模型、存档与证据继续保留；本轮不改变路线图阶段，不宣告 M7、M8 或用户视觉验收完成。

## 本轮行为

| 需求 | 实现 |
| --- | --- |
| 减少纯文字 | 去掉主菜单技术说明、备件常驻名称、卡面说明条；骑士身份与城市设施等级按需显示。保留回合、分数、资源数量、操作按钮与必要错误提示。 |
| 点击才抬起，完整干净卡面 | 鼠标经过手牌时位置、大小与叠放顺序不变；点击选中才上移。去除额外外框、上下亮线与覆盖卡面的文字条。手牌、预览、交易、历史缩略图统一完整卡面并保持宽高比。 |
| 骰子历史与统计 | 历史增加“掷骰”页，列出实际两骰及适用模式的事件骰；2–12 点统计次数与本局频率。分母为当前筛选记录中的投掷次数；无样本显示“—”，不将实测频率称为理论概率。 |
| 重新规划银行与收牌 | 中央保留棋盘；对手备件收紧到上方和两侧上半区；左侧银行每类资源／商品各自成摞排列，发展卡或三类进步卡背面朝上；左下历史、下方个人备件、右下设施与骰子分别留出空间。收获、银行交易等产生资源净流入后，从对应银行牌堆飞入玩家手中；对手收牌最后转为牌背。 |
| 全体交易快捷按钮 | 玩家交易页增加“向所有玩家报价”。同一份报价对所有其他玩家开放；首位接受者成交一次。拒绝只移除自己的回应资格，全部拒绝则结束；发起者可撤回。 |

银行资源／商品使用已有原照卡面。发展牌背没有原照，当前用简洁的深青色菱形程序图案占位；扩展模式沿用三类进步牌原背面。进步牌堆只表示种类，不编造公开视图没有提供的剩余张数。原照片本身的拍摄质量和外部圆角背景仍保留，没有用重绘替换用户原件。完整宽高比并不表示所有重叠手牌会同时无遮挡；超量手牌仍保持原尺寸重叠摆放。

## 权限与保存

收牌时间轴只读取当前人类席位获准的历史：公开资源净增加表示银行付出，玩家互换和垄断的同类资源净变化为零；私密偷取、弃牌和报价不伪装为银行发牌。首次进入或恢复对局只建立基线，不重播全部历史。权威结算先完成，显示动画不修改资源、不决定骰点，也不影响存档。

四套规则的广播交易仍经同一 Execute 入口。报价保存明确接收席位和已拒绝席位，并重新校验接受者的实际资源；重复或过期指令不会再次扣费。新增字段对既有定向报价保持可选，旧存档仍可回放。公开视图中没有新增对手完整手牌、牌库顺序、随机状态。

本轮在隔离分支 `codex/tabletop-ui-v006` 的独立工作区中验证。同期另一个聊天正在优化 AI 策略；此交付保留 v005 的策略基线，AI 只调整广播回应入口，不将另一任务的策略优化纳入本轮结果。

## 布局与来源

布局使用 1440×900 逻辑坐标，实际窗口按已有方式缩放。本人手牌保持屏幕坐标，公共牌堆、组件与设施使用桌面世界坐标。牌堆使用现有薄卡网格，每张厚度 0.36 mm、叠放间隔 0.38 mm，均为工作估算。来源与复现参数见 [v006 配方](../art/recipes/ui-tabletop-v006/recipe.json)；本轮没有新增 AI 位图或声称生成新的收藏版三维资产。

布局收尾将银行库存数字移到卡面外，采用更紧凑的骰子排列；飞牌按目标手牌矩形的大小与位置落入手中，避免终点卡片尺寸与手牌不一致。
