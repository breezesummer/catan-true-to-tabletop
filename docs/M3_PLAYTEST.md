# M3 航海家本地试玩

在仓库根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\development\Play-M3.ps1
```

Windows 程序为 `.local/m3/Builds/Windows/CatanM3.exe`。需要重建时运行 `Build-M3.ps1 -VerifyPlayer`；验证进程在后台隐藏运行，自动生成棋盘相机截图。`-CaptureUI` 可额外尝试完整界面截图，但隐藏窗口可能没有界面像素，验证器会明确报错，不能将黑图作为界面证据。程序旁的 Data、Mono 与 Unity 运行库须完整保留。M2 的场景、构建目录与启动入口独立保留。

## 开局与基本操作

默认进入 4 人「驶向新海岸」。点击「新开一局」选择 9 个剧本之一，再以 3 人或 4 人开始。剧本选择页显示对应说明与胜利条件；海盗岛须夺回自己的堡垒，卡坦奇观可建成 4 层直接获胜，或至少 10 分且层数领先所有对手。原局面不会自动保存。

确认「我是 P…」才显示该席位手牌。开局先放定居点，然后放与其相连的道路或船。最后一轮起始建筑领取相邻地块资源；剧本可规定不同的开局条件。绿色标记为当前可用目标，所有落点仍由规则核心检查。非法操作不改变局面。

鼠标点击拿起的棋子落下；右键或 Esc 取消。Tab 切换斜视和俯视，滚轮缩放。「地形显隐」可以隐藏立体山体，「隐藏提示」腾出更多棋盘空间。顶部显示当前剧本、目标分数，侧栏显示道路、船、村、城市余件。

基础版的掷骰、建村、升级城市、交易、发展卡、弃牌与隐私换座沿用 [M2 操作方式](M2_PLAYTEST.md)。航海家剧本的计分与特殊规则以核心规则及本阶段规则清单为准。

## 船、海盗与金矿

「航海」页提供建船和移动船。船消耗木材与羊毛各 1；可在合法海边延伸航线。道路与船只有通过己方定居点或城市才能连接为同一条航线。

移动船时先点选绿色标记的源船，再选目标边。每回合至多移动一艘，不能移动本回合新建的船；封闭航线及海盗封锁等限制由核心检查。取消操作不会移动或消耗棋子。道路建设发展卡可混合免费道路与免费船。

掷出 7 或使用骑士后，面板提供移动强盗、移动海盗与移到外框海域的按钮。强盗须去合法陆地；海盗须去合法海域。随后选择对手偷取资源；布匹剧本在符合条件时还可选择偷布匹。海盗岛的舰队移动和骑士作用有剧本专用规则，不能当作普通海盗规则使用。

金矿触发「金矿选择」面板。按提示数量，用加减按钮选择银行现有资源并确认。多人受益时自动提示依次换座，领取完成后回到原阶段。金矿不是第六种资源卡。

## 剧本操作与棋盘标记

- 雾岛：未揭示地块显示「迷雾」，只有经规则允许探索后才显示真实地形与数字。
- 遗忘部落：棋盘的星号、礼物和港口礼物标记可通过航线触及。获赠港口后，选择港口并点击连接己方沿岸建筑的合法边安置。
- 卡坦布匹：中立村显示数字及剩余布匹；航海页显示己方布匹和额外胜利点。布匹是公开剧本组件。
- 海盗岛：己方堡垒显示剩余强度；航海页提供「攻击己方海盗堡垒」。西行船尚未离开起始岛时可用「选择西行进攻航线的起点」改选合法己方沿岸建筑，开始西行后锁定。军舰以桅杆顶端深色圆旗区别普通船。核心处理攻击、损失和结束回合等结果。
- 卡坦奇观：航海页循环选择奇观，认领或建造一层；地图显示相应奇观顶点。建造仍需满足资源与认领条件。
- 新世界：正常放村前，先由各席位轮流安置当前翻开的港口。点击「安置当前港口」后选择合法海岸边；港口全部摆放后进入正常开局。

## 保存、恢复与验证边界

任意阶段可保存，包括金矿选择、船行动之前、待移动海盗、偷取与港口安置。读取成功后要求重新确认当前决策席位；读取失败保留当前局面。

M3 存档格式版本为 `3`，文件为 Unity `persistentDataPath` 下的 `m3-authority-v3.json`，通常位于 `%USERPROFILE%\AppData\LocalLow\CatanDevelopment\Catan M3\`。替换前保留 `.bak`。该文件包含恢复所需的完整权威信息，只供本地主持端使用，不能作为玩家网络数据或公开日志。M1、M2 使用各自入口和格式。

运行时验证器只在显式传入 `--m3-verify-save`、`--m3-verify-load` 等测试参数时启用。它使用 PlayerView 决定操作并通过同一命令入口提交；权威文件仅用来验证保存恢复，不进入画面或公开日志。实际已运行的结果应以 M3 验收记录为准；这些自动检查不能替代用户的整局试玩和美术确认。

## 可辨识组件与素材来源

M3 的船、军舰旗、海盗以及海洋、金矿、迷雾地块是 `M3BoardRenderer.cs` 在运行时构造的 v001 基础网格，实际可渲染，不是生成位图或最终收藏版模型。船使用立方体船体、桅杆与帆，长度估算 24 mm，枢轴为航线边的中点；海面基准为 8 mm。所有尺寸仍属 M0 允许的估算，没有实物测量确认。

资源来自项目脚本，无新增外部图片、模型或生成图。重建脚本与固定 Unity 工程即可复现网格；无二进制源资产或人工导出步骤。矿山沿用已有 `mountain-tile-v001` 样板及其原追溯记录。地形装饰不参与合法性判定，拾取按稳定 Tile / Vertex / Edge ID 对齐。
