2026-10-14 按本轮截图和布局要求调整 M6，发行名称为“卡坦岛之三国争霸内测版1.1”。继续使用当前优化 AI。本轮只修改显示、输入和发行流程，不改变游戏规则，也不推进 M7/M8 阶段。

## 布局与操作

- 棋盘恢复为画面中央的主体。删除中央地图纹理合成与固定分区裁剪，棋盘、银行、备件、城市设施、骰子及蛮族轨道由同一相机绘制。
- 桌上实体使用固定基准坐标，滚轮改变共同相机；缩放不改变棋子和卡板的世界坐标或尺寸。俯视保留实体摆放，展开桌面纵深。自己的手牌沿用屏幕底部的逐张选择和轻抬操作。
- 银行移到左上；玩家保留四方相对席位，左右手牌和备件按镜像位置摆放，上方手牌靠外、备件靠棋盘。自己的船横放，城墙分开放置；库存模型按实际网格底面贴桌和占地排布。
- 城市设施缩小到右下；骑士与特殊行动位于结束回合上方。蛮族轨道与航程、防御状态共处右上；历史框扩大覆盖左下。
- 删除常驻“桌边菜单”按钮。Esc 优先取消本地拿棋、选牌或关闭浮窗；无本地操作时打开居中菜单，再按 Esc 返回。菜单保留保存、恢复、切换俯视、AI 暂停/继续与新开对局。
