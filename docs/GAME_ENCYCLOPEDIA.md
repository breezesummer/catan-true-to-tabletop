# 游戏百科

本百科收录《卡坦岛之三国争霸》的发展卡名称、牌面描述及查阅入口。基础版、航海家、城市与骑士和组合模式中，卡牌类别统一使用“发展卡”；需要区分时使用“基础发展卡”和“绿色／黄色／蓝色发展卡”。

三国扩展的选将、寿命、轮换及54张武将牌另见[三国争霸游戏百科](三国争霸游戏百科.md)；工程实施与验收安排见[三国争霸扩展实现方案](三国争霸扩展实现方案.md)。两份文档目前为讨论稿，尚未接入游戏内百科。

## 查阅入口与文字约定

游戏中按 Esc，选择“游戏百科”，可查阅基础版／航海家与城市与骑士／组合两个分类。手牌、用牌面板和百科共用三色发展卡文字资料。

三色发展卡的题名与描述以用户提供的实体牌面为权威。游戏显示简体中文，保留牌面的词义、数量和条件；“发展牌”统一写作“发展卡”。牌面中的“村落”“麦”“铁”分别对应游戏界面的“村庄”“谷物／粮食／小麦”“矿石／铁矿”。括号与数字间距按中文阅读习惯整理。

以下每张三色卡均列出实体印刷题名和原始照片。来源为单张实体照片，PDF 页码不适用；原照片、原文件名和既有纹理不改动。例如照片文件名“新建道路”“锻铁匠”，实际印刷题名分别是“興建道路”“鍛冶匠”。

## 基础版与航海家发展卡

本地尚无这五类卡的实体正面照片，以下保留现有游戏名称与操作说明，不列为实体牌面转录。获得实体卡资料后再以对应牌面替换。

| 现有名称 | 现有游戏说明 |
| --- | --- |
| 骑士 | 移动强盗并向相邻的一名对手随机拿取一张资源；航海家可选择移动海盗。 |
| 道路建设 | 免费建设两段道路；航海家可选择道路或船，逐段选择合法位置。 |
| 丰收 | 从银行领取两张资源，可选同一种；受银行剩余资源限制。 |
| 垄断 | 选择一种资源，所有对手将该种资源全部交给你。 |
| 胜利点 | 持有即计 1 分；在自己回合达到胜利条件时公开。 |

基础发展卡新买入的当回合不能使用，每回合最多使用一张；胜利点卡按现有胜利结算处理。

## 城市与骑士及组合发展卡

以下为三色发展卡的实体牌面描述，适用于城市与骑士及其与航海家的组合。绿色为科学，黄色为贸易，蓝色为政治。英文标识仅用于与已有存档、卡面资产对应，不改变卡牌身份。

### 绿色发展卡 科学

#### 炼金术士

在你掷骰前打出，你操控两颗数字骰子的结果，然后掷出事件骰并如常结算。

实体题名：煉金術士。来源：[实体照片](../assets/references/inbox/发展卡/绿色发展卡/炼金术士.jpg)。稳定标识：`Alchemy`。

#### 起重机

本回合中你有一次建设城市设施时可少支付1张商品牌。

实体题名：起重機。来源：[实体照片](../assets/references/inbox/发展卡/绿色发展卡/起重机.jpg)。稳定标识：`Crane`。

#### 工程师

免费兴建1道城墙。

实体题名：工程師。来源：[实体照片](../assets/references/inbox/发展卡/绿色发展卡/工程师.jpg)。稳定标识：`Engineering`。

#### 发明家

交换2枚数字圆片，但不得选择2、6、8、12号。

实体题名：發明家。来源：[实体照片](../assets/references/inbox/发展卡/绿色发展卡/发明家.jpg)。稳定标识：`Invention`。

#### 灌溉

点算版图上有你的村落或城市相邻的田野板块，每有一块你便获得2张麦。

实体题名：灌溉。来源：[实体照片](../assets/references/inbox/发展卡/绿色发展卡/灌溉.jpg)。稳定标识：`Irrigation`。

#### 药物

支付2张铁和1张麦，把你的一个村落升级为城市。

实体题名：藥物。来源：[实体照片](../assets/references/inbox/发展卡/绿色发展卡/药物.jpg)。稳定标识：`Medicine`。

#### 采矿

点算版图上有你的村落或城市相邻的高山板块，每有一块你便获得2张铁。

实体题名：採礦。来源：[实体照片](../assets/references/inbox/发展卡/绿色发展卡/采矿.jpg)。稳定标识：`Mining`。

#### 印刷厂

1分（必须即时打出）。

实体题名：印刷廠。来源：[实体照片](../assets/references/inbox/发展卡/绿色发展卡/印刷厂.jpg)。稳定标识：`Printing`。

#### 兴建道路

免费兴建2条道路（若游玩使用船只的扩充则可选择兴建2艘船或道路和船只各1）。

实体题名：興建道路。来源：[实体照片](../assets/references/inbox/发展卡/绿色发展卡/新建道路.jpg)。稳定标识：`RoadBuilding`。

#### 锻冶匠

免费升级你的2个骑士，但依然需要遵守城市设施的规则才可将骑士升级到三级。

实体题名：鍛冶匠。来源：[实体照片](../assets/references/inbox/发展卡/绿色发展卡/锻铁匠.jpg)。稳定标识：`Smithing`。

### 黄色发展卡 贸易

#### 商港

你可向每位其它玩家给予1张资源牌，收到的玩家必须给你1张商品牌；若他没有任何商品牌，则把该资源牌归还给你。

实体题名：商港。来源：[实体照片](../assets/references/inbox/发展卡/黄色发展卡/黄色商港.jpg)。稳定标识：`CommercialHarbor`。

#### 大商家

选择一名比你高分的玩家，查看他的全部资源及商品牌，从中偷取2张。

实体题名：大商家。来源：[实体照片](../assets/references/inbox/发展卡/黄色发展卡/大商家.jpg)。稳定标识：`GuildDues`。

#### 商人

把商人模型放到你的村落或城市旁1块板块上。只要模型还在上面，你便可用该地形的资源以2:1的优惠比率贸易。

实体题名：商人。来源：[实体照片](../assets/references/inbox/发展卡/黄色发展卡/黄色商人.jpg)。稳定标识：`Merchant`。

#### 贸易船队

你指定一款资源或商品，本回合中你可用它以2:1的优惠比率贸易。

实体题名：貿易船隊。来源：[实体照片](../assets/references/inbox/发展卡/黄色发展卡/黄色贸易船队.jpg)。稳定标识：`MerchantFleet`。

#### 垄断资源

宣告1种资源。所有其他玩家必须给你2张该种资源牌。

实体题名：壟斷資源。来源：[实体照片](../assets/references/inbox/发展卡/黄色发展卡/垄断资源.jpg)。稳定标识：`ResourceMonopoly`。

#### 垄断商品

宣告1种商品。所有其他玩家必须给你1张该种商品牌。

实体题名：壟斷商品。来源：[实体照片](../assets/references/inbox/发展卡/黄色发展卡/垄断商品.jpg)。稳定标识：`TradeMonopoly`。

### 蓝色发展卡 政治

#### 外交官

你可移除任何一条开放道路（即任何一端没有连接同颜色配件的道路）。若你选择移除自己的道路，可立即重新兴建它。

实体题名：外交官。来源：[实体照片](../assets/references/inbox/发展卡/蓝色发展卡/外交官.jpg)。稳定标识：`Diplomacy`。

#### 间谍

查看另一位玩家的全部发展卡，从中偷取1张。

实体题名：間諜。来源：[实体照片](../assets/references/inbox/发展卡/蓝色发展卡/间谍.jpg)。稳定标识：`Espionage`。

#### 指挥官

立即免费激活你的全部骑士。

实体题名：指揮官。来源：[实体照片](../assets/references/inbox/发展卡/蓝色发展卡/指挥官.jpg)。稳定标识：`Encouragement`。

#### 权谋

驱逐其它玩家1个连接到你的道路（或船只）的骑士，把它移动到另一个符合规则的位置。

实体题名：權謀。来源：[实体照片](../assets/references/inbox/发展卡/蓝色发展卡/权谋.jpg)。稳定标识：`Intrigue`。

#### 主教

移动强盗。然后按照强盗所在的新板块，从相邻村落或城市的每位主人手中随机偷取1张资源或商品牌。

实体题名：主教。来源：[实体照片](../assets/references/inbox/发展卡/蓝色发展卡/主教.jpg)。稳定标识：`Taxation`。

#### 石碑

1分（必须即时打出）。

实体题名：石碑。来源：[实体照片](../assets/references/inbox/发展卡/蓝色发展卡/石碑.jpg)。稳定标识：`Constitution`。

#### 叛徒

指定另一位玩家，他选择移除自己1个骑士，然后你获得1个同等级的骑士（它保持被移除前激活与否的状态）。

实体题名：叛徒。来源：[实体照片](../assets/references/inbox/发展卡/蓝色发展卡/叛徒.jpg)。稳定标识：`Treason`。

#### 婚礼

每名比你高分的玩家都要选择给你资源牌及商品牌共2张。

实体题名：婚禮。来源：[实体照片](../assets/references/inbox/发展卡/蓝色发展卡/婚礼.jpg)。稳定标识：`Wedding`。

#### 破坏者

每名比你高分或同分的玩家选择并弃掉一半手牌（向下取整）。

实体题名：破壞者。来源：[实体照片](../assets/references/inbox/发展卡/蓝色发展卡/破坏者.jpg)。稳定标识：`Sabotage`。

## 游戏操作补充

三色发展卡通常在自己回合的行动阶段使用；炼金术士在掷骰前使用。印刷厂和石碑须即时公开，各计 1 分。普通三色发展卡的手牌上限为四张，只有超过上限时才进入弃置处理。卡牌的显示与动画不改变权威结算，查阅百科不会揭示其他玩家的隐藏手牌。

这些操作补充用于理解当前游戏流程，与上文实体牌面描述分别维护。本轮调整名称和描述，未变更卡效裁决；牌面转录不代表现有实现已逐项通过实体规则验收。
