# 卡坦岛之三国争霸内测版1.3

2026-10-15，按用户“向微信推送一个新版本包”的请求，将发行版本由内测版1.2 自动迭代到内测版1.3。工程界面批次仍为 v011，不增加规则或 AI 功能，M7／M8 阶段状态不变。

## 交付内容

- 程序：[CatanM6.exe](../.local/m6-release-1.3/Builds/Windows/CatanM6.exe)。两个启动脚本与默认构建、打包目录统一指向 1.3。
- 微信分享包：[卡坦岛之三国争霸内测版1.3.zip](../.local/m6-release-1.3/release/卡坦岛之三国争霸内测版1.3.zip)。Windows 64 位，完整解压后双击包内 `CatanM6.exe`，保留同目录全部运行文件。
- 启动界面、Esc 菜单与 Unity 产品版本均为 1.3；规则版本、权威存档格式、存档位置和当前 AI 策略沿用。

本包包含 [v011](UI_STRATEGY_V011.md) 的相机连续倾角、紧凑建筑栏与独立数量、金属手牌控件、独立设施、交易资源筛选、最长道路展示、顶部回合铭牌及 Esc 菜单调整。此前修复的地图随机化、真实港口与标记也沿用。

## 发布验证

本轮复验范围为界面相关 88 项 .NET 测试、当前源码的 .NET Standard 2.1 构建、Unity 6000.3.25f1 Windows 构建、四模式独立进程保存／恢复，以及发行包完整性和独立解压运行检查。实际结果记录于 [发布摘要](verification/release-beta-1.3/summary.json)。

v011 既有去重 815 项检查（含 52 个完整 AI 局）、28 配置无图形／图形检查属于继承基线，本次不记为全量重跑。用户本人完整对局、完整港口／骑士／移船鼠标链、全部分辨率及长期性能仍待验。
