# M6 单人 AI 试玩

启动已构建程序：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\development\Play-M6.ps1
```

首次构建或修改代码后：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\development\Build-M6.ps1 -VerifyPlayer
```

工程场景是 `Unity/Catan/Assets/M6.unity`，当前程序是 `.local/m6-ui-v004/Builds/Windows/CatanM6.exe`。M6 的四种规则模式使用桌面与实体摆放 v004；旧 M2–M5 启动脚本、本地多人换座版本及各自旧 UI 继续保留，旧 M6 程序也保留。

本轮已在城市与骑士窗口实际用鼠标完成开局建筑／道路拿放、掷骰、缩放、俯视，以及完整建设卡内部小翻板升级。全部分辨率和用户整局手感尚未逐一验收，具体证据见 [桌面与实体摆放 v004](UI_TABLETOP_V004.md)。

## 开始对局

1. 选择基础版、航海家、城市与骑士或双扩展组合。
2. 航海家可选择已交付的九个剧本；组合可选择驶向新海岸或穿越沙漠。
3. 选择 3 人或 4 人，以及自己控制的 P1–P3/P4。其余 2–3 个席位由本地 AI 控制。
4. 点击“开始对局”。AI 自动完成它们的开局和行动；轮到你时拿起面前的一枚棋子并点击合法位置，复杂选择通过临时纸片完成。

所有 AI 均在本机执行，无需在线模型、API 密钥或网络服务。当前只有一种启发式策略，强度和主要局限见 [策略说明](M6_STRATEGY.md)。

## 操作和等待

中央上方显示当前回合、行动席位和阶段。操作提示使用屏幕中央的大红字，每条 1.5 秒；正常本人回合依次提示“你的回合”“请掷骰”。底部始终只显示本人手牌，其他玩家只有公开备件、牌背与数量。收到 AI 交易报价时在交换盘响应；轮到本人弃牌或进行扩展选择时，完成当前待决后 AI 才会继续。

面前手牌完整横排，只有一类时整体居中；两类都有时发展／进步牌在左，资源／商品在右，超过可见容量可翻页或在手牌区域滚轮换页。手牌上方排列本人备件与余量，城市设施在右。卡片、棋子、银行牌堆和骰子均摆在三维桌面上，随地图一起缩放。悬停组件只显示一行资源名称，缺少的份数标红。点击可用棋子时只拿起这一枚并抽出所需手牌；先选择资源也可查看对应的可建项目名称。选择和费用预览不直接扣费。

点击发展卡或进步卡先阅读，再选择打出并通过临时纸片设置参数。城市设施为贸易、政治、科学三张完整建设卡，点击卡内下一等级的小翻板升级；成功后该小翻板显示已建面，跳级点击只提示当前应建等级。高级骑士用于晋升低一级骑士。开局与免费建设显示“免费”。棋盘上的己方骑士可展开动作，航海特殊行动在“航海日志”中选择；复杂待决使用按需展开的临时纸片。

直接点击桌上的骰子掷骰，无需额外按钮。基础／航海使用两颗，城市与骑士／组合的三颗骰子呈三角摆放，顶角为事件骰、左角红骰、右角白骰；转动停止后直接看顶面，事件为蛮族船或黄／蓝／绿城堡。行动阶段点击屏幕右下角“结束回合”。

点击左侧银行牌堆、可用港口或对手区域打开交换盘。银行交易选择付出种类、获得种类与份数，显示当前比例及银行库存；玩家交易配置双方数量，发送报价后等待接受或拒绝，也可撤回。对方完整手牌始终隐藏，确认时仍由规则入口校验。

右上角“桌边菜单”收纳保存、恢复、暂停／继续 AI、视角和新局入口。暂停不会代替你完成选择，菜单展开时暂停自动推进；只有明确开始新局才替换未保存局面。

Tab 切换视角，棋盘区域滚轮缩放。四种模式普通建造均为点击单枚棋子后点地图落下，也支持按住拖放。Esc、右键或“放回手中”取消草稿；提交或恢复后清除过期选择。手牌和弹窗点击不会穿透棋盘。各规则的详细说明见 [M2](M2_PLAYTEST.md)、[M3](M3_PLAYTEST.md)、[M4](M4_PLAYTEST.md)、[M5](M5_PLAYTEST.md)，其旧独立入口布局与当前 M6 有区别。

## 保存、恢复与问题定位

游戏内“保存”写入 Unity `Application.persistentDataPath` 下的 `m6-local-ai-v1.json`。存档含规则、场景、人类席位、暂停设置和权威局面，包括当前待决与随机继续状态。“恢复”或启动菜单的“读取 M6 存档”继续该局。

权威存档含私人游戏信息，不应作为公开截图或日志上传。无效版本或损坏内容会被拒绝，已在运行的局面应保留。AI 决策失败或命令被拒绝会显示暂停错误，不会以跳过回合隐藏问题；可保存现场以便复现。

## 试玩关注点

请重点观察：手牌横排、单枚拿取、整桌缩放、设施内部升级、三角骰子、桌面清晰度、费用缺料和中央提示，以及交易、扩展待决、暂停恢复和整局节奏。本轮使用既有实体网格、照片卡面和原生 8192×8192 橡木位图，最终美术仍待用户确认。M6 原阶段验证见 [验收记录](M6_ACCEPTANCE.md)，本轮验证见 [v004 说明](UI_TABLETOP_V004.md)，两者均不代替用户本人试玩。
