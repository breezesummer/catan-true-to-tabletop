# M6 单人 AI 试玩

启动已构建程序：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\development\Play-M6.ps1
```

首次构建或修改代码后：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\development\Build-M6.ps1 -VerifyPlayer
```

工程场景是 `Unity/Catan/Assets/M6.unity`，程序是 `.local/m6/Builds/Windows/CatanM6.exe`。M6 的四种规则模式使用本轮底部操作 UI；旧 M2–M5 启动脚本、本地多人换座版本及各自旧 UI 继续保留。

建议最大化窗口后操作。本轮新 UI 已人工查看双扩展组合普通窗口与最大化窗口；真实鼠标交互尚未可靠复验，较小窗口的完整布局也未逐一验收。具体证据与限制见 [操作 UI v001](UI_OPERATIONS_V001.md)。

## 开始对局

1. 选择基础版、航海家、城市与骑士或双扩展组合。
2. 航海家可选择已交付的九个剧本；组合可选择驶向新海岸或穿越沙漠。
3. 选择 3 人或 4 人，以及自己控制的 P1–P3/P4。其余 2–3 个席位由本地 AI 控制。
4. 点击“开始对局”。AI 自动完成它们的开局和行动；轮到你时点击底部组件或按右侧待决面板选择目标，依提示放置或确认。

所有 AI 均在本机执行，无需在线模型、API 密钥或网络服务。当前只有一种启发式策略，强度和主要局限见 [策略说明](M6_STRATEGY.md)。

## 操作和等待

左上角显示你控制的席位及 AI/人类等待状态。底部始终只显示本人手牌，不能通过点击 AI 席位查看其完整手牌。收到 AI 交易报价时在交换盘响应；轮到本人弃牌或进行扩展选择时，在右侧完成待决，AI 才会继续。

最下方左侧为发展卡或进步卡，右侧为资源和当前规则使用的商品。手牌上方左侧排列本人组件与余量，右侧为城市设施。点击组件会显示费用并自动抽出已持有的所需资源；也可以先点击资源手牌，查看高亮上浮的可建项目，再选择想建的组件。缺少资源仍可查看费用，缺少图标有暗色、红框、减号及数量提示，不会直接扣费。

点击发展卡或进步卡先阅读，再选择“使用 · 选择目标”，到右侧设置参数并确认。城市设施按所点轨道准备升级；高级骑士槽位用于晋升低一级骑士。开局组件及基础版 / 航海家的免费道路与船显示零资源费用；进步卡后续的免费建设仍从右侧待决完成。骑士激活与移动、航海特殊行动及其他多步选择仍在右侧操作栏内，必要时滚动查看。

点击底部“交易”打开交换盘。银行交易选择付出种类、获得种类与份数，自动显示当前港口和能力对应的比例以及银行库存；玩家交易选择对手和两侧数量，发送报价后等待接受或拒绝。发起方可以撤回自己的报价。对方完整手牌始终隐藏，确认时仍由规则入口校验。

“暂停 AI”停止自动推进，适合阅读棋盘或保存。它不会自动代替你完成任何选择；“继续 AI”恢复调度。打开规则菜单时也暂停自动推进，“返回当前局”继续当前配置；只有明确开始新局才替换未保存局面。

Tab 切换视角，棋盘区域滚轮缩放。基础版和航海家拿起组件后，在棋盘预览并单击落下；城市与骑士和组合模式选定棋盘目标后，在右侧确认。Esc、右键或“清空选择”取消当前草稿，提交或恢复后清除过期选择。手牌、侧栏及弹窗中的滚轮与点击不会穿透棋盘。各规则包的详细动作说明见 [M2](M2_PLAYTEST.md)、[M3](M3_PLAYTEST.md)、[M4](M4_PLAYTEST.md)、[M5](M5_PLAYTEST.md)，新 UI 与旧独立入口的区别见 [本轮操作说明](UI_OPERATIONS_V001.md)。

## 保存、恢复与问题定位

游戏内“保存”写入 Unity `Application.persistentDataPath` 下的 `m6-local-ai-v1.json`。存档含规则、场景、人类席位、暂停设置和权威局面，包括当前待决与随机继续状态。“恢复”或启动菜单的“读取 M6 存档”继续该局。

权威存档含私人游戏信息，不应作为公开截图或日志上传。无效版本或损坏内容会被拒绝，已在运行的局面应保留。AI 决策失败或命令被拒绝会显示暂停错误，不会以跳过回合隐藏问题；可保存现场以便复现。

## 试玩关注点

请重点观察：组件与手牌联动是否顺手、费用缺少态是否清楚、交易报价是否易懂，以及开局等待、本人待决、AI 交易、暂停恢复和整局节奏。本轮使用既有实体资产、照片卡面及网格缩略图，仍不代表收藏版成品美术已确认。M6 原阶段的自动完整局与窗口检查见 [验收记录](M6_ACCEPTANCE.md)，本轮新 UI 的验证见 [操作 UI v001](UI_OPERATIONS_V001.md)，两者均不代替用户本人试玩。
