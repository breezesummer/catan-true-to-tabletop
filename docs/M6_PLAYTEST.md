# M6 单人 AI 试玩

启动已构建程序：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\development\Play-M6.ps1
```

首次构建或修改代码后：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\development\Build-M6.ps1 -VerifyPlayer
```

工程场景是 `Unity/Catan/Assets/M6.unity`，程序是 `.local/m6/Builds/Windows/CatanM6.exe`。旧 M2–M5 启动脚本和本地多人换座版本继续保留。

建议最大化窗口后操作；本轮实际鼠标检查以最大化窗口为准，较小窗口的完整布局尚未逐一验收。

## 开始对局

1. 选择基础版、航海家、城市与骑士或双扩展组合。
2. 航海家可选择已交付的九个剧本；组合可选择驶向新海岸或穿越沙漠。
3. 选择 3 人或 4 人，以及自己控制的 P1–P3/P4。其余 2–3 个席位由本地 AI 控制。
4. 点击“开始对局”。AI 自动完成它们的开局和行动；轮到你时按右侧规则面板选择目标并确认。

所有 AI 均在本机执行，无需在线模型、API 密钥或网络服务。当前只有一种启发式策略，强度和主要局限见 [策略说明](M6_STRATEGY.md)。

## 操作和等待

左上角显示你控制的席位及 AI/人类等待状态。右侧始终是本人视图，不能通过点击 AI 席位查看其完整手牌。收到 AI 交易报价、轮到本人弃牌或进行扩展选择时，需要你完成右侧操作，AI 才会继续。

“暂停 AI”停止自动推进，适合阅读棋盘或保存。它不会自动代替你完成任何选择；“继续 AI”恢复调度。打开规则菜单时也暂停自动推进，“返回当前局”继续当前配置；只有明确开始新局才替换未保存局面。

沿用原阶段的棋盘操作：Tab 切换视角，滚轮缩放；选择顶点/边/地块字段后在棋盘点击，再在右侧确认。Esc 或右键取消当前拾取。各规则包的详细动作说明见 [M2](M2_PLAYTEST.md)、[M3](M3_PLAYTEST.md)、[M4](M4_PLAYTEST.md)、[M5](M5_PLAYTEST.md)。

## 保存、恢复与问题定位

游戏内“保存”写入 Unity `Application.persistentDataPath` 下的 `m6-local-ai-v1.json`。存档含规则、场景、人类席位、暂停设置和权威局面，包括当前待决与随机继续状态。“恢复”或启动菜单的“读取 M6 存档”继续该局。

权威存档含私人游戏信息，不应作为公开截图或日志上传。无效版本或损坏内容会被拒绝，已在运行的局面应保留。AI 决策失败或命令被拒绝会显示暂停错误，不会以跳过回合隐藏问题；可保存现场以便复现。

## 试玩关注点

请重点观察：开局等待是否清楚、是否容易分辨本人待决、AI 交易是否合理、暂停恢复是否符合预期，以及整局节奏。M6 复用已有网格占位和界面，不代表收藏版成品美术已确认。自动完整局与实际窗口检查见 [验收记录](M6_ACCEPTANCE.md)，不代替用户本人试玩。
