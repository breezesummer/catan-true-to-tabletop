# 田园菜单与交互音效 v001

日期：2026-10-16。游戏名称：卡坦岛之三国争霸；沿用内测版1.4。本次仅发送微信文字公告，未要求发布可玩压缩包，因此不递增版本号。

本轮按用户要求升级游戏外菜单并增加交互音效。与另一对话的游戏内动画、手牌及 AI 操作速度工作共用工程；只提交本轮新增文件和明确的接入改动。规则、权威存档格式及 AI 策略保持既有实现。

## 菜单

动态背景包含海洋、山川、河流、村庄、麦田与羊群。背景采用可复现的代码绘制，保留云层、海浪、河流、风车、麦穗和羊群的动画；采用未缩放的展示时间，菜单暂停游戏时仍能运动。

暖白面板与森林绿按钮承载基础版、航海家、城市与骑士、双扩展组合的全部开局设置；保留剧本、人数、AI 操作速度、胜利分数、本人席位、读档、返回当前局与联机入口。局域网与在线大厅沿用相同背景及配色。

## 音效

音频属于展示层，只消费当前席位可见的投影历史与公开视图。资源和抽牌使用通用声音，不按对手隐藏牌名、资源类型、牌库顺序或规则随机状态选音。读取存档、切换规则或重连时建立新历史水位，避免重播旧动作。

各类建造、升级、船只、资源收取、交易、卡牌、骰子、强盗与海盗、骑士、蛮族及倒塌采用不同合成音色；通用 UI 反馈覆盖现有菜单和游戏内控件。并发声部与同类音效有数量和频率限制。菜单及 Esc 游戏菜单提供持久化音量和静音设置。

具体生成配方与运行实现以 `TabletopAudioSynth.cs`、`TabletopAudioModel.cs` 和相关资产清单为准；无外部采样授权依赖。

powershell -NoProfile -ExecutionPolicy Bypass -File tools/development/Build-M7.ps1 -OutputRoot .local/menu-audio-v001 -VerifyPlayer
