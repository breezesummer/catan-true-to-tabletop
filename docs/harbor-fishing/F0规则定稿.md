## 七项闭合裁决

### D01 港口建筑

有效港口的村庄1点、城市2点；大都会仍为2点（FAQ“Harbormaster + C&K - How many points does a metropolis yield…”）。同一Vertex只计一次，不把大都会附加分、联盟共享贸易、分数标记计入。未放置的部落港口不计（FAQ“The Lost Tribe + Harbormaster…”）。

三国损害按B5实体效果：倒塌村庄0；城市降为仍有效的村庄1；修复成城市2；村庄亦倒塌则0。`DowngradedCities`是棋子库存记录，不额外加分；城市损害标记不能把仍存在的有效村庄错误归零。实现不可直接使用未过滤损害的`Buildings`枚举。移除0，归属变化归新主。损失后的唯一最高／并列回公共区、持有人并列保留遵循实施方案3.1第5条，为项目裁决。

### D02 行动窗口与事件

TB25.pdf第10页只规定自己回合，未穷举中断点。项目固定：`ProductionAwaitRoll`且准备／判定／三国响应全部完成，或自由`Action`窗口，允许五种用鱼和传靴；不得打断掷骰、产出、弃牌、入侵、卡牌响应、换将或其他待决。操作权限使用真实提交者与被代操资产席位。5鱼建设可在该掷骰前窗口执行，但只绕过普通建设的阶段门，不绕过位置、供应、禁建和优先修复；建设事件的技能仍按其原时机触发，例如奋音限出牌阶段。

3鱼偷牌不是强盗行动，也不是技能／发展牌，首次蛮族前可用（FAQ“The Fishermen of Catan + C&K … barbarians haven’t come yet?”）；不触发“成为技能／发展牌目标”，仍适用空城等既有通用保护、联盟不互攻与牌流禁失／禁获。4鱼只选可得资源，不能选商品；7鱼在城市骑士选择非空颜色牌堆，随机抽1张，不检索具体牌面（FCK.pdf第1页的“choice”按选择类别裁决）。进步牌上限、公开胜利点牌和获得响应走原路径，不能重扣鱼。

鱼行动生成的真实资源得失正常触发牌流技能；花鱼本身不触发弃牌／失牌／打牌技能。免费道路／船是实际建设，资源实付0，不受资源造价增减，不返还鱼；可以触发既有建设复制，但复制仍免费、不得递归。

### D03 开局与产出

标准图按TB25.pdf第9页：湖泊取代沙漠并处于中心七格之一；六枚渔场随机分配到六个框架V口，每处影响三个连续海岸顶点。一个号码只出现一次。固定稳定ID表由F2按当前拓扑生成并验证；F0固定几何合同，不伪造代码ID。

TB25.pdf第9页开局句与FAQ只保证邻接鱼源时抽1枚，没有多源叠加条款。项目裁决：第二座开局建筑即便邻接两个鱼源也只抽1枚；城市骑士第二座城市亦只抽1枚，此为开局奖励，不是生产。正常生产则按每个命中鱼源逐建筑累加，村庄1、城市2。倒塌村庄不产；降级城市按有效村庄产1。

三国额外“收获资源”、替代摸牌、地块资源选择均不额外抽鱼；只有正式产出结算及FSF明确的探索奖励触发。只得鱼不取消水渠（FCK.pdf第1页）。结算顺序固定为宿主骰子／入侵／进步卡 → 原资源与商品及其替代／水渠响应 → 鱼生产队列 → 自由行动；待决期间不得用新抽鱼插入支付。队列冻结本次座次、数量和产出源，逐玩家抽完再轮下一人；同玩家按源ID、Vertex ID排序。保存游标及已处理标记。

### D04 满额、旧靴与随机

29枚鱼合计55条鱼，另1枚旧靴；不可变Token ID唯一归属供应、弃置或一名玩家。抽旧靴占用一次抽取机会，公开放入其资产区，不补抽。普通城市两次机会第一抽旧靴，第二次仍执行。

满7枚时尚有应抽次数可选择换抽或放弃。选择换抽：弃1枚 → 必要时将弃置堆洗入供应 → 抽1次 → 本次该玩家剩余机会全部终止。若抽到旧靴，最终6枚鱼＋旧靴，仍停止；不额外补鱼。拒绝换抽也终止本次该玩家剩余机会，但不消耗当回合换抽次数。换抽次数只在真正换抽成功时消耗。原文未分别列举这些边界，此处为项目裁决，遵循TB25.pdf第10页“停止抽取”。旧靴永不作为弃鱼、支付或洗回对象。

队列是单次有限额度，不因旧靴、洗牌、座次调整而扩张。供应空时只洗弃置；双池空停止剩余抽取。初始化固定Token ID排序后用权威随机源洗牌；抽牌只弹出池首，不再每枚额外随机。非法／取消／预览不得消耗随机。附加开关关闭不调用该随机路径。

### D05 胜利目标

| --- | --- | --- |
| 基础默认 | 10＋海港开关的1 | T＋本人旧靴的1 |
| 城市骑士默认 | 13＋海港开关的1 | T＋本人旧靴的1，保留既有合法胜利窗口 |
| 航海／双扩展 | 当前剧本默认值＋海港开关的1，仅一次 | T＋本人旧靴的1，仍需满足剧本条件 |
| 自定义目标16且开海港 | 16（输入已包含修正） | 无靴16，有靴17；反复开关不重复加 |
| 奇观 | 当前分数路径默认／手动目标 | 分数路径T＋旧靴1且奇观等级领先；完成奇观路径不受旧靴影响（FSF.pdf第3页，旧11分常量不照搬） |
| 三国联盟 | 各玩家独立检查同一T | A有靴须T＋1，B无靴只须T；一人合法获胜才全盟获胜 |

旧靴不降低显示分数，转交只比公开分；隐藏胜利点不参与（TB25.pdf第10页）。非当前行动玩家不能因收到／传出旧靴或奖励转移而绕过回合胜利窗口。事务全部结束、强制响应结束后检查，不在临时中间局面终局。

海盗群岛捕鱼禁止。海港在该图也暂不开放，F5需验证3／4人以及单／双扩展可达上限后才设置具体上限；不把13盲加1或放开20。该后续开放门不影响首切片，F0不宣称该图目标已经可达。

### D06 地图事务

沿用[B6地图合同](../three-kingdoms/B6地图交换与均分规范.md)。湖泊是独立地形组件，带固定号码集迁移，不加入普通单数字池；作为内陆地形支持陆路，不支持湖边建船。榻谟不能把湖泊移至海岸，不能产生新内湖航线；迷雾按FSF发现湖泊仅抽1枚，探索例外单独验证，不套用榻谟限制。

渔场ID、号码、三顶点集合固定于空间，不随地形旋转；交换预检要求三顶点仍为合法连续海岸、渔场之间不重叠、号码／数量不变、湖泊合法内陆、原B6所有锚点和棋子条件成立。港口按B6重定位，可与渔场共享合法顶点但港口间仍不得共享端点。共享只影响两种独立用途，不重复计港口分。

在副本完成全部迁移、损害与归属记录、港口和鱼源校验后一次提交，重算港口奖励再进入响应和胜利检查；失败连次数、随机源、历史都不改。未揭示湖泊池不进入公开视图。

### D07 三国技能边界

[逐技能审查](F0三国技能审查.md)覆盖54将97技能。“牌／手牌／任意资源／商品／发展牌”均不含鱼与旧靴；数量上限技能不改变7枚鱼上限。原文未出现可取得“任意组件／任意奖励”的通用技能，武库、田和奖励分均各有专属类型，不能替换成鱼。通过鱼取得的真实卡牌再走现有类型事件；海港奖励为独立分数项，不能被发展牌回收或复制。
