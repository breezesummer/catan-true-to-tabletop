# F0 三国逐技能审查

日期：2026-10-29。依据[百科原文](../三国争霸游戏百科.md)及B0—B6已实现合同，覆盖54将97技能。以下为附加模块的项目裁决；不改动原牌文。共同边界见[F0定稿D07](F0规则定稿.md#d07-三国技能边界)。每行列全该将技能，逐项指明鱼、奖励或间接事件的关系。

| 编号 | 武将 | 技能 | 裁决 |
| --- | --- | --- | --- |
| W01 | 张辽｜登锋陷阵（魏） | 突袭 | 突袭仅替代资源／商品摸牌额度，不能少抽鱼来偷牌。 |
| W02 | 吕布｜傲睨万物（群） | 无双、利驭 | 无双、利驭只操作骑士；小麦费用不能用鱼抵付，驱盗仍用原保护。 |
| W03 | 周瑜｜雄姿英发（吴） | 英姿、反间 | 英姿不多产鱼；反间只猜资源／商品，伤路不伤渔场。 |
| W04 | 貂蝉｜舞惑群心（群） | 惑心、闭月 | 惑心获得被代操者鱼的操作和私密权限，不转归属；闭月只取资源。 |
| W05 | 大乔｜衣垂绿川（吴） | 流离、国色 | 流离是技能移动强盗，与2鱼离场分开；国色禁失牌不禁花鱼，但仍禁相应卡牌流。 |
| W06 | 曹仁｜国之柱石（魏） | 据守 | 据守禁摸资源／商品不禁自然抽鱼；4鱼取得资源仍受禁摸。 |
| W07 | 于吉｜神术妙法（群） | 蛊惑 | 蛊惑不能把鱼当资源支付或声明，鱼费用不能虚报。 |
| W08 | 甘宁｜万人辟易（神） | 劫营、魄袭 | 劫营不取鱼；魄袭不看弃鱼，额外资源收获不产鱼。 |
| W09 | 郝昭｜死守陈仓（魏） | 镇骨 | 镇骨手牌数不含鱼，补牌不抽鱼。 |
| W10 | 袁绍｜一往无前（群） | 乱击、血裔 | 乱击费用不含鱼，虚拟入侵不产鱼；血裔不提高7枚上限。 |
| W11 | 贾诩｜陈筹画策（群） | 帷幕、乱武、间书 | 帷幕不免疫鱼行动（不是蓝牌）；乱武、间书不支付或统计鱼，间书禁摸不禁自然抽鱼。 |
| W12 | 留赞｜灵魂歌王（吴） | 奋音 | 奋音可由出牌阶段的5鱼道路触发，掷骰前建设不触发。 |
| W13 | 司马懿｜佳期若梦（魏） | 连破、鬼才 | 连破额外真实回合重置换抽标记；鬼才不能弃鱼或取湖泊多号码改单骰。 |
| W14 | 曹操｜逐鹿天下（魏） | 奸雄 | 奸雄不回收鱼或海港奖励；7鱼取得的真实卡随后被使用时按原合同。 |
| W15 | 刘备｜龙御天下（蜀） | 仁德 | 仁德不能赠鱼／旧靴，传靴不算赠牌；3鱼偷牌不算主动给予。 |
| W16 | 黄盖｜鏖战赤壁（吴） | 苦肉 | 苦肉拆除5鱼道路返资源0，按实付账本，不退鱼；港口建筑变化重算奖励。 |
| W17 | 甘宁｜龙生九子（吴） | 奇袭 | 奇袭不能弃鱼／拆渔场；建筑与设施变化按真实类别重算。 |
| W18 | 关羽｜明良千古（蜀） | 武圣、单骑 | 武圣只拿红号资源，不拿6／8渔场的鱼；单骑不改鱼池。 |
| W19 | 诸葛亮｜明良千古（蜀） | 观星、空城 | 观星仅最终骰点产鱼；空城手牌不含鱼，有鱼无牌仍满足空城，沿用通用负面保护。 |
| W20 | 孟获｜祸崇南疆（蜀） | 祸首、再起 | 祸首黑7不产鱼；再起资源翻倍不翻鱼，不把3鱼偷牌当强盗；城市变化重算港口。 |
| W21 | 张昭张弘｜同心协力（吴） | 固症、直谏 | 固症不获得弃鱼；直谏固定7无鱼生产。 |
| W22 | 孙权｜吴王六剑（吴） | 制衡 | 制衡不能弃鱼换资源，发展牌交换不检索鱼池。 |
| W23 | 陆逊｜烈火烛天（吴） | 连营、谦逊 | 连营不由花鱼触发，鱼偷走最后真实手牌可触发；谦逊列举牌免疫不扩为所有鱼行动。 |
| W24 | 华雄｜梦回唐朝（群） | 耀武、扬威 | 耀武上限不改7枚，鱼行动不是发展牌；扬威只改骑士。 |
| W25 | 董卓｜乱世魔王（群） | 崩坏、横征 | 崩坏比分含公开海港2分，靴不减分；横征不转鱼，取消摸牌阶段按原资源流程，独立鱼生产仍执行。 |
| W26 | 阚泽｜循循善诱（吴） | 下书、宽释 | 下书不转移或展示鱼；宽释仅计真实手牌得失，3／4鱼造成的手牌变化可计数。 |
| W27 | 孙尚香｜前后两难（吴） | 结姻、枭姬 | 结姻可复制5鱼真实建设且实付0，不递归；花鱼不触发同步弃牌；枭姬只计发展牌。 |
| W28 | 吕蒙｜剑起惊澜（吴） | 涉猎、克己 | 涉猎不替换鱼生产；克己花鱼不算失牌，鱼偷牌仍受禁失牌保护。 |
| W29 | 曹丕｜气荡山河（魏） | 放逐、颂威 | 放逐跳过回合不产生鱼行动窗口；颂威不因弃鱼触发。 |
| W30 | 曹植｜龙生九子（魏） | 落英、酒诗 | 落英不能收弃鱼；酒诗费用不含鱼，额外回合重置换抽。 |
| W31 | 李儒｜鸠杀少帝（群） | 焚城、绝策 | 焚城弃牌不含鱼；绝策无手牌判断不含鱼；建筑变化重算港口。 |
| W32 | 徐盛｜大宝（吴） | 破军、疑城 | 破军不放大鱼效果／奖励，扣科技不改城市基础港口2点；疑城牌费不含鱼。 |
