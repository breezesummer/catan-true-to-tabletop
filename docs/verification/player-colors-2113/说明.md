# 玩家棋子归属色对照

日期：2026-11-10。客户端：Windows 内测版 2.1.13。

四人双扩展＋三国＋海港＋捕鱼，穿越沙漠，第 42 回合。读取既有的 `knight-reference-2111/扩展棋子验收局.json`，暂停后在同一场景内临时摆放四色模型。对照结束恢复实局，权威对局状态前后一致。

466 项检查通过，保存 15 张离屏相机场景图。检查包含归属材质与玩家席位色一致、四色共享网格、着色器可用、实体与绘制视图显示、同源建造预览、库存图存在及碰撞器未增加。未执行鼠标交互或完整界面像素验收。

`玩家建筑四色对照.png` 由四张原始场景图按相同坐标裁切、排列并加行列标题，模型颜色和背景未作调整。单图左起为红方、蓝方、金黄方、米白方。图片中的并排摆放只用于外观对照。

归属色读取 `BoardRenderer.SeatColors`。村庄和主城的屋顶、城墙上沿、道路、骑士服饰与船帆统一使用该色；大都会扩大到金帐屋面、重檐屋面和穹顶。保留原贴图的纹理与明暗，以及石基、木材和金属构件。归属遮罩在编辑器内生成，客户端共享网格、贴图和材质，不扫描模型三角面。

重建材质：Unity 菜单「Catan／美术／统一玩家棋子归属色」（`PlayerPieceColorImport.Run`）。大都会遮罩额外核对非原玩家色屋面的覆盖，避免 FBX 轴转换导致漏染。普通棋子与扩展棋子的原导入入口会继续应用归属色。
