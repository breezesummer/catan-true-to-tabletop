# B4 Windows 局部交互观察

日期：2026-10-23。使用本地构建的 `game version/2.0/Catan2.0.1-Three-Kingdoms-B4/Builds/Windows/Catan2.0.1.exe`，通过 computer-use 的窗口截图及鼠标输入检查；窗口截图在本轮工具记录中显示，没有另存PNG。

## 实际鼠标路径

1. 从主菜单打开“开始游戏”，选择城市与骑士，启用三国，四人开局。
2. 私密面板显示四张候选：大乔、郝昭、曹操、张辽。先选择曹操，再选择张辽；数量从0／2变成2／2，确认按钮启用。
3. 确认后进入“私密选择登场 · 全员完成后统一公开”，只显示本人已选的两张牌。
4. 选择张辽并确认，私密面板关闭，正常初始摆放接续，历史中出现统一公开登场结果。全程通过实际鼠标操作，未直接注入规则命令。
5. 发现主菜单仍显示B3的旧包说明，修改后重新构建，再打开最终Windows程序，进入城市与骑士向导，目视确认“三国争霸 B4（30张完整武将）”及“已开放30将、51技能，同时选将与自动阶段；支持本地及联机对局”。

城市骑士默认13分胜利目标未改。B4同时预留候选所需的三人13张／四人17张，属于武将实体数量。

## 检查边界

本观察证明局部开局选将、登场及菜单文案可通过实际窗口操作。没有覆盖全部14将卡面选择、每种分辨率、触控、联网实机或完整对局，不标记完整UI或用户本人试玩通过。
