# 三国争霸 B2 牌流基础验收

完成日期：2026-10-23（Asia/Shanghai），首轮规则验证于 2026-10-22 运行。分支：`dev-2.0`。游戏版本：内测版2.0.1。本轮交付本地规则与 Windows 开发程序，不是正式发布。

## 交付范围

正常启用张辽、曹仁、郝昭、留赞、刘备、孙权、陆逊、吕蒙、黄月英、郭嘉、骆统，共 **11 将、15 个具名技能**。前九将全部采用 [B0 首批规范](../../three-kingdoms/B0首批武将规范.md)；黄月英、骆统以 [B2 补充规范](../../three-kingdoms/B2补充武将规范.md)完成定稿与全部技能，满足四人逐人发 4／末位发 5、各留 2 的最低池量。其余 43 将保留原文且不进入正常将池，没有用空技能武将填池。

城市与骑士和九张双扩展地图使用相同的技能核心。生产预留、金矿、自选银行所得、替代、批量牌流、建设计数、禁摸、目标免疫、失牌保护、发展牌容量和延时奖励均写入权威状态；选择点支持预览、幂等执行及存档重放。架构、版本与规则 PDF 页码见 [B2 实现说明](../../three-kingdoms/B2实现说明.md)。

Unity 面板显示原文、技能次数、寿命、持续效果和技能待决；仁德与制衡支持批量手牌，涉猎亮牌公开，天妒以地块、地形和点数说明选择。AI 只读取所属 `PlayerView`，完成所有强制技能选择；主动策略有限，不主动用仁德循环交牌或无限隐退。

## 验证方法与覆盖

- 独立技能宿主覆盖各技能正常、非法、零牌、库存不足、次数、批量、任次、持续效果与中途复制恢复。独立预期值断言实体资源／商品守恒、随机一致、非法零变更及隐藏信息隔离。
- 原生规则夹具验证实际造路支付与连营、谦逊拒绝进步牌目标、遗计先于大商家主体、克己与强夺／自愿交易、奇才容量、集智等待修路选择结束，以及商港两步交换的整笔牌流。夹具不冒充正常开局或重放存档。
- 正常会话覆盖城市与骑士 2 配置及九图 18 配置，使用完整 11 将池按真实发牌选将。完整局由产品 AI 从正常开局运行至正式胜利；每局跨越三轮轮换，并检查实际技能待决的保存、恢复与预览一致。
- 保留 B1 显式骨架入口及旧规则身份，复测冻结旧存档、生命周期和四局骨架完整局。关闭三国的原模式、协议与服务另行回归。

## 运行与边界

Windows 开发程序位于 `game version/2.0/Catan2.0.1-Three-Kingdoms-B2/Builds/Windows/Catan2.0.1.exe`。在开始游戏中选城市与骑士或双扩展，打开“三国争霸 B2”即可进入。

实际程序探针通过产品入口创建城市与骑士／组合各三人、四人局，完成技能选项提交、隐退、保留配置重开和精确保存恢复。详细结果见 [Windows 运行说明](Windows运行说明.md)。隐藏窗口未生成 IMGUI 重绘图像，程序探针不等于像素、鼠标、触控或用户本人整局试玩。

三国联机继续关闭；协议与隐私回归用于后续接入，不等于多人外网或断线恢复验收。Android、真机、美术和全部 54 将技能不在本次 B2 完成范围；后续仍按 B3–B7 推进，M0–M8 原状态不变。

## 复跑入口

在仓库根目录设置项目工具链后执行：

```powershell
$env:DOTNET_ROOT='D:/Development/dotnet'
$env:PATH=$env:DOTNET_ROOT+';'+$env:PATH
dotnet test tests/Catan.Rules.Tests/Catan.Rules.Tests.csproj -c Release --filter 'FullyQualifiedName~ThreeKingdoms'
dotnet test tests/Catan.Network.Tests/Catan.Network.Tests.csproj -c Release
dotnet test tests/Catan.Server.Tests/Catan.Server.Tests.csproj -c Release
./tools/development/Build-M7.ps1 -OutputRoot 'game version/2.0/Catan2.0.1-Three-Kingdoms-B2' -SkipVerification
```

独立程序接受 `--three-kingdoms-verify <绝对证据目录>`，成功标记为 `CATAN_THREE_KINGDOMS_PLAYER_OK`。构建脚本的 `-SkipVerification` 只跳过历史通用检查，本轮规则、网络、服务和实际程序验证分别记录。
