# 2026-11-02 手杀武将与技能界面

版本沿用内测版 2.1.2。本轮依据用户提供的六张参考图调整界面；隐退限制与取消预约依据本轮用户明确指令，不引用官方卡坦 PDF。

## 改动

- 技能操作区只在实际选择、技能响应或隐退选择时出现；空闲时不绘制底框，也不拦截该区域的棋盘输入。结束回合沿用右下角按钮。
- 使用本地无名杀十周年 UI 的手杀势力渐变框、三态技能按钮、回合发光动画和字体。技能分支用透明背景上的绿色按钮，悬停与选中显示高亮；有真实牌面的候选继续使用牌面交互。
- 武将立绘扩展至姓名条旁，保留露头与原透明边缘。势力文字随原框配色，姓名采用手杀行楷，技能采用 HYZLSJ。
- 隐退进入技能区，只在自己的合法回合窗口亮起。删除预约界面，权威层不再生成或接受预约命令，旧存档中的预约不再执行；保留序列化字段以便读取旧档。
- 技能说明只显示名称与规则正文，删除附加的时机、费用、次数、提交说明和运行状态。武将说明统一为姓名、势力、称号及逐项技能正文，去除 Markdown 标记与重复标题。
- 说明弹层半透明、按正文高度收缩，使用无框关闭按钮。

## 素材与导入

来源见 `Unity/Catan/Assets/Resources/GeneralUI/v002/素材来源.md`；复现入口为 `tools/art/Import-ShoushaUI.ps1`。三个源按钮虽以 `.png` 命名，实际为 WebP，已转存 PNG；技能字体由 WOFF2 解封装为 TTF。

- 最终 GameView 65 项断言、6 次鼠标点击通过，覆盖六种势力素材、主动选择、灰置、右击、寿命、其他回合、武将说明、隐退取消和原有结束回合。最终通过批处理图形入口运行，截图为实际游戏渲染；此前交互式编辑器截图也已检查。
