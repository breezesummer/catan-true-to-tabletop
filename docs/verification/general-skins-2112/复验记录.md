# 2026-11-07 武将动静皮与中央技能演出

## Windows 客户端

双扩展、三国、海港大亨、捕鱼的四人「穿越沙漠」验收局面中，客户端实际加载了 33 套待机和攻击图集。鼠标在李儒详情中先点「切换静皮」，再点「切换动皮」。张辽在合法的摸牌待决中发动一次「突袭」，实际取得两张手牌。实录由完整窗口帧按采样时间编码。[动皮](李儒-动皮.png) · [静皮](李儒-静皮.png) · [中央演出](张辽突袭-中央实录.webp)

## 四席联机

四个独立 Windows 客户端加入本机 WebSocket 房间，开启上述同一组模式，分别从本席收到的投影提交合法操作。四席都记录到事件 `tk-b2-harvest-46`，发动者是 P3，武将为郭嘉，技能为「天妒」。每席在动作中段从自己的窗口截图。四幅画面的手牌各不相同，中央显示同一演出。[四席画面](四个客户端-同一技能.jpg)

## 复验入口

- 单机窗口复验使用 `tools/validation/verify_all_table_input.py`。依次传入 Windows 游戏程序、项目已有的「穿越沙漠四人验收起点.json」、新的输出目录、解出 `tk-g01-s1.input.json` 的验收局面目录和 `--skin-clicks`。
- 四席复验使用 `tools/validation/Test-TableReactions.ps1 -GeneralSkins`。传入游戏程序路径、本机房间服务地址和新的输出目录，四个客户端都使用图形设备。
- 素材烘焙入口是 `tools/art/bake-general-skins.cjs`，参数为本机无名杀的 `extension` 目录。工具使用十周年 UI 的皮肤配置、皮肤切换的 Spine 运行时和势力顶弧。需提供 Playwright、sharp 和可用的 Chromium 内核浏览器，浏览器路径可通过 `CATAN_BAKE_BROWSER` 指定。张辽复用此前验收的原图集。
