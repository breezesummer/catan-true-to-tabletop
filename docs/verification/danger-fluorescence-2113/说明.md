# 强盗与海盗红色荧光验收

日期：2026-11-10。覆盖 Windows 内测版 2.1.13。

强盗陆地与海盗海格使用已确认的荧光样式：红色亮芯、外晕、交织光丝和渐隐拖尾，沿六角边缘持续循环。取消原有静态红色描线和整格染色；强盗危险流光优先于该格的翡翠或金色产出流光。棋子移位后更新同一危险光层，离场时关闭。海盗光层设在最高波峰上方，避免随海浪闪断。

以四人「双扩展＋三国＋海港＋捕鱼／穿越沙漠」第 42 回合存档加载正式 Windows 客户端。在验收副本中通过正式绘制入口分别将危险标记投影至产出格、沙漠及两处海格，核对坐标、材质复用、重复刷新、离场清除、地图标记显隐和权威状态未改变。临时投影不执行规则指令，也不移动棋子模型。检查结束恢复原危险标记。

每处保存 0、0.6、1.2 秒三张离屏图；同一游戏帧内仅改变荧光时钟，用像素差异验证流光移动。首轮海盗截图因地块 ID 含 Windows 不允许的冒号中断，修正文件名后重新执行。

本轮仅调整本地渲染，不改变规则、隐藏信息、网络协议或服务端。未执行桌面鼠标操作、完整 UI 像素、四设备联机或 Android 真机验收。

最终构建通过 43 项危险光专项检查，保存 12 张离屏图；另通过 203 项翡翠与金色产出流光回归检查。
