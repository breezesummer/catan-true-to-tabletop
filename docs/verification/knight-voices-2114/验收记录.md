# 骑士分级英语语音接入记录

日期：2026-11-11。版本：内测版 2.1.14，覆盖当前 Windows 版。

## 素材与触发

| 实体等级 | 已验收音色 | 数量 |
| --- | --- | ---: |
| 一级 | John North | 12 |
| 二级 | George | 12 |
| 三级 | Lord Griff | 12 |

共36句，覆盖建造／晋升、激活、驱赶海盗、驱赶强盗、进攻和移动，各等级每种动作含 A、B 两句。台词适用于普通骑士，不依赖三国武将身份。使用已交付成品，未重新合成、变速或变调；英文、中译、表演要求与来源见 `art/recipes/knight-lines-en-v001/`。

按成功操作的公开历史选择骑士实体等级，晋升使用晋升后等级，联盟代操使用实际进攻方等级。基础骑士卡、船只进攻与被迫撤退不会套用骑士进攻台词。首次绑定、恢复与重连建立历史水位，不重放旧动作；声音不参与规则计算、随机数或网络协议。

资源异步预载，动作与等级各自轮换 A/B，语音串行播放。待播队列最多4条，4秒过期；静音、语音音量归零及后台暂停会清空待播。复用原语音总线，保留音乐闪避及其他配音。主菜单、局内设置与紧凑声音设置均不提供试听或语音选择，只保留静音和音量。

## 验证结果

- `Catan.Audio.Tests`：298／298 通过。覆盖动作与实体等级、联盟代操、公开与隐藏变化、批量激活、恢复与重复历史、A/B轮换、队列边界及36份运行资源的校验值与混音余量。
- Unity Editor：256项检查通过，36份资源全部加载，实际启动39次语音播放，包含36句逐条播放和同帧三种战斗动作的顺序播放；静音、零音量、暂停和权威存档不变检查通过。机器结果见 [result.json](result.json)。
- 资源：24 kHz、16位、单声道 PCM WAV；运行时增益0.83，处理后峰值不高于0.701。逐句成品 SHA-256 与已交付素材一致，自动转写核对36／36通过。
- 界面：四人「双扩展＋三国＋海港＋捕鱼＋穿越沙漠」真实游戏声音设置截图已检查，试听和语音选择均已移除。原图保存在本地同目录的 `双扩展三国捕鱼-骑士语音设置.png`，按仓库存储约定不入库。

实际播放和画面检查运行于 macOS Unity Editor；Windows 为交叉构建，未执行 Windows 真机运行或新增人工听审。本次仅客户端声音与设置变化，不涉及服务端规则或协议部署。

## 复现入口

单元测试：

```sh
source tools/development/Enter-DevEnvironment.zsh
dotnet test tests/Catan.Audio.Tests/Catan.Audio.Tests.csproj
```

编辑器验收：使用 Unity 的 `-executeMethod KnightVoiceEditorVerification.Run --knight-voice-verify <项目绝对路径>/.local/knight-voices-2114`，开启图形环境，不传入 `-quit` 或 `-nographics`。macOS 临时目录路径须解析为真实路径。该入口创建独立本地对局，退出前恢复声音偏好。

Windows 构建入口：

```sh
./tools/development/Build-Game.command --target windows --output-root 'game version/2.1/Catan2.1.14-Knight-Voices'
```

本次在独立 Unity 快照中完成构建，快照包含远端基线与本次骑士语音改动，避免混入同工作区的其他未提交修改。最终构建校验见 [构建核对.json](构建核对.json)。
