# 1.6.10 历史、选择提示与交易界面验收

日期：2026-10-19。构建：`game version/1.6/Catan1.6.10-Choice-Trade-History/Builds/Windows/Catan1.6.10.exe`。

## 本轮行为

- 历史统一“使用／获得了”，工程学建墙显示“建造了城墙”；卡坦保卫者、宪法（兼容石碑名称）、印刷术标记“（1分）”。发展卡按已公开的牌背轨道着色，具体隐藏卡身份继续脱敏。
- 城市被掠夺、失去城墙与降级合为一句；破坏和掷出 7 的弃牌只播报弃置数量，“破坏”使用蓝色「」卡名。历史保留固定字号及卡面尺寸，长记录换行并增加行高。
- M2–M5 的地图棋子／位置及强制待决选择持续提示。城市降级、叛变移除骑士和替补骑士安置均有明确文案；每帧按交互状态同步，短通知不能覆盖尚未完成的选择。
- 游戏内窗口统一 `—` 收入回合按钮，`×` 关闭。普通草稿关闭后恢复地图操作和正常回合按钮；强制选择关闭后从常驻提示重新打开。历史、菜单和百科的收起入口可跨 AI 行动保留，打开新窗口不会错误恢复旧窗口。
- 银行、玩家交易、资源港口和交易请求使用居中图标标题、纹理边框；双方头像、名字和资源居中，中央使用上下旋转对称的黄色半头双向箭头。港口标题不显示兑换比例。
- 全体接收者无力支付而自动拒绝时，从本条已确认报价保留完整公开内容，避免空交易历史；零资源玩家不能发送空单，发送前再次校验。
