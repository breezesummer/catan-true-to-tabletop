# 荧光流光实装验收

日期：2026-11-10。Windows 内测版 2.1.13，覆盖原有 `Catan2.1.13-Building-Sounds` 构建目录。

按照已确认概念图实现翡翠与金色荧光：亮芯、柔和光晕、三组沿边游走的光头、渐隐拖尾与交织细光丝。光带沿六边形周长循环，转角柔化，边与边使用连续周长坐标。荧光层为加色透明材质，贴在地块表面上方，光晕可扩展到边缘外侧，建筑依照深度遮挡。

203 项检查通过，保存 9 张正式客户端离屏图。验收配置为四人「双扩展＋三国＋海港＋捕鱼／穿越沙漠」，读取第 42 回合存档。使用正式 Windows 客户端、离屏相机检查画面；不把这些图记作完整 UI 像素或鼠标交互验收。

核对内容包括无产出地块不亮、单倍翡翠、多倍常态金色、城市升级与降级、失去建筑、换席位、材质共享、无新增碰撞器和对局状态一致。每块荧光共用一份四顶点／两三角形平面及同一材质，每帧只推进共享时钟，由 GPU 计算光丝运动。沿用地图标记显隐及强盗危险光优先级。

分别对翡翠和金色取 0、0.6、1.2、1.8 秒画面。同一组截图在同一游戏帧内完成，只改变荧光时钟，因此像素差异可用于验证流光运动，不将海面变化计作流光移动。未进行四设备外网或 Android 真机性能验收。
