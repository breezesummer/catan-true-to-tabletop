# 收藏版主菜单与联机界面（1.6.14）

日期：2026-10-20。

## 实现范围

- 按用户确认概念图保留暖光桌面、立体棋盘插画、资源卡与骰子的构图。背景、透明标题分别导入，菜单文字、六角选中标记和命中区域由 Unity 独立绘制。标题保持宽高比，背景适配窗口裁切；本版为二维静态菜单场景，不宣称三维模型或镜头漫游。
- 主菜单取消矩形导航底板、宣传短句和右下风景说明卡，改用随包思源宋体、米金色文字与细线。默认山海棋桌，旧六景仍可选；独立偏好键保留旧版主题设置，棋桌不使用水波变形。
- 子页面与联机统一暖纸色、细纹、深木边框、旧金色和森林绿主操作。在线／局域网大厅保留独立入口，列表按房间列出人数与状态，在线列表补充玩法名称；连接设置留在次级页面。
- 等待房间改为两列座位：颜色、本人／房主标识、玩家名、准备／托管状态以及换座／转交房主。增加复制房间号；未满员或未准备时，房主开始按钮说明等待原因，最终开局仍由服务端验证。默认胜利分数按规则解析，避免空白。
- 保留创建房间三步配置、密码弹窗、在线空状态／离线重试、按房间号加入、断线恢复。补上联机内容区单指滚动；Android 与 PC 使用同套布局，新图片在 Android 使用 2048 上限。

## 资产与来源

使用内置 image_gen，以已确认概念图为编辑参考，保留原件并生成无 UI 的背景及透明标题；未覆盖历史原画。源文件、完整生产提示词与校验值见 [资产记录](../../../art/source/menu-collector-v001/README.md)。场景里的数字牌仅是装饰插画，不是对局规则数据。
