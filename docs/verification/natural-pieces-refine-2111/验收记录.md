# 2026-11-05 自然建筑第二轮精修验收

本轮覆盖 Windows 内测版 2.1.11。主城强化中央高塔，压低副塔与门厅，以矮连廊替代前部多余屋顶；村庄与道路同步调整材质层次、瓦石分段和接地表现。源配方与 Blender 检查图保存在 `art/recipes/natural-pieces-v002`。

## 资产与接入

- 三件源模型、FBX 独立回读均无退化面、UV 越界；三角面数分别为村庄 8,939、主城 21,464、道路 2,282。主城比上一版减少约 43% 三角面。
- 三件网格由红、蓝、橙、米白共用，每件一个 Renderer、三个材质槽。门窗暗部合入石木贴图，第三槽用于渐隐贴地柔影；未增加碰撞或逐帧脚本。
- 以 Blender 烘焙瓦石色差、屋檐与墙脚遮蔽；Unity 中关闭建筑接收实时阴影，保留表面受光与贴地柔影，减少小瓦片的阴影噪点。
- 地图、库存、十二张缩略图、合法／非法建造预览和既有城墙组合沿用同一资源入口。规则、网络与用户存档路径没有修改。
