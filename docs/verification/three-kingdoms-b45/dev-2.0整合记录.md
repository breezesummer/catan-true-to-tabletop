# B4.5并入dev-2.0整合记录

日期：2026-10-26。版本：内测版2.0.2。本轮按用户要求整合源码并同步本地及远端`dev-2.0`，不正式发布、不部署云端。

## 整合内容

- 将本地B4.5完整的桌面直接交互、底栏重排、技能按钮、手牌／头像／棋盘对象选择、真实支付与用途声明、运行时状态提示及对应检查合入远端最新基线。
- 包含本次手牌修复：已有牌面使用贴合实际卡面的纸芯与阴影，去掉额外纸底边框和可选／选中彩色描边，保留抬牌与选中提示。
- 保留远端B5的49将87技能、损害／修复／骑士／科技等棋盘规则，以及已落地的联机增量同步、后台解码和表现事件恢复。
- 为B5新增技能补齐新界面入口，保留常规修复及借用利驭入口；棋盘选择和费用附加在可见动作元数据中，不改写旧合法命令。科技轨道与数字选择不会被误判为真实支付。
- 原本地分支与远端经过仓库瘦身后的历史不相接。本次以远端`e710582c`为基础重放本地B4.5、逐项解决冲突并整理为单次提交，不将旧的大型素材历史重新推回远端。

- 整局回归发现杜预虚拟牌候选在视图生成时被逐项重复完整试执行，出现平方级耗时；仅对本次已验证的虚拟技能候选复用结果，实际执行仍完整校验。新增四组双宿主／旧B4.5与新整合包的性能、只读、真实执行及伪造命令拒绝回归。

## 新旧规则包

新局使用`three-kingdoms-board-state-49-direct-v1`，对应规则`three-kingdoms-b5-direct-v1`，将B5棋盘能力与B4.5自选主动技能交互组合。城市骑士和组合模式分别使用带`b5-direct-v1`的宿主存档身份；内容哈希与旧包不同，联机按真实身份检查。

B4、B4.5、B5原包身份及哈希均保留，旧存档按各自身份恢复。旧B5仍保留原有自动询问；新整合包不在自由出牌阶段强制询问主动技能，事件响应继续由规则驱动。规则依据沿用既有[B4.5选择合同](../../three-kingdoms/B4.5选择合同.md)与[B5规则定稿](../../three-kingdoms/B5规则定稿.md)，本次不增加新的武将技能或擅自更改牌文。
