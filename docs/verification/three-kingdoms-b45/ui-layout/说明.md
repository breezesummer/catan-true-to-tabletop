# B4.5 底栏、手牌布局与输入组件证据

日期：2026-10-24（Asia/Shanghai）。对应开发版本2.0.2。此处只记录实际完成的组件检查，不据此宣布B4.5全部退出、Android真机或用户试玩通过。

## 实际检查方式

在Unity 6000.3.25f1图形编辑器中加载真实M6场景，使用产品`OperationDock`、`TabletopScene`及三维库存模型。独立`OperationSnapshot`只提供本人的显示夹具；检查前后权威存档逐字相同。鼠标事件进入原生游戏输入队列，由真实`OnGUI`及产品手牌事件处理器处理，没有直接调用选择回调代替点击。

编辑器输入使用与[Unity GameView实现](https://raw.githubusercontent.com/Unity-Technologies/UnityCsReference/master/Editor/Mono/GameView/GameView.cs)相同的`QueueGameViewInputEvent`，延迟到编辑器更新后派发。此证据属于**编辑器输入模拟**，并非物理鼠标、Android触控或用户试玩验收。

截图由`ScreenCapture.CaptureScreenshotAsTexture`从真实渲染画面读取，未生成或编辑像素。四种实际渲染尺寸为1440×900、1920×1080、2560×1080、2400×1080；每种检查空手、1张、5张、70张。最后一种通过仅编辑器可用的安全区覆盖，令三维HUD与二维界面共同使用两侧80像素、上下28像素的内缩。

## 结果

第8轮：**373项断言通过，18张截图，6次点击，右键与长按说明回调2次**。完整原始结果见[组件结果](组件结果.json)，本目录保存9张代表截图及[文件指纹](截图指纹.json)。全部原始截图、输入坐标日志在项目`.local/three-kingdoms-b45/dock-ui-8`及同级`dock-ui-8.log`。

| 检查 | 观察结果 |
| --- | --- |
| 空手、单牌、少量牌 | 始终从逻辑坐标342开始；手牌管理按钮固定在右侧 |
| 超量手牌 | 无正间隔，最小露出26逻辑像素；滚轮、横向拖动、滚动条共用同一偏移；滚动后可点末张 |
| 选中与排序 | 选中上抬22像素，保留原横向插槽；资源序号及发展牌身份不因标签切换、整理而改变 |
| 鼠标输入 | 按下不选择，松手选择；右键进入说明回调，不增减草稿；拖动不产生点击 |
| 长按模拟 | 0.5秒后进入说明回调；松手不再选择；滑动取消点击 |
| 权威边界 | 组件未产生模态窗口；选择、说明、整理、标签与滚动不改变权威存档 |
| 库存 | 上移至底部武将框上方；超过6组时排两列，保持银行与底栏空间 |

说明回调在此隔离夹具中用计数器观察；**完整技能说明卡的文字与位置须由完整M6交互证据另行验证**。同样，给定资源数量用于检查布局，不代表规则允许在某局持有70张同类资源。

独立.NET布局、输入模型及收牌动画检查150项，149项通过；唯一失败为历史`ProgressTreasonRemove`文案断言要求“叛变”，产品既有文案为“叛徒”，本轮未改该代码。结果保存在`.local/three-kingdoms-b45/b45-dock-animation.trx`。旧收牌测试的首牌居中预期按B4.5明确要求改为固定左起点，飞牌与落位坐标一致的断言保留。

## 视觉复查及限制

已实际查看1440×900的5张牌、选中牌，以及2400×1080超量安全区图。普通布局仅确认手牌紧贴、选中上抬、右侧按钮与库存框一致；1440×900图的左上骰盘仍有裁切，不能写为整个桌面布局正确。本夹具取出真实桌面后关闭M4/M6组件更新，以独立快照绘制手牌，因此三维骰盘/其他周边对象的完整相机定位不在已通过范围内，须以完整M6截图复验。安全区图主体模型与框对齐，但屏幕左侧内缩边缘仍能看到少量库存模型残影；可能涉及连续修改编辑器视口后的场景或渲染残留，**安全区视觉尚未完全验收**，必须在完整界面及Android真机复验，不能以断言通过消除此问题。

首轮及第3轮有真实布局图但输入未透传；第2、4轮受共享程序集/脚本编译中间态阻塞；第5、6轮输入注入时序未完成；第7轮找出绘制事件误记拖动的问题。最终修复为仅真实拖动或松手事件更新移动判断，绘制事件不改变手势状态。历史失败记录仍保留在`.local/three-kingdoms-b45/dock-ui*`，没有改写成通过。

## 复现入口

```sh
source tools/development/Enter-DevEnvironment.zsh
"$UNITY_EDITOR" -projectPath "$PWD/Unity/Catan" \
  -executeMethod B45DockEditorVerification.Run \
  --b45-dock-verify "$PWD/.local/three-kingdoms-b45/dock-ui-repeat" \
  -catan-mobile-ui \
  -logFile "$PWD/.local/three-kingdoms-b45/dock-ui-repeat.log"
```

需要图形编辑器，不能加`-nographics`。退出后以`result.json`和日志为准；此命令不构建或发布游戏。
