# 内测版 2.1.11 棋盘手绘重制（PC）

## 地形与接缝

森林、丘陵、牧场、麦田、矿山、沙漠、金矿、湖泊、海域和迷雾各占一幅 1024 × 1024 画面。四种规则模式共用 4096 × 4096 图集。Blender MCP 制作的六边底板边长 40 毫米、厚 8 毫米。顶面铺到规则顶点，陆地交界的约 4.8 毫米范围按两侧公开地形混色，遇到第三块地形时使用同一套权重。

码头的靠岸端收窄，给两端的聚落与城市留出占地，海侧保留货物标识。六类交易港采用同一组栈桥、货物徽记和兑换比例。六处渔场共用鱼群与渔网画稿，数字圆片独立定位。港口与渔场的水色透出动态海面。湖泊保留 2、3、11、12，红色 6 和 8 与其他号码共用字体，圆片底部的小点表示组合数。海面、礁石、航路奖励、蛮族航程板、航海剧本图签，以及主要玩家棋子和中立棋子的表面颜料一起更新。

## 画稿与排版

使用内置 imagegen 生成画稿。母稿的提示词为「正俯视历史策略桌游地图，细笔水粉与铜版刻线，统一漫射日光，哑光颜料，九宫格满幅地形，不画外框、文字、点数或投影」。再以母稿为参照，逐幅扩绘每种地形，另绘海雾。

港口提示词为「青绿水面，沙岸在下缘，左右木栈桥，一艘靠岸货船，上方留出货物空间」。渔场提示词为「左翼银金鱼群，中央渔网和芦苇浮子，右翼留给点数」。货物为透明背景的木材、砖块、羊毛、麦束、矿石和商船。航程板使用长船与岸防小人，剧本图签使用村舍、堡垒、滩头、奇观、礼箱、战船、海盗船和旗帜。数字、概率点、兑换比例与蛮族航程位置由排版生成。

## Unity 验收

基础版和城市骑士各核对 42 条公共边，航海家和双扩展各核对 103 条。四局均检查顶面六个顶点、图集分辨率、每格公开地形与每个邻格编号。渔场通过 432 个凹凸岸、旋转和缩放案例，四局各连续刷新 20 次，检查显示对象复用、号码避让和存档一致性。

## Windows 构建

本轮仅构建 PC。游戏入口为 `game version/2.1/Catan2.1.11-Painted-Map/Builds/Windows/Catan2.1.11.exe`，同目录的 Server 提供本地房间服务。2.1 系列保留 2.1.7 至 2.1.11。
