# 王城与大都会石墙的实机对照

内测版 2.1.17，Windows，Unity 6000.3.25f1，Direct3D 11。四人双扩展开启三国、海港和捕鱼，地图为「穿越沙漠」。读取四席各有一座城市的对局，在原城址向棋盘绘制层分别置入哥特王城、哥特商会、冠冕议政宫和观星学宫，再给四座建筑同时筑墙。退出拍摄时复核了对局存档。[验收起点](../direct-input-2112/穿越沙漠四人验收起点.json) · [客户端校验结果](result.json)
