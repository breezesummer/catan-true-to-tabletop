# 2.1.4 技能阶段、发展牌生成与骄姿修正

日期：2026-11-03（Asia/Shanghai）。本次为内测版本更新，版本号 2.1.4。

## 规则依据

已阅读 `docs/PROJECT_BRIEF.md`、`docs/ROADMAP.md` 的当前阶段及 `assets/references/rules/README.md`。本轮为用户在 2026-11-03 明确修订的三国自定义技能，不将其表述为官方卡坦规则，也不虚构 PDF 页码。以下修订覆盖 B4／B5／B6 历史合同中的相反约定。

- 阶段描述未明确“任意玩家”“任意回合”或其他玩家时，限定技能拥有者自己的对应阶段。吕蒙的该技能在项目牌文中名为“涉猎”；与周瑜“英姿”一起限制为自己的摸牌阶段。
- 奇策仍在自己的回合开始、至少一张手牌时使用，弃置全部手牌后直接获得所选发展牌。每种牌只提供一个选项，无需提前选目标或满足该牌使用条件；“任意”包含分值牌，分值牌沿现有公开计分区规则落区。
- 当前 54 将包的奇策、灭吴的发展牌分支、协穆、疑城共用生成入口；获得后按正常卡牌操作。灭吴保留原有非分值牌限制、标记费用及随机摸一张奖励。资源／商品视为支付、国色与急袭的专属技能效果不属于现有发展牌牌种生成。
- 生成牌不从牌堆取出，使用或弃置后不回牌堆；间谍转移、奸雄取得、制衡换牌、技能弃牌及保存恢复均保留来源。普通实体牌仍正常回收。旧 B4／B4.5／B5 包的虚拟用牌实现保留，以维持旧包行为。
- 骄姿在支付前比较资源与商品总数，唯一最少时直接减一张并按实际库存自动选择可支付造价，最低一张，免费仍免费。道路、船、村庄、城市、城墙、骑士招募／升级、城市改良均接入。减费后的价格同时用于棋子入口、设施说明、合法预览和权威扣费。唯一最多的既有加费选择保留，城市改良按同种商品直接加费。

## 全技能阶段审查

逐项对照 54 将 97 技能牌文，并检查阶段调度、摸牌替代、开始／结束事件及主动技能入口。发现并修复英姿和涉猎两处范围错误。

| 范围 | 检查结果 |
| --- | --- |
| 普通出牌阶段技能 | 统一主动入口和 B3／B4／B5／B6 分支均校验拥有者为当前玩家及自己的出牌阶段；奋音、烈弓的事件计数同样有此限制。 |
| 普通开始／结束阶段 | 奇策、据守、镇骨、劫营、屯江、智盟及闭月按自己的开始／结束处理。 |
| 明示跨回合 | 突袭、天妒、替身、克己、连破、三陈、惑心、祸首、直谏及酒诗的回合外分支，保留各自明示范围。 |
| 指定对象的延迟阶段 | 间书、劫营、镇骨及被扣置设施的恢复按已指定对象自己的相应阶段结算。 |
| 非阶段事件 | 登场、成为目标、失去／获得牌、建造和入侵等仍依牌文事件触发；不将没有阶段限制的事件一律缩为自己回合。 |
