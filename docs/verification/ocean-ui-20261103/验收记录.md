# 2026-11-03 — 海洋主题界面与海岸环境

## 实现范围

- 将设置中原有“海洋”选项升级为独立图集主题：深海蓝面板、细黄铜边、波纹角饰、手牌框、武将框、技能按钮、资源圆片、滚动条和右下罗盘按钮。设置预览同步更新。
- 保留既有界面坐标、命中区域、棋子与手牌直接交互、回合按钮语义和所有规则适配器。仅为海洋主题调整库存文字、玩家名称和次级文字对比度。
- 连续海面新增双层缓慢流动的海水贴图及近岸碎浪；仍使用原公开海岸遮罩、海面水位、几何波幅及固定俯角相机。
- Blender MCP 制作四处屏幕边缘礁石的共享模型；保留FBX源旋转与单位缩放，使用灰岩贴图、湿润礁底和附近海水泡沫。四个实例共享1296顶点、2560三角形网格和一个材质，不带碰撞体，不加入棋盘取景边界。
- 保留铜木、骑士、青玉鎏金主题。正常验证会恢复原主题偏好；显式 `--keep-ocean-preview` 保留海洋主题及最后的可操作预览。

素材、概念图与复现说明见[素材说明](../../../art/recipes/ocean-ui-v001/素材说明.md)。

## 实际验证

- Windows Unity 6000.3.25f1构建成功；最终独立程序以1440×900可见窗口执行 `--ocean-theme-verify`。
- 基础、航海、城市骑士、新世界双扩展、三国双扩展五类四人配置，共 **45,405次断言通过，28张完整窗口截图**。覆盖默认／远／近取景、港口平移、公开地图拾取、相机投影、HUD固定定位、图集加载、礁石露出水面、着色器支持、无碰撞体、三主题切换、银行及玩家交易与设施入口、取消草稿和权威存档一致性。
- 海面动画的两次320×200采样分别有41,801／40,232／41,792／41,454／40,043个像素变化；静止地图的海岸遮罩修订均保持为1。这只证明动画和遮罩缓存有效，不是帧率基准。
- 已审看最终基础与三国完整截图、交易窗口及可见游戏窗口。通过 computer-use 实际点击银行、点选羊毛资源（数量0→1且对应手牌抬起）、Esc取消交易恢复手牌、右键查看手牌、关闭说明、点击顶部回合栏进入菜单，以及进入设置确认海洋主题入口，最后返回对局保留可操作预览。
- Windows源码完整性检查通过（当次2643项文本配置／脚本）；后续美术修正通过最终Unity双端编译和上述运行检查。针对本轮源码的差异空白检查通过。
- Android ARM64／IL2CPP／OpenGLES3构建及APK签名验证通过，版本2.1.6、版本码20106、最低API26。详见[构建信息](android-build.json)。

首次隐藏窗口运行没有绘制完整UI，因此未采用其黑图作验收；增加空白截图检测后，经用户明确同意改为可见窗口。另一次在构建进程尚未完全退出时提前启动预览发生资源序列化崩溃；待构建退出后重新启动正常，最终五配置验证及手动操作未再出现异常。验证器同时修正了临时模型组未先Begin就End的问题。初版规则短线海纹与礁石缩放问题已通过最终材质与FBX变换修正。

`result.json`沿用既有验证器字段；`fullUiPixelsVerified=false`表示未自动判定全部UI像素，手动视觉与交互检查以上文为准。没有把概念图、截图生成或自动断言宣称为逐像素100%还原；概念图局部比例与原游戏布局不同，本次以用户要求保留的原布局为准。

## 构建与边界

- 沿用内测版2.1.6，覆盖当前版本，归档目录改为 `game version/2.1/Catan2.1.6-Ocean-UI`。Windows入口为 `Builds/Windows/Catan2.1.6.exe`；Android入口为 `Builds/Android/Catan2.1.6.apk`。随包Server保留当前版本原服务，规则与网络源码未变。
- 正式归档的exe、资源包、界面程序集与APK均与本轮预览构建逐项SHA256相符，见[构建摘要](build-hashes.json)。二级版本目录保留五份构建，本轮无需删除旧版。
- 未正式发布或部署云端，未修改版本号。Android真机触控、整机帧率和四设备外网没有在本轮重测。
