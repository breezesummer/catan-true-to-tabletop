# 资源牌重绘与四主题卡框验收

## 实施范围

五种资源手牌采用用户确认的原版重绘图，原照片与牌背保留。卡框分别使用铜木棕铜、海洋青蓝黄铜、骑士冷钢银和青玉鎏金，统一应用于卡面显示入口；选中勾选、抬升、命中区域和规则不变。

素材来源和导入方法见[素材说明](../../../art/recipes/resource-redraw-v001/素材说明.md)。运行时五张卡面合计约4.75MiB（含mipmap），不保留CPU可读副本；切片只在编辑器导入时执行。
