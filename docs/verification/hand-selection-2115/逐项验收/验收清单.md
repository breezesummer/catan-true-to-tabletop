# 武将与发展牌逐项实机验收

日期：2026-11-13。内测版2.1.15。四人「双扩展＋三国＋海港＋捕鱼模式＋穿越沙漠」。

此前真实鼠标验收只覆盖李儒，不能据此声称其余武将和发展牌均已实机通过。本次补充21个场景，每项均用真实Windows窗口进行“选中→再次点击撤选→重选→确认”，由正式UI提交权威命令，并核对确认后的牌数、待决或骑士等级。未确认时，验收入口同时检查权威存档没有变化。

局面由显式 `--selection-matrix-review` 隔离验收入口装配：通过实际本地宿主创建基础对局，再装配资源守恒、牌库守恒及合法棋盘目标，武将待决由正式技能引擎生成，发展牌待决使用原规则入口。不是从随机对局自然触发的完整全局试玩，也不代表所有武将、全部分支或四台设备联机验收。

## 本轮发现并修复

- 疑城：原流程在确认两张费用后出现独立「主教」用途按钮和下一轮确认。现仅有一个合法用途时，确认费用即弃牌并取得主教；多用途时才保留实际用途选择。已重新构建并复验。[修复前](徐盛-疑城-修复前.png) · [修复后](徐盛-疑城-05确认生效.png)。
- 间书：原先声明0、1、2张矿石的数字误用了资源类型，显示成木材、砖、羊牌。现显示「声明矿石 N 张」文字选项，命令中的数字含义保持原规则。已复验暗选可撤销、确认后数字显示正确。[修复前](贾诩-间书-修复前.png) · [修复后](贾诩-间书-05确认生效.png)。
- 伏骑额外检查了要求对方没有的牌：交易未成交且没有误扣双方手牌；随后重开隔离场景完成有效的一换二验收。
- 乱击抵御初次验收的夹具误将已抵御人数初始化为1，导致结果检查不匹配。夹具修正为0后，重新完成选中、撤选、重选与确认，实际为本人弃置1张矿石、袁绍领取1张麦子。没有把夹具错误算作游戏修复。
