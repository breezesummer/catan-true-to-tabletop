# 选牌撤销与确认

日期：2026-11-13。版本维持内测版2.1.15，联机协议维持3。

## 交互

- 焚城弃牌显示「请至少弃置 N 张牌」，资源与商品在原手牌中点击抽出、再次点击下沉。达到最低数量后，玩家选择确认，一次提交整批弃牌。
- 手牌旁移除「弃置选中的 N 张」用途按钮，保留原有的手牌旁确认与右下角入口，两者提交同一份选择。
- 结姻同步弃牌、筹策弃自己的牌、疑城费用、间书暗选共用本地草稿；前者按规定数量选牌，间书至少一张。疑城只有一个合法主教用途时，确认两张费用即直接支付并取得主教；存在多个用途时才保留用途选择。间书声明矿石数量显示为数字文字选项。
- 魄袭、连环及实体手牌／发展牌费用选择保留到确认；仁德继续以接收者头像完成赠牌。棋盘目标沿用现有直接操作。
- 伏骑要求的一至两张牌可以调整后确认。商港交商品可反复撤选；大商家逐张抽出和撤选所取牌；锻冶匠再次点击已选骑士会撤选，最后由确认完成晋升。

## 权威与兼容

数量上下限由本人投影提供，服务端重新校验窗口、待决、技能身份、持有数量及弃牌限制。未确认的选牌不发送命令，不扣牌、不占用随机数。整批确认继续通过原房间命令入口，保留命令去重与脱敏诊断。

旧逐张命令保留。已按旧方式选满的焚城待决，恢复后仍可重新选择。新增可选字段不改变旧客户端已有字段的含义，伏骑旧命令继续有效；间书暗选不向其他席位公开所选牌。
