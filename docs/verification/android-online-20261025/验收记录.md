# Android 在线大厅初始化修复（2026-10-25）

## 问题与定位

用户反馈 B4 安卓版在 Wi-Fi 和移动数据下均停留在“正在连接中”，PC 正常。使用原 B4 ARM64 APK（内测版 2.0.1）在 Android 15 / API 35 模拟器的 ARM64 转译环境中复现。

- 原包 SHA-256：`219cbc116dc7abbbb4467230ea5a1fe52f41ed4cf7f248fb0c0f3d321c0f33df`。
- APK 已声明 `android.permission.INTERNET` 和 `usesCleartextTraffic=true`。云端健康接口正常，协议为 3。
- 原包启动时，`M7Client.Awake()` 抛出 `NotSupportedException`：IL2CPP 不支持 `Assembly::GetManifestModuleInternal`。
- 异常来源是启动诊断读取 `typeof(M7Client).Assembly.ManifestModule.ModuleVersionId`，与规则、联网权限及手机运营商无关。
- 实际 `List` 请求在约 233 毫秒收到成功响应，后台解码完成；随后主线程未应用回包，界面持续显示正在连接，忙碌状态未解除。原包日志只有 `session_start`，没有正常的 `client_start`。

## 永久修复

修改共用源码 `Unity/Catan/Assets/Scripts/M7Client.cs`：启动日志使用 `Application.buildGUID`，避免调用 IL2CPP 不支持的程序集反射接口。该改动适用于以后所有由此源码构建的 Android 包，并保留 Windows 和 Android 的构建关联诊断。

不更改协议、传输、重试、命令幂等、隐藏信息投影及规则。版本号不变，本次不是正式发布，也不部署服务器。已安装的旧 B4 包仍需更新安装包才能获得源码修复。
