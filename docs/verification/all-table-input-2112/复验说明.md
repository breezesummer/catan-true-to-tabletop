# 逐项实机复验

打开本目录的「逐项验收.html」，输入武将、技能或牌名可筛选。在每一行点「操作回放」看鼠标点位和结算画面。金色圆圈标出实际点击位置。「结算画面」可单独放大。回放由实际点击帧组成。112 项有真实鼠标点击回放。另有 9 项由本局 AI 执行触发动作，袁绍「血裔」直接核对公开的资源阈值，这 10 项各有结算画面。

每项使用 Windows 客户端从同一份四人「穿越沙漠」存档独立开始。验收按项目准备武将、手牌或触发阶段；出牌、选目标与响应走游戏正常入口。被动技能由相应行动或对局中的 AI 自然触发。记录只对应表中实际走过的分支。

要复验，使用 Windows 与装有 Pillow 的 Python。将「验收局面.zip」解压到一个目录，在项目根目录运行下列命令。输出目录须为新目录，运行时让游戏窗口保持在前台。

~~~powershell
python tools/validation/verify_all_table_input.py "game version/2.1/Catan2.1.12-Recorded-Foley/Builds/Windows/Catan2.1.12.exe" "docs/verification/direct-input-2112/穿越沙漠四人验收起点.json" "D:/CatanQA/四人复验" "D:/CatanQA/验收局面"
~~~

如果只复验指定项目，可先设置环境变量。例如 `$env:TABLE_ITEMS='CommercialHarbor,tk-g07-s1'` 只运行商港和于吉「蛊惑」。清除该变量即可运行全量。查看输出目录里的「逐项结果.tsv」判断每项是否完成。
