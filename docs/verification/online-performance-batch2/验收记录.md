# 联机性能第二批实施与验证

日期：2026-10-25（北京时间）。完成[优化方案](../../ONLINE_PERFORMANCE_OPTIMIZATION_PLAN.md)第二批 P4、P5 的工程实施与本机后台／兼容检查。推送等待的 50ms 初始目标尚未达到；Android 运行检查被自动审批拦截。前台体验、四设备、长局和弱网仍属于 P6，不能据本记录宣布全部性能目标通过。

版本仍为内测版2.0.2。候选包位于 `game version/2.0/Catan2.0.2-Online-Performance-Batch2/`，没有正式发布、切换云端或推进 M7／M8。规则核心、AI 源码与权威存档格式未改变。

## 实施内容

P4 先独立提交为 `5decf656`：持久化成功后登记变更，房间锁外通知订阅，采用每连接一个唤醒与10ms合并窗口；750ms周期检查保留兜底。AI、超时托管、重开、连接替换、离开与保存恢复都可唤醒推送。拒绝不制造新修订，保存失败只通知已保存的回退状态与暂停结果；回退同时清除未提交视图的投影缓存。收尾补齐不改变修订号的连接轮换及等待房间在线变化。

P5 在既有协议3中通过 `Sync` 主动协商。旧请求与旧根字段保持原形状，新连接用既有 `ViewJson` 携带完整席位快照或字段／稳定实体键差量。每条连接独立维护房间、席位、连接、对局、状态基准、地图指纹、状态校验与事件版本。雾岛只处理所属席位已获准看到的变化，不缓存权威隐藏内容。

待发送队列合并的是完整投影；真正发送时才相对于实际已发送基准计算差量。命令回执优先且保序，快照只有一个待发送槽，回复队列最多8条，另设8MiB正文缓冲预算。慢客户端独立超时或进入完整恢复，不能拖住其他席位或静默丢弃回执。

展示事件从完整可见历史计算差量，普通命令按序号、技能按稳定 `SkillEventId` 去重和替换，覆盖同命令多事件与同事件结果补写。恢复时同时补齐状态和事件；普通同修订 Get 不提前开放操作，迟到历史页不回退技能结果，等待房间不等待不存在的游戏视图。重连后即使修订相同，也等待新连接的完整事件覆盖。

针对投影计时中发现的额外转换开销，增加同字段合同的直接 JSON 写入，应用于可见视图、历史与增量封装；保留原 XML 编码／解码作兼容对照。新旧严格解码、可选字段、转义与席位隔离通过；Android反射DTO显式写入 `link.xml`。完整合同和回退参数见[席位同步说明](../../ONLINE_STATE_SYNC.md)。

## 四席字节与等待测量

第一批源码基线为 `ce0503e7`，不是14点的B4现场二进制。这里的字节对照在同一新服务、同一权威组合地图和相同提交上完成，两组各四条真实回环 WS 分别观察原全量路径与增量路径；不是两个不同地图或不同构建的平均值。

见[最终测量](四席同步测量.json)及[探针源码](../../../tests/Catan.Server.Tests/IncrementalTransportTests.cs)。40条命令直接交给正式房间入口，两组都计入相同命令回执的编码正文；保存接口为空存储，专测字节与提交后调度，不能用于声称磁盘保存成本降低。首次入桌单独列账；预览、独立历史请求、心跳、HTTP／TCP头与真实网卡出口不在本脚本内。

| 指标 | 结果 |
| --- | ---: |
| 原全量路径正文 | 6,249,196字节 |
| 增量路径正文 | 752,097字节 |
| 正文减少 | **87.96%** |
| 两组共同观察时，提交后入队 P95 | 56.728ms，320个样本 |
| 仅四条增量连接，提交后入队 P95／P99／最大 | **63.294／64.329／64.514ms**，120个样本 |
| 四条增量连接，操作入口至探针收包／复原 P95 | 76.172ms，120个样本 |

最后一项包含命令处理、发送和探针通用差量复原，不包含 Unity 主线程应用、显示刷新或首个可见像素，不能当作点击到动画的结果。纯四流阶段额外执行30条动作，四席始终与权威 Get 的类型规范化结果一致。断开并重建一条流后，第一份回复重新给完整快照，无需重复执行命令。

50ms目标仍未通过。中间样本的同一四流口径P95为69.033ms，见[中间测量](中间四席同步测量.json)；收尾没有删除该结果。分段日志显示剩余时间集中于房间锁等待与席位投影，代码中仍有可见视图深复制和合法动作枚举；本轮没有取得这些内部函数的逐项CPU调用栈，不把推断当作精确归因。P6需在固定设备、实际前台和网络条件下继续测量，不能通过移动计时点、取消磁盘确认、暂停AI或缩短动画制造达标。

初次同步的正文另外保留在测量JSON中，包含握手与首次推送，份数会受时序合并影响，不用这两个总量宣称单份初始快照的比例收益。87.96%仅适用于本脚本，不等于B4旧二进制整局、4Mbps网卡出口或多房间容量结论。
