# 2026-11-01 界面与捕鱼交互修复

## 修改范围

- 调整三颗骰子的尺寸与位置，事件骰留在骰盘内。
- 自己与各玩家面板使用统一鱼图标，在发展卡下显示鱼牌张数／7。规则已有七枚鱼筹码上限，本轮未改规则；支付仍按面值合计。
- 三张鱼牌主图分别绘制一、二、三条完整鱼，移除底部说明区，保留左上角面值；按用户追加要求废弃底部小鱼符号方案。
- 最长道路与海港大师加入分隔线，归属文字按区域缩放、裁切；历史栏同步下移，避免盖住奖励。
- 铜框九宫格各切片按实际屏幕像素对齐，消除缩放后的拼接黑线。
- 捕鱼行动统一使用“偷取手牌”“任意资源”“新建道路”“发展卡”；未选择目标时不显示“选择行动”和取消，实际选择后显示确认、取消。
- 鱼建路复用绿色发展卡的道路／船定位与预览逻辑，不在棋盘上铺设路／船按钮；落点只产生支付草稿，确认后才提交权威命令。
- 建筑库存整格命中，棋盘投影与实体落点使用同一高度，建筑及虚影在港口叠板上方；静止悬停继续显示预览。
- 共用按钮、直接交互手牌、建筑库存和有效棋盘预览使用手形鼠标。触屏不显示鼠标。
