# 内测版2.1.15：武将、发展牌与取牌交互修正

本轮覆盖当前 Windows 程序与随包房间服务，版本号保持2.1.15。界面主验收采用四人「双扩展＋三国＋海港＋捕鱼＋穿越沙漠」，另以基础版、城市骑士、双扩展的隔离局面验证发展牌使用。

## 行为

- 祸首只提供发动与跳过，不再选择骰点。发动后公开显示红6、白1、黑色事件骰；没有掷骰动画、滚动声、随机数消耗或观星／鬼才响应。回合结束直接点地图移动强盗或海盗，涉及偷牌时点玩家头像。
- 再起只列出本次事件实际可执行的效果，同一效果的多个城市合为一个入口。先选效果，再按提示点村庄升级或进入银行取牌；只有失分满足条件时也保留玩家选择。
- 烈弓及同类技能的棋盘目标不再形成文字枚举框；建筑、道路、城市设施沿既有地图与设施图标操作。烈弓的两道路分支保留明确入口和逐条选路提示。
- 发展牌左键查看完整卡面，重复点击不使用卡牌，右键不弹说明。右下角原有主按钮切换为「使用」，由同一权威用牌入口继续结算。查看卡面时隐藏会盖住牌面的行动提示和中央武将演出；拿取其他组件或关闭预览后恢复。
- 30种发展牌逐张标定左上图标右缘与右端花纹左缘之间的实际顶栏。牌名按可见字形边界居中，校正字体行框与字形之间的偏差，保持上下、左右成对等距；字号同时约束于顶栏高度和宽度。标题和描述统一采用项目内置 `NotoSerifCJKsc-Regular` 的宋体字形与粗体。
- 共用取牌框只显示资源／商品牌与右侧的数量，标题为随选择更新的「请选择资源0/2」，居中放大并避开边框。游戏内主菜单保持居中并缩小三分之一。修路主入口与遗留资源统一使用已验收的木槌录音。

- 牌名逐张居中修正后另通过157项实机定向检查。在1920×1080原尺寸画面中测量30张牌的黑色字形边界，相对标定顶栏的左右边距差最大1.72像素、上下边距差最大1.66像素，处于字形栅格化的2像素范围内。
