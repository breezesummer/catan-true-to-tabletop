# 1.6.6 操作面板与历史播报

日期：2026-10-18。构建目录：`game version/1.6/Catan1.6.6-Operation-History-Polish`。本轮为内测迭代，未创建正式发布版，未改变阶段退出状态。

## 行为与范围

- 资源支付使用“使用了”，产出使用“收获了”；开局按实际棋子显示“建造了开局村庄／城市／道路／船”。
- 城市设施建造合为“玩家使用了〔商品〕建造了〔设施〕”。十五个名称逐一对照现有中文实体卡面；贸易、政治、科学名称分别用黄、蓝、绿，发展卡也使用其所属轨道颜色。对手未公开的发展卡仍只显示通用名称，不推断颜色。
- 偷牌、间谍、行会征费、垄断、征税和婚礼赠礼合并收付双方。偷牌显示双方姓名及张数；婚礼显示“收取了某玩家交出的婚礼礼物：〔卡牌〕”。只有观看者已获准读取的牌种会显示卡面。
- 同一骑士从激活变为休眠只记录一次，多个骑士按玩家合并；棋子移动导致位置变化时仍识别为同一状态转换。
- 操作面板提供“收起”，在右下角回合按钮显示继续操作的提示。保留本地草稿与权威待决；点击继续后重开。新命令或换座会清理旧的收起状态。地图观察与实际提交仍分别受控。
- 查看历史、切换资源／发展卡和整理手牌不再受展示动画的行动锁阻挡。其他玩家的金矿或引水渠选择不会遮挡本人的界面；规则指令仍只接受有权限的当前行动者。
- 金矿和引水渠机会出现时播放已有的三段上行钟声。持续等待、重复快照、重连与读档不重播旧机会；音效模型只读取所属视图，不访问随机状态或隐藏手牌。
- 锻铁匠先预览所有合法的有序的两名骑士组合，有组合时选两名，否则选一名。预览包含先晋升高阶骑士释放库存的顺序；首个目标不会提前消耗卡牌。最终使用同一权威命令提交，规则中的一至两名合法范围不变。
- 创建联机房间时，房主选择第一个非 AI 颜色。配置中把房主颜色交给 AI 时，房主顺延到空闲人类颜色；不能覆盖其他人类或把全部颜色设为 AI。身份凭据、保存恢复及房主权限继续有效。AI 颜色按钮与空席选色按钮使用对应棋子颜色。
