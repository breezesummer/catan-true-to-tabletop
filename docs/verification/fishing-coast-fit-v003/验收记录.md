# 渔港凹凸海岸自适应贴合

2026-10-31。用户指出上一轮渔港离岸、方向错误，并明确允许渔港覆盖普通港口。本轮修正显示层，版本仍为内测版2.1.1，未发布或部署。下面是自动验证和游戏内截图，外观等待用户确认。

原先沿用小型标记的向海偏移与避让港口逻辑，又仅按一个朝向旋转V形板，导致实际接岸边没有贴住板块。现移除这套偏移、最小间距与港口避让；位置直接来自公开渔港的三个关联顶点，即两条海岸边。

通过Blender MCP为每块渔港补充六个接岸锚点。凸岸使用V形板的凹口，凹岸使用另一侧的外尖；按实际两边长度计算水平缩放和旋转，板面保持向上，不镜像照片，厚度仍为1.5毫米。接岸处向陆地覆盖0.75毫米，以消除现有地块倒角和板缝；普通40毫米边长棋盘上，渔港约69.28×50毫米。原始模型的42×30.31毫米属于制作参考尺寸，运行时按海岸匹配，不再当作固定占地。

渔港底面为棋盘表面上方0.5毫米、顶面10毫米，既有港口顶面9.6毫米，重叠处渔港在上。渔港无碰撞体，不改变普通港口的贸易资格、点击目标或规则关联点。没有修改规则、网络、存档和随机状态。
