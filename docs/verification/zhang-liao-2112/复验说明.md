# 张辽「登锋陷阵」实机验收

使用内测版 2.1.12 Windows 客户端，在四人双扩展、三国、海港大亨、捕鱼的「穿越沙漠」局面验证。将张辽安排在本席，通过游戏的技能提交入口选择少收两张并指定两名玩家。客户端核对该技能只新增一次完成记录，公开结果为实际获得两张手牌。全桌和近景取自同一次实机录制。

## 素材

人物取自本机无名杀的 `extension/十周年UI/assets/dynamic/张辽/登锋陷阵/XingXiang.skel`，骨骼版本为 Spine 3.6.38。待机使用 `DaiJi`，64 帧循环；突袭使用 `GongJi`，66 帧播完。两段各自保留原动作时长，分别为 80/30 秒和 82/30 秒。战场背景取自同目录的 `BeiJing.skel`。

手杀动皮的魏国顶弧取自 `extension/皮肤切换/images/border/wei.png`。该扩展的 `js/core/skin-switch-core.js` 创建势力顶弧，`js/modules/skin-utils.js` 按明置和动皮状态显示它。人物遮罩按顶弧内缘烘焙。人物移出后，战场背景和顶弧继续显示。

## 复验

解出项目既有的 `docs/verification/all-table-input-2112/验收局面.zip` 中的 `tk-g01-s1.input.json`。从项目根目录运行以下 PowerShell 命令，将两个目录变量指向验收局面和新的输出目录。

~~~powershell
$fixtures = 'D:/CatanQA/验收局面'
$output = 'D:/CatanQA/张辽动皮'
$start = (Resolve-Path 'docs/verification/direct-input-2112/穿越沙漠四人验收起点.json').Path
& 'game version/2.1/Catan2.1.12-Recorded-Foley/Builds/Windows/Catan2.1.12.exe' -force-d3d11 -screen-fullscreen 0 -screen-width 1440 -screen-height 900 --ocean-view-verify $output --zhang-liao $fixtures $start
~~~

保留可见窗口直至录制结束。结果目录包含 `result.json`、三张原始截图及按实际采样时刻命名的完整窗口帧。
