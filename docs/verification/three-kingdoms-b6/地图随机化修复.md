# B6地图随机化修复

日期：2026-10-27。沿用内测版2.0.2，覆盖本地B6开发包；不部署、重启或连接云服务器，不干预正在进行的对局。

## 原因

房间的创建与重新开始都会通过 `RuleRoomGame.Create` 抽取新的随机种子，不是沿用了昨天的房间缓存。双扩展 `CombinedScenarios.CreateSeeded` 只为驶向新海岸、穿越沙漠实现完整地形／数字随机化，其余七图转到航海家旧生成器。旧生成器仅对新世界随机生成地形，部分剧本只洗港口。因此四岛无论换房、跨日或重新开始，地形和数字都相同。

## 全图排查与处理

| 地图 | 修复前双扩展 | 修复后新局 |
| --- | --- | --- |
| 驶向新海岸 | 地形、数字、港口随机 | 保持原生成算法 |
| 四座岛屿 | 完全固定 | 四岛陆地池和数字随机，森林／牧场避开2、3、11、12，港口随机 |
| 迷雾岛屿 | 已揭晓地形固定，探索池另行洗牌 | 已揭晓陆地、数字和港口随机，迷雾位置与探索池不变，允许红数字相邻 |
| 穿越沙漠 | 地形、数字、港口随机 | 保持原生成算法和沙漠屏障 |
| 被遗忘的部落 | 地形数字固定，只洗奖励港口 | 主岛地形数字随机，东侧三格避开5、6、8、9；外围岛屿、奖励位置固定 |
| 卡坦的布匹 | 地形数字固定，只洗港口 | 大岛地形数字随机，小岛、村庄数字与布匹位置固定 |
| 海盗群岛 | 地形数字固定，只洗港口 | 保持原状；官方不建议此图变体 |
| 卡坦奇观 | 地形数字固定，只洗港口 | 主岛地形数字随机，沙漠旁两格避开6／8，小岛、沙漠、奇观标记固定 |
| 新世界 | 已随机生成自由地图 | 保持原生成算法 |

同源问题也影响单独航海家模式，已让新局采用相同布局算法。基础版和城市骑士没有经过上述固定剧本分支，不受本缺陷影响。地形轮廓、Tile／Vertex／Edge ID保持稳定；不改变同步频率、消息格式和隐藏信息投影。

规则依据：本地 `catan-seafarers-2025-en.pdf` PDF第7页（四岛）、9页（迷雾）、13页（部落）、15页（布匹）、17页（海盗群岛不推荐变体）、18页（奇观）；此前两图的第4–5、10–11页算法保持原样。布匹强盗起点从12点格中确定性选择，延续自动开局方式。

## 存档与联机边界

新增双扩展地图身份 `m5-combined-variable-all-2025-v004` 与航海家存档身份 `m3-seafarers-variable-v002`；原有地图身份继续调用旧生成器，不能用新算法重建旧存档。原有两图、新世界、海盗群岛的双扩展地图身份不变。房间握手协议保持兼容，云端由服务器产生权威地图；客户端不会自行改写服务器的地图。

覆盖客户端不会让尚未更新的云服务器立即采用新算法。云端新局的修复须等待之后用户允许部署，本轮不部署。现有存档／重连保持原地图，新建局／重新开始才采用新算法。
