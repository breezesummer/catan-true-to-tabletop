# 内测版 2.1.7 海洋主题细化

## 改动

- 海面交叉采样、缓慢扭曲与大范围明暗变化，降低饱和度与同向重复感；近岸浪花改为断续片状白沫。
- Blender MCP 重建主礁和碎石层次；四处礁石共 5,120 三角形，较上一版减半。岸线随礁石旋转并加入扰动；灰岩三平面投射使用同一坐标空间。
- 面板中央改为缓存的半透明深蓝渐变，保留图集边框；小圆片增加黄铜宽边与倒角明暗。
- 海洋主题玩家名提亮；历史字号从 11 调为 13，并在主题变化时重新计算排版。
- 原有布局、命中区域、规则与通信逻辑不变。

- 源文件完整性：2,645 项通过。
- Windows 可见窗口：基础版、航海家、城市与骑士、双扩展、三国双扩展，共 45,406 次断言通过、28 张截图。覆盖缩放、拖动、海面动画、公开海岸遮罩、礁石无碰撞、主题切换及交易入口。
