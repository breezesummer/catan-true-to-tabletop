此处保留 1.6.13 初次构建的记录。用户随后要求同版本覆盖为交易风格，并增加交易资源牌自适应；当前产物及截图以[覆盖更新验收](../trade-window-style-1.6.13/README.md)为准。

## 本轮行为

- 发展卡预览的“使用”直接执行无参数效果：道路建设、灌溉、采矿、商业港口、鼓舞、婚礼及破坏。需要地图目标的卡直接进入地图选择；商船队、垄断、炼金术等保留必要的效果选择，均通过原指令入口。
- 发展卡效果窗口居中，操作窗口统一主页的纸色、森林绿、金线和中文字体。骑士菜单移除重复长说明；道路／船选择只显示两项。局部菜单打开时暂时隐藏大号地图提示，收起后仍保留必要选择提示。
- 四种规则均可右键己方村庄升级城市；城市与骑士及组合规则可右键城市修建城墙。资源不足、对手建筑和重复城墙不会改变局面。
- 出牌动画从上到下为头像、姓名及动作文字、卡牌。公开胜利卡仍收回所属头像；五种窗口比例验证卡面宽高比，包含手机横屏尺寸。
- 鼠标预览区分村庄、城市、城墙、骑士等级及激活状态、道路、船、强盗、海盗、商人、港口和普通目标，修复骑士误显示村庄等问题；相同目标复用预览，刷新棋盘清除旧预览。
- 收获文字、资源／商品／进步牌飞牌与收牌音效共用骰子实际落定时间。头像、手牌页签和银行库存也延后更新；骰子展示期间阻止建造、交易和升级。联机历史早到不提前显示、迟到不重复等待。
- 抽到公开胜利卡时，旧视图期间不消费新收牌历史；卡牌退场、应用新视图后再播放飞牌与收牌声，避免丢失动画。
