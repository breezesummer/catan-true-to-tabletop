# 地块常态流光验收

日期：2026-11-10。Windows 内测版 2.1.13，覆盖当前构建。

使用四人「双扩展＋三国＋海港＋捕鱼／穿越沙漠」第 42 回合存档。194 项检查通过，保存 9 张离屏相机场景图。初次隐藏窗口的整窗捕获为空，随后改用项目既有离屏相机完成画面验收；不将初次捕获计为通过。

检查覆盖资源地块、金矿、湖泊、沙漠、海面、未揭示地块的产出分类，单村庄、双村庄、城市、其他席位，以及升级、降级、建筑移除和换席位。逐块检查正式棋盘材质属性，核对常态颜色、隐藏及恢复地图标记和权威状态前后一致。翡翠、金色各保存四个间隔 0.6 秒的连续画面；金色不再依赖收牌历史或计时闪光。

常态产量根据本人当前村庄和城市计算，城市的资源与商品合计为双份；同格多个本人建筑的份额累加。湖泊保留捕鱼产出流光。强盗危险标记继续优先显示。此处表达建筑常态产出，不预测银行短缺、临时技能选牌或替代收获结果。

光带使用深玉底色、双层亮边、环绕高光、渐隐光尾和轻微明暗变化，复用地形材质与单一共享时钟。动画在 GPU 完成，每帧不扫描结算历史、不增加网络消息。未执行四设备联机或 Android 真机性能验收。
