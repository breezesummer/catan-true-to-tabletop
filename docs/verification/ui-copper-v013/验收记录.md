# 铜木桌游 UI v013 验收

日期：2026-10-28。版本：内测版2.0.2。用户要求按参考图实现完整UI、保留棋子模型，仅构建PC。

## 实现范围

统一顶部功能栏与回合铭牌、玩家卡、骰盘镶边、蛮族与最长路线面板、历史窗口、竖向库存、数字底板、手牌铜框与底托、回合按钮、交易与城市设施窗口、弃牌与资源选择等共用操作面板。三国选将、武将区、技能按钮、费用用途、响应候选及说明窗口使用同一外观。主菜单的开局、加载、设置、联机共用控件与暂停菜单同步换肤；主页背景及现有卡牌、头像、模型继续复用。

库存沿左侧排一列，使用原有透明缩略图及轮廓命中，棋盘上的三维棋子不变。保留底部武将及技能、手牌左齐与滚动、右侧手牌管理按钮；参考图没有三国技能区，因此没有删除这些现有功能。去掉出牌条重复的操作介绍与第二行技能历史，避免窄条文字压住边框，完整技能结果仍在历史中。

## 实际验证

- 最终手牌组件检查：372项断言通过，18张实际GameView截图，6次点击与1次右键说明；覆盖1440×900、1920×1080、2560×1080及2400×1080模拟安全区，0／1／5／70张手牌、横向滚动、末张选择、跨页签选择与整理。
- 最终三国交互检查：180项断言通过、36次原生GameView事件点击，覆盖仁德取消与提交、制衡、国色、魄袭私密选择、被动技能说明和龙胆两张实体砖的普通造路支付。
- 地图输入限制：首轮不启用目标定位夹具时，编辑器原生事件未选中造路目标，支付确认没有执行；最终复验显式使用已有 `--b45-allow-target-fixture`，只将地图目标送入真实草稿，选牌、用途与确认仍通过GameView事件。不能将此项写成Windows实际鼠标地图命中通过。
- 完整外观检查：真实GameView取得15张截图，覆盖主页、开局三步、加载、设置、双扩展桌面、暂停、历史、银行、设施、行动界面及三国选将／宽屏。已人工审看主要桌面、银行、选将、设置、开局页面，未出现遮挡主要操作的铜边；库存边界检查通过。
- 新素材缓存复用，绘制只在Repaint生成像素指令，无每帧纹理生成或网络同步。未进行Windows硬件帧率基准，不据编辑器结果承诺帧率。
- 编辑器启动曾记录Unity搜索索引的 `ArgumentOutOfRangeException`；实际验证继续完成，非游戏业务异常。新验收脚本编译期发现内部成员访问不可见，已改用测试反射后重新运行通过。

结果文件见同目录JSON。原始截图与日志保存在 `.local/verification/copper-ui-v013/`，最终批次为 `final-hand`、`final-interaction`、`final-full`。截图不上传Git。

## PC构建

构建目标为Windows x64客户端与随包本地房间服务，输出目录：`game version/2.0/Catan2.0.2-Copper-UI-PC-20261028/`。Windows客户端与win-x64自包含房间服务均构建成功。Unity检查通过：47张卡牌原始比例、五种窗口卡面比例、53张关键界面贴图（含本轮木纹）、26张地图／4张玩法封面／7张主页原画与标题；规则DLL在Unity内执行、AI命令与权威存档往返检查通过。1959个Unity源文件完整性检查通过。

客户端入口：`Builds/Windows/Catan2.0.2.exe`，必须连同同目录依赖分发。可直接分发同目录 `卡坦岛之三国争霸内测版2.0.2-PC.zip`，约553 MiB；包含514个归档条目，压缩包完整性校验通过，大小与SHA256见[PC构建结果](PC构建结果.json)。

本轮没有构建Android、正式发布或部署云端，版本保持2.0.2。Windows实机安装与地图鼠标命中、完整多人外网对局、Android真机均未在本次验收；不推进B7整体验收结论。
