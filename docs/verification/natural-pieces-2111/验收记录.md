# 2026-11-05 自然四色棋子接入

沿用内测版 2.1.11，覆盖 Windows 客户端。此次交付包含村庄、王国主城、道路各四种玩家颜色，共十二个预制体与十二张透明缩略图。新模型用于基础、航海家、城市与骑士、双扩展的棋盘、库存和建造预览；已有城墙与新主城组合。规则、协议、隐藏信息与存档结构未修改。

## 视觉与资源

- 村庄采用双坡屋顶与相连的小屋，主城采用中央高塔、错落副塔和低层门厅；道路为薄石铺面与着色边石。四色保留自然墙面和木构，仅替换屋顶、边石。
- 四色共享三件网格，每件一个渲染器、最多三个材质槽。村庄 10,540 三角面，城市 37,899，道路 2,684。来源为 Blender MCP，制作与材质提示词位于 `art/recipes/natural-pieces-v001/`。
- 移除新建筑的旧顶点四毫米展示余量，底面落到棋盘 0.008 米高度；道路长轴与现有边朝向一致。库存道路使用更高俯角展示石铺面。
- Unity 截图：`四色棋子-58度.png`、`四色棋子-66度.png`、`四色棋子-82度.png`、`四色棋子-90度.png`。其中最上一行为新主城与旧城墙的组合，后三行为道路、主城、村庄。这是独立资产排布，不是规则局面。

## 检查结果

1. Blender 源网格与独立 FBX 回读：三件均为单网格，三角面数一致，UV 存在；退化面与 UV 越界均为零。数据见配方目录 `geometry.json` 和 `fbx-roundtrip.json`。
2. Unity 6000.3.25f1 源码完整性检查通过 2,898 个文本配置与脚本，Windows 构建通过，随包 Windows 房间服务构建通过。
3. 实际 Windows 客户端四种四人对局通过 669 项检查，验证地图落地、四色共享网格、正确配色、材质与缩略图存在、合法／非法预览、无新增碰撞、预览不改变权威存档，以及城市和城墙的组合。生成 17 张完整窗口和独立相机截图，见 `result.json`、`player.log`。
4. 复用现有棋子回归脚本并以 `--natural-components-only` 限定受影响的村庄、城市和带城墙城市：40 个实例通过，生成 8 张相机图，见 `component-regression/player-components-verification.json`。全量旧脚本在本轮未改动的骑士激活标记断言上停止，不宣称整套历史美术回归通过。
5. 使用 computer-use 在实际窗口查看了四色棋盘，执行滚轮缩放、Tab 俯视／斜视切换以及村庄点击；未执行消耗资源的升级。自动报告里的通用注释描述自动采样范围，此项人工窗口检查单独记录。

基础版固定种子 1，未启用捕鱼；航海家种子 56、双扩展种子 97、城市与骑士种子 17，后三者启用捕鱼。初轮隐藏窗口截图无效，已改为可见窗口重拍；初轮随机基础局遇到现有强盗位置为空的界面异常，本次定向检查采用上述固定合法局面，未扩展修改该规则／界面路径。最终 `player.log` 未出现异常。

本轮为本机 Windows 美术与相关交互检查；未做 Android 真机、四设备外网或性能长局验收。概念图的雕刻、瓦片不规则度和小摆件做了可读性简化，最终外观由用户在游戏中验收。
