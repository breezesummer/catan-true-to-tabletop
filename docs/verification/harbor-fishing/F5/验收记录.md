日期：2026-10-30（Asia/Shanghai）。实施范围为遗忘部落、卡坦布匹、卡坦奇观、新世界捕鱼，以及海盗群岛海港大师；以[实施方案](../../../海港大师与捕鱼实施方案.md)和[F5规则说明](../../../harbor-fishing/F5规则说明.md)为准。本轮不发布安装包、不部署云服务、不改发布版本。

## 发现与修复

- 布匹沿用两轮开局判断会在第二、第三轮重复发鱼，已改为读取剧本开局轮数，仅最后一轮发鱼，并补独立案例和12种正常完整局。
- 真实产出进入满额换抽时，航海通用校验缺少`FishReplacement`阶段，并把待决受益人限定为当前行动玩家。已补齐阶段和实际受益人；4个真实掷骰案例、2个部落港口恢复案例及17项受影响回归通过。布匹与新世界受影响的4人航海完整局已定向重跑。
- 初轮专项夹具曾遗漏双扩展首次蛮族标志、误用区域奖励分，以及遗漏海盗要塞预留村庄计数。已调整夹具以遵守生产不变量；最终上限案例覆盖3／4人、航海／双扩展四种配置。未用放宽生产不变量的方式通过夹具。
- 早期部落港口专项使用默认目标，可能在领取港口前获胜，因此专项改为种子1、目标20；正常完整局仍维持种子97与默认目标。

## 通信与性能边界

沿用现有命令、增量编码和有界队列，没有加入逐帧消息、重复全量同步或新队列。新世界渔场只在最后一个港口提交时完成一次；预览与重复命令不推进权威随机。四席测试验证对手鱼面值／Token ID、供应顺序和内部待决信息不泄漏。

网络测试记录两次支付×四席的增量与完整视图／历史字节数，以及两次权威提交耗时，具体数值见测试结果。这是同进程单次样本，测试并发可能影响耗时；不能据此推断公网延迟、设备帧率或长期性能。没有修改高频渲染或底层传输路径。

## 复现与后续

本地原始TRX位于`tests/Catan.Rules.Tests/TestResults/`、`tests/Catan.Network.Tests/TestResults/`；日志位于`.local/development/harbor-f5/`。复现F5规则与网络检查：

```sh
source tools/development/Enter-DevEnvironment.zsh
dotnet test tests/Catan.Rules.Tests/Catan.Rules.Tests.csproj -p:UseArtifactsOutput=false -p:DirectoryBuildPropsPath="$PWD/Directory.Build.props" --filter FullyQualifiedName~FishingThirdWaveTests
dotnet test tests/Catan.Network.Tests/Catan.Network.Tests.csproj -p:UseArtifactsOutput=false -p:DirectoryBuildPropsPath="$PWD/Directory.Build.props"
```

Unity专项入口为`FishingF5EditorVerification.Run`，启动参数`--fishing-f5-verify`后跟本地证据输出目录。完整局包含三国策略计算和完整恢复校验，耗时明显长于固定案例。本次52项主批次约69分钟；最慢单局为四人三国遗忘部落、不启用海港，14分34秒、1028条指令、135回合自然结束。只读运行栈采样落在三国棋盘操作合法性计算；此测试耗时不等同于单次玩家操作延迟，实际设备表现留F6测量。

F6继续完成完整模型、PC／Android双端交互与真机、四设备外网、长期性能和用户试玩；这些项目本轮未宣称通过。已有美术、配置、AGENTS与其他日志改动保留，不纳入F5提交。
