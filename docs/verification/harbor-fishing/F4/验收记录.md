# F4 航海第二批验收记录

日期：2026-10-29。对应[实施方案](../../../海港大师与捕鱼实施方案.md)F4，采用[F0定稿](../../../harbor-fishing/F0规则定稿.md)及用户确认的[F4地图版本适配](../../../harbor-fishing/F4规则说明.md)。本轮未发布、未部署，不修改发布版本。

## 范围与实现

驶向新海岸、四座岛屿、迷雾岛、穿越沙漠开放捕鱼，支持3／4人航海家、双扩展、三国双扩展，可叠加海港大师。主菜单、本地保存恢复、房间配置、产品AI及桌面交互已接入。遗忘部落、卡坦布匹、卡坦奇观、新世界仍留F5；海盗群岛继续禁止捕鱼。

五鱼可修路或建船，二鱼可移出强盗或海盗；复用真实航线连接、船供应、封锁和探索逻辑。船不参与捕鱼产出。迷雾湖泊属于隐藏地形池，发现仅抽一枚鱼、不消费普通号码；满额选择能恢复至原阶段。湖泊和渔场采用轻量显示，没有新建模型。

正式产出冻结鱼的受益人、源、数量和顺序，等待原资源、商品、进步牌及三国响应结束后抽取。旧靴个人目标贯穿裁决与AI，鱼筹码不进入资源／商品手牌。鲁肃交换预检海岸与内陆限制，商人不得把湖泊当资源地形使用。

地图适配按用户确认记录：迷雾池换出一块田地及普通12号；新海岸3人换出一块主岛田地及原号码；穿越沙漠独立换出主岛田地和原2号，保持三块沙漠屏障与红点分离。原FSF旧组件前提不再直接套用2025地图。出处：`FSF.pdf` PDF第1—2页、`TB25.pdf` PDF第9—10页、`FCK.pdf` PDF第1页，路径见[规则索引](../../../../assets/references/rules/README.md)。

规则专项包含三国建船零资源费用记录、海图湖泊交换、建船、缺失海盗拒绝、真实移出不偷牌、过期命令、重复筹码、非法目标原子回滚、重复命令幂等、湖泊发现、满额返回、船不产鱼和商人湖泊拒绝。完整局在每个自然换抽点执行保存／载入后的同一选择，比较权威存档；终局再次重放整个权威存档。每条命令后检查状态不变量。

回归中发现并修复原三国“大商家→破军”响应卡局：初始目标合法，破军扣置贸易科技并撤销大都会后两人分数相同，恢复主体不能再次否认先前已合法选定的目标。城市骑士／双扩展各有真实大都会撤销、非法初始目标拒绝及待决恢复对照案例。

首次相关回归的1项失败来自旧测试仍把新海岸列为未开放；改成尚未开放的遗忘部落后通过。首轮网络全套的1项失败来自“每个响应必须是增量”的过强断言：进步牌响应改变大量合法操作时，原编码器允许更小的完整快照。最终检查验证接收视图完全一致，且选用的传输包不大于同响应强制全量；未改变同步实现或放开一致性检查。完整局首轮暴露的换抽返回阶段与大商家问题已经补独立案例。历史F3记录中的间谍历史／旧牌名断言未在本轮全量重跑，不将它们宣称为已修复。

## 网络与性能

四人权威房间覆盖基础、城市骑士、三国城市骑士、航海、双扩展、三国双扩展。各执行两次鱼支付并检查预览不改存档、重复提交幂等、四席隐私、同步还原、服务重建与重连。航海网络夹具选择鱼源开局、优先合法鱼支付并使用20分目标，以稳定覆盖两次支付；产品AI策略和默认目标的可达性由独立完整局矩阵验证。

F4能力版本为 `harbor-fishing-f4-v001`。F3客户端仍能读取标准房间，不能加入或配置航海捕鱼；不支持模块的旧客户端继续被拒绝。关闭模块及F1／F2／F3存档身份沿用原合同。没有新增逐帧消息、无界队列或额外全量同步路径。

测试输出保留两次提交耗时与四席同步包体，见测试结果JSON；这是同进程单次样本，房间种子由服务生成，且与其他检查并行，不是公网延迟或稳定帧率基线。服务全套仍包含既有同机四条WebSocket、连接、恢复与发送队列测试，不冒充四设备外网验收。

## 复现

```sh
source tools/development/Enter-DevEnvironment.zsh
dotnet test tests/Catan.Rules.Tests/Catan.Rules.Tests.csproj -p:UseArtifactsOutput=false -p:DirectoryBuildPropsPath="$PWD/Directory.Build.props" --filter 'FullyQualifiedName~FishingSeafaringTests|FullyQualifiedName~FishingExplorationTests|FullyQualifiedName~ThreeKingdomsB5CivilIntegrationTests'
dotnet test tests/Catan.Network.Tests/Catan.Network.Tests.csproj -p:UseArtifactsOutput=false -p:DirectoryBuildPropsPath="$PWD/Directory.Build.props"
dotnet test tests/Catan.Server.Tests/Catan.Server.Tests.csproj -p:UseArtifactsOutput=false -p:DirectoryBuildPropsPath="$PWD/Directory.Build.props"
```

Unity入口为 `FishingF4EditorVerification.Run`，参数 `--fishing-f4-verify` 指向 `.local` 内独立证据目录，不写入用户存档。TRX和原始日志位于 `tests/*/TestResults/fishing-f4-*.trx` 与 `.local/development/harbor-f4/`；仓库只保存脱敏摘要、公开地图样本与实际界面截图。
