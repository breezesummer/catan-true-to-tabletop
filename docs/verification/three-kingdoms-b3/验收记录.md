# 三国争霸 B3 工程验收记录

日期：2026-10-23（Asia/Shanghai）。游戏版本保持内测版2.0.1；本轮是本地开发包，未正式发布或部署云端。B3 的交付范围为骰子与时间工作包，不改变 M0–M8 的原验收状态。

## 实际交付

在 B2 的11将15技能基础上，完整启用司马懿、诸葛亮、张昭张弘、曹丕、曹植，共16将25技能。保留每人发4张、末位发5张选2的正常开局，以及三轮寿命、任次重抽与有限供应；其余38将仍整将隔离。

实现正式骰局的候选、鬼才付费改点、观星逐颗选择、直谏固定结果，以及翻面、额外机会、固症／落英弃牌竞争、颂威和空城。判定、比大小与重掷提供独立基础；后批判定来源、判定后的勤政接续与甄姬技能未提前启用。具体语义见[B3规则定稿](../../three-kingdoms/B3规则定稿.md)和[实现说明](../../three-kingdoms/B3实现说明.md)。

酒诗仍遵从原文和既有翻面通则：背面付7木排入的机会也会跳过并翻回，没有采纳“先翻回再完整行动”的改文。额外机会先进先出，不推进正常轮或扣轮寿命。

## 收尾缺陷与复验

- 合法动作预览原本没有命令ID，被B3退牌来源校验误判，导致建设入口隐藏。现为隔离探针设置临时身份；产品AI建城、重复视图／预览零状态变化及四完整局均通过。
- 雾岛同次支付和探索奖励不能按最终净手牌推算失牌。现记录真实支付快照，先处理连营、落英，再恢复探索；两个待决点恢复、不重扣费用及不重复造船通过。
- 空城免疫未实际弃牌时不再虚构截获牌；海盗先处理劫掠反应，再锁七点量和普通产出。银行0木、落英7→8张、连营补牌和骰后集智不会倒置七点义务的案例通过。
- 首次Windows实际检查发现直谏与主动隐退叠加时补将入口被空技能窗口遮住，并发现补将遗漏刷新挂起决策标识。现只投影最上层武将选择，保留并恢复原骰子帧；新增M4/M5正常会话逐点公开重放，最后74项相关检查通过。

早期失败或主动中止的 TRX 不纳入最终通过数量；完整局通过后最后改动仅涉及生命周期待决投影与窗口刷新，已用新增真实会话和Windows运行验证，没有无理由重复所有完整局。

## 原模式与产品边界

原模式快速回归1171项：1149通过，22项既有展示／旧牌名／历史断言失败，与B2记录的失败名单逐项相同，无新增失败。支付与组合场景尾段收口后，另对受影响组合路径复验85／85通过。网络协议、房间与权限回归141／141通过；三国联机仍关闭。旧模式108完整局本轮未重复运行，不计作本轮证据。

Windows实际程序、包身份、保存恢复和运行结果见[Windows运行说明](Windows运行说明.md)与[程序指纹](Windows程序指纹.json)。未取得界面像素、真实鼠标／触控、Android真机、四真人长局或用户整局试玩证据；AI仍采用保守的主动改骰／直谏策略，不声称对战强度验收。

## 复跑入口

在仓库根目录加载 `tools/development/Enter-DevEnvironment.ps1`，使用 `$toolchain.dotnet test tests/Catan.Rules.Tests/Catan.Rules.Tests.csproj -c Release --filter 'FullyQualifiedName~ThreeKingdoms'` 可复跑三国全部规则与完整局。需要运行跟踪时设置 `CATAN_B3_TRACE` 为本地私有目录；跟踪包含权威状态，不复制到公开文档。

Windows构建使用 `tools/development/Build-M7.ps1 -OutputRoot 'game version/2.0/Catan2.0.1-Three-Kingdoms-B3' -SkipVerification`，然后以 `--three-kingdoms-verify <绝对证据目录>` 启动程序。此开关只跳过脚本中的历史通用验证；本轮各项测试和实际程序验证分别执行并记录。
