# 三国争霸 B1 可玩骨架验收

日期：2026-10-22（Asia/Shanghai）。工程分支：`dev-2.0`。游戏版本：内测版2.0.1。本轮不是正式发布，未递增版本、构建 Android 或部署云端。

## 交付范围

在“开始游戏”中选择城市与骑士或双扩展组合，可开启“三国争霸 B1 开发骨架”。基础版、航海家单扩展及联机没有此入口。54张武将保留姓名、称号、势力及97个技能原文，**技能均未启用**；本包用于验证选将、轮换和阶段，不算完成B2或完整三国扩展。

本地Windows开发程序：`game version/2.0/Catan2.0.1-Three-Kingdoms-B1/Builds/Windows/Catan2.0.1.exe`。

- 固定座次串行发4张、末位发5张，私密选2张并指定拟登场；全员完成后统一公开，再进入原地图初始摆放。
- 每人通常保有在场1张和暗置1张；暗置不老化。正常轮末对在场任次建立快照、扣1轮寿命，三轮到期按座次轮换；该轮界补入的新任次从下一轮计算。
- 在自己的合法回合窗口可主动隐退，旧将先回池，再抽2留1并选择登场。完成后可以继续主动隐退；不设隐藏次数上限，同实体回抽创建新任次并重置计数。
- 准备、判定、掷骰、摸牌、出牌、结束采用独立可恢复阶段。换将期间保留原核心的弃牌、交易、进步卡和剧本待决，完成后恢复；旧窗口令牌失效，旧确认不能再次执行。
- 展示本人候选与暗置、公开在场武将及寿命。收起面板不会取消强制选择。AI通过所属PlayerView完成选择和阶段，不主动循环隐退。保存恢复与本地重新开始保留三国开关。

翻面跳过、额外行动机会FIFO及额外机会不耗正常轮，在公共生命周期引擎中测试；B1没有启用能产生这些效果的武将技能，不能据此宣布B3产品能力完成。B1的摸牌阶段保留一个显式恢复边界；生产替换、供应预留及逐技牌流由B2接入。已开始效果的恢复通过父帧和原生待决验证，不等于97技能已实现。

据此完成B1工程退出，更新三国工作包状态；下一工作包为B2牌流基础。M0–M8产品阶段保持原状态，界面人工验收和后续技能实现仍按各自范围推进。

## 复跑入口

以下命令在项目根目录执行。使用`tools/development/toolchain.json`指定的.NET与Unity，避免系统`dotnet`没有SDK。

```powershell
$env:DOTNET_ROOT='D:/Development/dotnet'
$env:PATH=$env:DOTNET_ROOT+';'+$env:PATH
dotnet test tests/Catan.Rules.Tests/Catan.Rules.Tests.csproj --filter 'FullyQualifiedName~ThreeKingdoms'
dotnet test tests/Catan.Network.Tests/Catan.Network.Tests.csproj
./tools/development/Build-M7.ps1 -OutputRoot 'game version/2.0/Catan2.0.1-Three-Kingdoms-B1' -SkipVerification
```

独立程序接受`--three-kingdoms-verify <绝对证据目录>`。探针通过产品入口执行，不注入修改后的权威存档；结果写入`result.json`，成功日志标记为`CATAN_THREE_KINGDOMS_PLAYER_OK`。它不模拟真实鼠标、触控或网络用户。`-SkipVerification`仅跳过构建脚本的历史通用验证，本轮独立规则、协议及实际程序验证分别记录，不把构建成功替代它们。
