# 1.6.11 游戏菜单与发展卡界面验收

日期：2026-10-19。产物目录：`game version/1.6/Catan1.6.11-Pause-Menu-Card-UI`。

## 本轮调整

- 历史中原“获得了”统一显示为“收获”；资源、商品、发展卡和奖励沿用已有观看权限。
- 银行、玩家交易与三种设施图标删除下方固定文字，保留图标、设施等级与悬停提示。该五按钮组在当前画面位于左上角。
- Esc 优先关闭当前窗口，清除未提交的本地草稿。交易报价复用原关闭按钮的行为，撤回自己的报价或拒绝收到的报价，避免关窗后无法继续回应；强制选择只关闭界面，可从常驻提示重新打开。手动点击窗口的收起按钮仍保留原入口。
- 点击发展卡只放大完整卡面；右下回合按钮显示“使用”并换行显示卡名。新买入的基础发展卡、胜利点卡和强制待决期间不能使用；骑士、道路建设直接进入规则出牌流程，丰收、垄断保留必要资源选择。
- 游戏菜单采用主页的纸面、森林绿和金色细线，文字居中，同款按钮依次为继续游戏、保存游戏、游戏设置、游戏百科、返回主菜单。菜单没有最小化和关闭按钮；设置、百科支持逐层返回。
- 打开菜单自动阻挡本地 AI 调度和牌桌操作，保留原暂停配置；点击继续游戏可恢复人工暂停，故障暂停不会被自动清除。联机房间继续运行，单个客户端打开菜单不会暂停其他玩家。
- 全体报价仅向仍有操作权限的席位显示模态窗口；接收者关闭后只拒绝自己，其他玩家仍可回应。已拒绝席位、旁观者和同帧重复关闭均不会重复提交拒绝。
