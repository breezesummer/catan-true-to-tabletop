# 2026-11-03｜2.1.5 连续海面与固定俯角

## 实现

- 木桌和装饰海框改为覆盖视野的连续海面。原海板显示实例隐藏，公开的海格、道路边、顶点 ID、港口和捕鱼板不变；航海海格通过海面遮罩保持边界。
- 水面使用 Blender MCP 制作的非均匀网格，中央密、远处疏。PC 为 25,921 顶点／51,200 三角形，移动端为 6,561 顶点／12,800 三角形；实际宽度 16 米。源文件保留在 `art/source/ocean-v001/ocean-v001.blend`，复现脚本为 `tools/art/build_ocean_v001.py`。
- URP 单次不透明绘制：两组低幅几何波、叠加细波法线、太阳高光、近似天空反射色、近岸浅水及破碎薄浪。水位 4.5 毫米，最大波幅合计 1.2 毫米；靠岸及航海格边减弱起伏，低于 8 毫米棋盘操作面。没有流体物理、实时场景倒影或折射。
- 海岸与海格遮罩只接收公开地形，包括公开迷雾占位，不读取未揭示资源。512×512 遮罩按约 3 毫秒批次分帧生成；地图未变化时复用，不逐帧改网格、不增加网络消息。输出一次性 `CATAN_OCEAN_READY` 脱敏诊断。
- 正交投影保持不变；默认俯角 66°，俯视 82°，缩放全程固定角度。库存与骰子使用原有独立 58° HUD 相机，位置、朝向和点击不跟随地图。
- 默认取景区域为逻辑坐标 `(158,130,1012,558)`；仅拟合公开棋盘和真实港口，排除外围装饰海圈，向左调整并保留底部手牌空间。放大倍数按地图实际范围决定，不强行统一放大 20%。

## 验证方式

- `TabletopCameraTests`：4 项通过，覆盖正常、越界及 NaN 缩放参数下的固定俯角。
- Blender MCP 回读两档 FBX：尺寸、顶点和三角形数量一致，坐标有限，无零面积面。见 [网格检查](mesh-validation.json)。
- 游戏独立进程 `--ocean-view-verify`：基础、航海、城市骑士、新世界双扩展、三国双扩展五类四人局，启用海港大师与捕鱼，推进至正常行动和实际手牌。
- 检查默认／远景／近景的固定角度与投影比例、拖拽射线、HUD 定位、实际港口完整性、海板隐藏、无海面碰撞、着色器支持、遮罩复用、动画像素变化和操作前后权威存档一致性。
- 最终五类配置共 45,178 次断言通过，20 张完整窗口截图已通过总览及重点原图审看。五类对局的两次 320×200 相机采样分别有 41,547／42,670／41,562／43,981／42,562 个像素变化，遮罩修订均保持为 1；这是动画有效性检查，不是帧率或整机性能基准。
- 完整画面由独立游戏在帧结束时截图，包含 UI。`result.json` 沿用旧验证器的统计字段和通用备注；本次 `cameraImages` 对应完整游戏截图，`fullUiPixelsVerified=false` 表示没有自动判定全部 UI 像素，不表示截图缺少 UI。

## 已知验证边界

- 旧 `Test-TabletopUi.ps1` 在“单建筑模型没有排在左下”断言处失败；使用未修改的 2.1.4 原程序复跑得到同一失败。该断言针对固定库存布局，不能据此宣称整套旧测试通过。本轮的相机断言已随需求更新，另用海面专项覆盖受影响路径。
- Android 真机帧率、触控整局及四设备外网未验收；没有改动通信或同步协议。
- 本轮为内测版本更新，不是正式发布，不部署云端。
