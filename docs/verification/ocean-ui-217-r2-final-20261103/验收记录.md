# 内测版2.1.7海洋主题第二轮覆盖

## 改动

- 内置imagegen根据原概念图生成新的青蓝细浪纹理与透明罗盘素材，原始图片保留，来源、项目位置与完整提示词见[素材说明](../../../art/recipes/ocean-ui-v002/素材说明.md)。
- 海面移除上一轮导致灰蓝的去饱和混合，降低两层水纹交叉角度并调整尺度；岛岸白浪减淡，礁石外围使用独立的浅水／碎浪过渡。
- 保留现有三维碎礁模型，调整边缘摆放、浅米灰受光面和青灰湿润底部；仍为4个实例、共5,120三角形，无碰撞体。
- 面板沿原边界补充金属明暗描边、增大角饰切片；右下罗盘更换独立素材，文字继续由程序绘制。
- 玩家名使用象牙白，当前玩家名使用青色；放大玩家名、回合数字、阶段文字，进一步提亮历史玩家名。命中区域、布局及规则／通信逻辑保持不变。

## 视觉复核

首轮实机发现礁石外围白浪过宽、出现白色斑块，因此收窄浪带、降低白沫强度，并调细水纹后重新构建。本文目录内为修正后的最终截图，首次临时构建不用于覆盖。

已查看最终基础版完整窗口：海水恢复青蓝，边缘浪花收窄，名字与回合数字更清晰，罗盘金属环不遮挡中央文字。现有布局下仍保留原棋盘与卡面，未宣称与概念图逐像素一致。
