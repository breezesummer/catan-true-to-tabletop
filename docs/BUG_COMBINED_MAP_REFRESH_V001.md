# 双扩展新局地图刷新修复 v001

2026-10-14，用户反馈每次开局地图相同，并确认使用“双扩展组合”。当前可玩程序为 [CatanM6.exe](../.local/m6-map-refresh-v001/Builds/Windows/CatanM6.exe)，`Play-M6.ps1` 与 `Play-AiStrategy.ps1` 均指向本版当前优化 AI。

## 原因与行为

新局入口已经生成不同种子，但双扩展规则工厂一直调用固定剧本模板，种子只影响牌库、先手和之后的骰子。修复后，“驶向新海岸”“穿越沙漠”的 3／4 人新局分别使用主岛与海外区域的组件池随机摆放地形和点数，并随机港口类型。

海陆轮廓、Tile／Vertex／Edge ID、主岛开局范围和海外奖励区域保留。“穿越沙漠”的三块沙漠屏障固定，金矿不放 6／8；两剧本均保证 6／8 不相邻。地形、点数和港口数量守恒。红点位置采用有限回溯，不能无限重抽或返回违规的备用地图。

依据为已锁定的官方 2025 航海家 PDF 第 4／5、10／11 页，本轮重新读取并查看第 5、11 页整页渲染。原件 SHA-256 为 `a499abe2b613afd618dd3c806790400c7e84adebcc9b9ab19a24fb80dd04b099`，保持不变。[官方来源](https://www.catan.com/sites/default/files/2025-03/CN3083%20CATAN%E2%80%93Seafarers%20Rulebook%202025%20secured%20reduced.pdf)。地图生成在纯规则库内执行，显示和动画不参与规则结果。

## 存档与入口

新场景版本为 `m5-combined-variable-2025-v002`，保存初始种子、当前随机状态、待决选择与权威命令记录。同配置同种子精确复现；读档重建同一地图并回放，不重新开局。

旧场景版本 `m5-combined-official-2025-v001` 仅用于识别和恢复已有固定地图存档，仍经当前规则入口执行。旧局保留原地图和随机续跑；新开局使用新版地图。未知版本或篡改种子的存档拒绝，不替换当前局面。

运行本版 EXE，选择“双扩展组合”和剧本后开局。对局中按 Esc → “规则／新开一桌” → “开始新局”。切换旧窗口时先保存并退出，直接打开旧目录 EXE 不会加载修复。

## 实际验证

- 全量 .NET 运行 781 项：778 项通过、3 项失败。首次进程未设置固定 .NET 路径，一个独立保存进程误用系统 .NET 6；两个完整局的最优开局全部落在内陆，未满足原验收的船覆盖断言。修正环境，并让完整局验收首村选择合法海岸，继续保留船断言，未改变产品 AI。
- 最终专项 **75／75 项通过**，含上述失败、4 个正常完整组合局、20 个新增地图用例及组合规则／策略。两批去重 **781 项全部通过**，其中 **52 个当前产品 AI 完整局**；不是另跑一次 781／781 全量测试。
- 四种配置各扫描 258 个种子，共 **1,032 张地图**；官方独立数量预期、稳定拓扑与区域、红点／金矿限制、复现与变化、非法操作及存档篡改拒绝通过。
- Unity `6000.3.25f1` 构建及 Unity 内规则／AI 执行通过。两个独立图形 Windows 进程完成四模式保存与恢复。
- 实际 M6 入口在无图形／图形模式各通过 **4 配置、12 次新局、4 次新存档恢复、4 次旧存档恢复**；检查每次地图变化、投影与三维地形一致、仅一个棋盘渲染器。四份旧局在修改前实际执行 40 条合法命令后保存，只保留本地忽略目录。
- 既有桌面集成在无图形／图形各 28 配置通过，分别 20,051／20,060 次检查。完整 IMGUI 像素自动验收仍为 `false`。
- 实际窗口连续两次从菜单开“驶向新海岸”，确认地形、点数、港口刷新；另打开“穿越沙漠”，检查随机地图和固定沙漠屏障。

公开结果见 [验证摘要](verification/combined-map-refresh-v001/summary.json)。权威存档、随机状态、牌库顺序和私有手牌只留本地。用户本人整局试玩、所有分辨率、长期性能与随机地图对战平衡未在本轮全面验收；M7／M8 状态保留。

复验：`tools/validation/Test-CombinedMaps.ps1`（可加 `-Graphics`）；全量使用 `Test-M6Rules.ps1` 以加载固定工具链。构建使用 `Build-M6.ps1`。本次新局修复针对用户确认的双扩展组合。
