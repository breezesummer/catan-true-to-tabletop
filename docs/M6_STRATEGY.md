# M6 策略与质量边界

M6 是本地确定性启发式 AI，目标是合法完成对局并与人类混合游玩。没有训练模型、在线服务、蒙特卡洛搜索、难度分级或胜率承诺。当前策略是工程基线，未由用户确认对战强度。

## 当前策略

| 场景 | 行为 |
| --- | --- |
| 开局 | 评估骰点产出、资源种类及城镇发展需求，使用规则投影的合法位置 |
| 基础行动 | 建城和定居点、有限长度路径扩张、发展卡、银行及港口交易 |
| 玩家交易 | 每回合至多一次主动报价；接收者按本人持有量及边际价值接受或拒绝，不知道对手具体手牌 |
| 七点与强盗 | 依法弃牌，尽量避开己方建筑并选择对手，合法偷牌 |
| 航海家 | 船、金矿、港口、剧本特殊选择，以及奇迹/布匹/海盗要塞等剧本行动 |
| 城市与骑士 | 招募、激活和晋升骑士，城市改良、进步卡与蛮族相关选择 |
| 组合 | 在组合合法动作范围内处理船、骑士、金矿和进步卡等交互 |

## 已知质量缺口

- 只做短期目标和有限路径评估，没有多回合搜索、对手建造预测或胜率估值。相同局面会作相同选择。
- 主动报价范围保守，可能向没有所需资源的玩家提出交易；这符合隐藏信息约束。拒绝后当回合不会反复报价，也不议价或建立信誉模型。
- 发展卡、进步卡和多步待决中有些选择只从合法候选里选取，不能保证最大收益。合法完成卡牌不等于高水平用牌。
- 城市骑士优先维持自身防御，可能过度投入，不能保证集体抵抗蛮族或最优抢夺大都会。
- 航线、海外奖励、探索、船移动、骑士阻断及部分特殊行动的长期价值判断有限；能完成剧本不等于充分运用每种战术。
- 当前正常局倾向移动强盗，52 局未自然选择 MovePirate；海盗封锁与目标选择仍缺少有效战术评估。
- 对局测试覆盖有限种子和固定剧本。它证明被测局面合法且可结束，不能推出所有随机局面都必然快速结束，也不能替代人类对战体验验收。

后续质量改进应保留 PlayerView 权限边界，先增加能复现问题的局面和可观察目标，再评估搜索或不同策略；不通过额外信息或修改规则提高表现。完整测试范围、实际回合和耗时在验收记录中登记。
