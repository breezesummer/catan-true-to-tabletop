# M6 策略与质量边界

M6 是本地确定性启发式 AI，目标是合法完成对局并与人类混合游玩。2026-10-13 的 [策略优化 v002](AI_STRATEGY_V002.md) 加入初设配套、登岛回本、最低有效防御、设施竞争及立即获胜优先。没有训练模型、在线服务、蒙特卡洛搜索、难度分级或胜率承诺；用户尚未确认对战强度。

## 当前策略

| 场景 | 行为 |
| --- | --- |
| 开局 | 优先覆盖 6／8，补资源与骰点；航海重木羊，砖港须有对应产出，城市兼顾产纸 |
| 基础行动 | 建城和定居点、有限长度路径扩张、发展卡、银行及港口交易 |
| 玩家交易 | 每回合至多一次主动报价；接收者按本人持有量及边际价值接受或拒绝，不知道对手具体手牌 |
| 七点与强盗 | 依法弃牌，扩展策略考虑领先分、关键生产与自伤；海盗考虑船线阻断 |
| 航海家 | 登岛奖励、剩余回合产出与路船费用一起比较；零资源可挪闲船，末盘低成本争最长航线 |
| 城市与骑士 | 立即获胜优先；按最低有效兵力保城，早期排水渠、后期贸易，判断大都会能否争得 |
| 组合 | 组合登岛、保城和设施规划，并在已有连接处进行低成本阻断 |

## 已知质量缺口

- 只做短期目标和有限路径评估，没有多回合搜索、对手建造预测或胜率估值。相同局面会作相同选择。
- 主动报价范围保守，可能向没有所需资源的玩家提出交易；这符合隐藏信息约束。拒绝后当回合不会反复报价，也不议价或建立信誉模型。
- 发展卡、进步卡和多步待决中有些选择只从合法候选里选取，不能保证最大收益。合法完成卡牌不等于高水平用牌。
- 城市骑士防御基于当前公开兵力，不预测其他玩家后续激活与扩军，不能保证集体抵抗蛮族或最优抢夺大都会。
- 航线、海外奖励、探索、船移动、骑士阻断及部分特殊行动的长期价值判断有限；能完成剧本不等于充分运用每种战术。
- 原 2026-10-09 基线的 52 局未自然选择 MovePirate；v002 已加入海盗战术评分及真实执行案例。新结果单独记录，不改写原验收证据。
- 对局测试覆盖有限种子和固定剧本。它证明被测局面合法且可结束，不能推出所有随机局面都必然快速结束，也不能替代人类对战体验验收。

后续质量改进应保留 PlayerView 权限边界，先增加能复现问题的局面和可观察目标，再评估搜索或不同策略；不通过额外信息或修改规则提高表现。完整测试范围、实际回合和耗时在验收记录中登记。
