# 资源牌左加右减 v014

2026 年 10 月 17 日，统一当前四种规则模式的资源牌选择操作。

- 玩家报价、银行兑换、港口兑换、金矿领取：直接左键点击牌面增加一张，右键点击减少一张；数量保留为文字，移除加号、减号及数量调节框。
- 手牌资源选择同样左加右减，同种牌重复点击按数量选择，不再用左键反复切换选中／取消；弃牌数量不能超过当前待决要求或实际持有数。
- 丰收、垄断、城市与骑士／双扩展组合中的资源与商品选择、商业港口、水渠及赠礼／交牌草稿共用牌面输入。单种资源选择可用右键清空，未选时不能确认执行。
- 银行与港口两侧分别只选择一种资源，点击其他种类时切换该侧种类；右键点击未选种类不影响已经选择的数量。仍需按实际兑换比例点选数量，库存、手牌及最终指令校验沿用原入口。
- 资源牌区域的右键优先用于减牌，不会触发取消整个面板。关闭、取消与 Esc 入口保留。
- Android 共用布局提供轻点增加、长按后松开减少的输入映射，无独立增减控件；本轮未构建 APK，触屏手感仍待真机验证。
