# 菜单原型质感还原

1. **先对形。** 原型与实机同尺寸并排，先看整组边界是否闭合、表头与各列是否对齐，再比转角、厚度和接缝。外形偏了就回原图取形，内外包边随同一端头转折。
2. **按细节选做法。** 轮廓、符号用矢量，纹理和反光用无字底板，雕花、端头可从原型拆取。伸展控件时固定两端；缩略图保持原比例，清掉抠图残边，再按底色补接触影。
3. **沿着光看到背景。** 看倒角哪一侧接光、亮边多宽、哪一侧转暗。原型有辉光时，给贴图留出透明边距，让光从边缘渐隐到实际底色上。实体显得悬空时，先对齐底边，再补接触影。
4. **把字当作表面的一部分。** 按实机像素字号排字，保留字形收锋，分别调字号、字重和浮雕。印字融入底纹，刻字表现槽壁暗部与下缘反光。用最长文案核对两端留白，禁用态也要读得清。
5. **用实机决定下一步。** 挑代表控件和完整一行，用真实内容、底色打样。全图核对阅读顺序、选中态和分区，细线与浅底共同托住内容；局部保留边框外背景，同尺寸并排看原型、上一版和本版。每轮修最明显的一处，复用后再看整页，并核对交互。
