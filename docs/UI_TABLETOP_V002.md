# 整桌交互 v002

2026-10-11，按用户本轮概念图将当前 M6 的四种规则模式改为以地图为中心的整桌布局。用户明确要求本轮不申请操控电脑、不中断其正在玩的游戏；实施、构建和验证均使用文件及后台命令。

## 启动与布局

运行 `tools/development/Play-M6.ps1`。本轮不自动启动前台试玩窗口。默认新局为四人，即自己加三个 AI；仍可选择三人和不同人类席位。

- 中央是完整地图、海框与数字筹码，背景是连续木桌。移除 M6 的固定右侧操作栏、底部背景板和分隔线。
- 自己始终坐在前方，其他玩家按相对座次分布在左、上、右侧；三人局显示两名对手。对手只显示公开备件、分数、牌背和手牌数量。
- 自己的备件逐枚摆在地图近侧，资源牌与发展／进步牌呈扇形。城市设施以卡片放在右前方；手牌过多时用滚轮或牌旁箭头翻看。
- 骰子、银行和回合交接都在桌面上。保存、恢复、暂停 AI、切换视角和新局入口收进右上角“桌边菜单”。菜单展开期间阻止棋盘与手牌操作。

旧的 M2–M5 独立入口保留原布局。本轮适用范围为 M6 启动后的基础、航海家、城市与骑士及双扩展四种模式。

## 具体操作

| 对象 | 操作与结果 |
| --- | --- |
| 备件 | 单击拿起后点地图落下，或按住拖动后在合法目标松手；费用和已有资源联动，规则校验通过后才扣除资源 |
| 放回 | 右键、Esc 或手牌旁的放回按钮取消本地选择；取消不改变权威局面 |
| 骰子 | 轮到本人且允许掷骰时点击两颗骰子，结果由规则核心生成 |
| 回合交接 | 行动阶段点击“交出回合”；其他阶段禁用 |
| 银行与港口 | 点击桌上银行牌堆，或基础／航海模式的港口标记，临时展开交换纸片 |
| 对手 | 点击其备件／牌背区域提出交易；需要随机偷取时点击合法对手，海盗保留资源与布匹选择 |
| 交易牌 | 可点选资源配置报价，也可将资源牌拖到玩家交易的付出一侧；确认后才提交交易指令 |
| 发展与进步牌 | 点击卡面阅读，再选择打出；需要资源、玩家或多个目标的效果按需展开临时纸片 |
| 骑士与船 | 城市与骑士／组合模式可点地图上的己方骑士选择动作；组合模式可以点己方船拿起移放；航海模式的特殊动作在“航海日志”中发起 |
| 设施 | 点击可升级的城市设施翻到下一等级并经规则入口扣费；大都会等后续选择仍按规则等待 |
| 弃牌与特殊待决 | 基础／航海弃牌从自己的资源手牌抽出所需数量后确认；复杂扩展待决保留临时纸片的参数选择与确认 |

普通放置不再到侧栏二次确认。多参数进步卡、蛮族、金矿等复杂选择使用按需出现的纸片控件，尚未把每项扩展规则都实现为纯实体拖拽。点选或拖放均经过现有 `Submit` / 规则入口，动画与渲染不裁决规则。规则版本和存档结构没有修改。

## 资源来源

来源与复现说明见 [资源配方](../art/recipes/ui-tabletop-v002/README.md)。用户原图原样保留，木桌与海框由代码生成，棋盘与卡面复用已有资源。桌上库存缩略图、牌面和筹码是二维显示，实际棋盘、落子模型、木桌与海框使用三维场景；没有把概念图或缩略图宣称为三维资产。
