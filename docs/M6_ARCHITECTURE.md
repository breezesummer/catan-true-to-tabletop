# M6 本地 AI 架构

M6 将策略放在独立的 `src/Catan.AI` 程序集中，目标为 .NET Standard 2.1 / C# 9。它引用规则模型，不依赖 Unity、渲染、物理、网络或在线大模型。基础版、航海家、城市与骑士和组合分别由 `BaseGameAi`、`SeafarersAi`、`CitiesKnightsAi`、`CombinedAi` 处理。

## 权限与指令入口

四个策略的公共决策入口均为 `Command Decide(PlayerView view)`。调用方先确定当前应操作的席位，再投影该席位有权读取的视图。报价接收者、弃牌者、金矿受益者和进步卡选择者可能不是当前回合玩家，不能只按 `ActivePlayerId` 调度。

策略不接收游戏会话、权威状态、存档、随机状态或预览回调；不访问完整对手手牌、未揭示地图或牌库顺序。规则允许的窥看仍由规则层按待决权限投影。策略返回独立的指令，调用方分配唯一 ID，并经与人类相同的 `Submit` / `Execute` 入口验证。合法目标和合法扩展指令是视图的辅助数据，不能替代执行时验证。

M6 不改变既有规则或各规则包的存档版本。AI 无可变的跨决策记忆；相同视图产生相同选择。每回合至多一次主动玩家报价，通过公开事件中最近一次 `EndTurn` 之后的报价记录限制，因此拒绝交易后和保存恢复后不会立即重复报价。

## 策略与终止

开局按骰点产出、资源种类和资源权重选择顶点。正常行动以城镇、扩张路径、发展卡和资源目标为基础；城市骑士增加防御、改良和进步卡优先级。贸易只使用本人手牌、公开报价、港口、银行及对手公开数量。扩展待决先于普通建设处理。

策略每次只选择一个指令，由下一份实际规则视图继续多步流程。免费建设、逐人弃牌、金矿、进步卡和蛮族选择不能用界面动画的完成情况推动。没有普通行动时结束回合；出现不支持的状态或非法指令时，产品暂停并显示错误，不假装已完成该选择。

## Unity 与本地保存

M6 复用 M2–M5 的棋盘和操作面板，并提供独立启动场景。单人模式固定显示人类席位的视图，AI 私有视图只传给策略。AI 的待决由调度器推进；人类待决停下来等待输入。旧阶段场景保留本地换座行为。

M6 的本地保存外壳记录规则包、人数、人类席位与暂停设置，并内含原规则包的完整权威存档。权威内容包含规则版本、场景版本、待决和随机继续状态；仅留在本地保存目录。恢复先验证完整内容，再替换运行局面。公开证据只包含测试结果、汇总日志、截图及校验值。

## 验证边界

测试调用实际产品策略，观察器可独立检查权威状态和守恒，但不将这些信息传给策略。正常开局完整局、待决保存恢复、隐藏信息非干扰、输入不可变和非法权限检查与 Unity / 独立 Windows 验证分开登记。实际运行结果见 [M6 验收记录](M6_ACCEPTANCE.md)，策略质量限制见 [M6 策略说明](M6_STRATEGY.md)。
