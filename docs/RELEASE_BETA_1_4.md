# 卡坦岛之三国争霸内测版1.4／安卓发布记录

2026-10-15，按用户确认保留同一个 `Unity/Catan` 工程，共用规则、当前 AI、M6 场景和原有资产，新增横屏安卓 APK。用户后续确认只发布 APK，PC 保持可玩，不制作 PC 分享压缩包。Android 8.0 及以上、64 位 ARM64 手机为本轮兼容目标，另带 x86_64 用于模拟器验证。

## 本次变化

- 手机采用安全区布局，加入常驻菜单、银行、玩家交易、设施和历史入口，建造与卡牌使用抽屉；扩展待决面板支持较大按钮和滚动。
- 单指拖地图，双指缩放和平移；点选或拖放建造，返回键取消操作并打开菜单。所有动作仍经既有验证入口，不复制规则或 AI。
- 安卓采用 IL2CPP、OpenGL ES 3 和 ETC2 纹理，使用独立移动画质；PC 保留原渲染管线和鼠标键盘入口。中文字体与 OFL 许可随包提供。
- 安卓菜单可主动保存／恢复，正常对局切后台尝试自动保存；验收会话隔离，PC 沿用手动保存。存档在各自设备本地，无云同步。
- 建立可重复的签名构建、APK 内容检查、四模式运行／恢复与模拟器触控验收入口。签名密钥和加密口令仅留本机 `.local`。

实际最终 APK、校验值、各项已运行结果及微信发送状态以 [公开摘要](verification/android-port-v001/summary.json) 为准；技术说明见 [安卓适配记录](ANDROID_PORT_V001.md)。原始权威验收存档、手牌截图和本机路径不进入公开报告或发行包。

最终APK为302425389字节（约288.4 MiB），SHA256 `c6a694ff087da714a9cd04107846a79b52ee5b190ff0af75ac34ac655094a1e9`，内测稳定v2签名校验通过，双向横屏；发行副本哈希一致。845项.NET检查、Windows构建与独立四模式存档、Android 15模拟器原生运行353项及独立恢复139项通过；48张原生截图、22条模拟器触控断言和9张触控截图已验收。原生最终运行日志无Unity Error或AndroidRuntime崩溃。

## 存档事故与修复

首轮新增退出自动保存时未限制平台，Windows 验收局写入了默认 PC 存档目录的当前档与备份档。已告知用户，无法确认测试前是否有用户原档，也没有找到可证实的原档备份，不能声称已恢复。随后将自动保存限制为安卓正常对局，并排除验收会话；最终 Windows 验收前后默认目录的两份文件哈希保持一致。后续测试采用独立目录。
