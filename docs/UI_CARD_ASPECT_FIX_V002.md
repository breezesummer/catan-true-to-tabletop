# 手牌屏幕比例修复 v002

2026-10-13 按用户反馈修复木头卡变扁、其他资源牌及特殊卡拉长的问题，对照今天 10:52:38 的 `a244e44` 版本。属于 M6 显示修复，不更新路线图阶段；本轮按用户要求不发送微信。

## 原因与修改

本轮查到正在运行的程序来自 `.local/m6-ai-v002/Builds/Windows/CatanM6.exe`，不是上一轮已修复贴图导入的版本。实际查看旧窗口，木头卡偏扁、砖块和纸张卡细长，与反馈吻合。保留旧程序和用户当前对局，没有强制退出或覆盖存档。

此外，原界面使用宽、高分别缩放的 `GUI.matrix`。只在逻辑坐标中使用 `ScaleToFit`，仍会在 16:9、超宽或 4:3 窗口中改变最终卡面比例。现在按实际矩阵补偿卡面区域，再绘制完整图像，使屏幕像素宽高比保持原图比例。发展卡文字卡面的外形与预览也使用同一补偿方法。继续沿用 10:53 附近版本的手牌布局尺寸、排列与重叠规则，以及当前点击抬牌方式。

继承 v001 的 47 张贴图原比例导入修复，不改原照片、不重采样源图、不修改规则及 AI 源码。没有实体照片的发展卡仍使用文字卡面，不声称补齐了美术资源。

## 启动

项目根目录新增双击入口 `启动卡坦.cmd`，调用 `Play-AiStrategy.ps1`，保持用户本次正在使用的优化 AI 策略。两个脚本分别指向：

- 优化 AI：`.local/m6-ai-v002-card-ratio-v002/Builds/Windows/CatanM6.exe`。
- 原策略：`.local/m6-ui-v006-card-ratio-v002/Builds/Windows/CatanM6.exe`。

旧窗口不会动态加载新资源。请先在旧窗口保存并退出，再双击新入口，按需恢复原存档。直接启动历史目录的 EXE 仍会运行历史版本。

优化 AI 版通过 `Build-M6.ps1 -VerifyPlayer -OutputRoot .local/m6-ai-v002-card-ratio-v002` 构建。原策略版使用 v001 原策略程序保留的 `Catan.Core.dll`、`Catan.AI.dll` 作为 Unity 插件，执行 `M6Build.Build --m6-output-root` 构建到上述独立目录；构建结束后恢复工作区的当前源码程序集。原策略交付程序的两个程序集哈希与 v001 逐一一致。
