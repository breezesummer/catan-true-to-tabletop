# M3 航海家架构

规则位于纯 C# / .NET Standard 2.1 的 `Catan.Core.M3`。M1、M2 的类型、入口、场景与独立程序保留。航海家使用自己的规则版本 `catan-seafarers-2025-en-v1`、场景版本 `m3-seafarers-v001` 和存档格式 `3`，不把旧存档解释为航海家存档。

```csharp
var game = SeafarersGameSession.Create("heading-for-new-shores", 4, seed);
var preview = game.Preview(command);
var result = game.Execute(command);
var player = game.GetPlayerView("P1");
var restored = SeafarersGameSession.Load(game.Save());
```

`M3GameSession.cs` 保留基础版交易、发展卡、资源供应、建造、回合与命令账本；`M3Seafaring.cs` 实现船、海盗、金矿、探索、港口、布匹和奇迹；`M3PiratesAndValidation.cs` 实现舰队、海盗要塞和航海家不变量。`M3Scenarios.cs` 固定官方剧本数据、拓扑生成和新世界地图生成。剧本来源与编号见 [剧本目录](M3_SCENARIOS.md)。

## 同一裁决入口

人类 UI 与测试席位均提交相同 `Command`。规则不引用 Unity，不读取屏幕、碰撞、动画完成状态或网络状态。合法落点仅由纯规则计算；预览在事务副本上运行，提交成功后才替换权威状态。命令 ID 与完整输入指纹去重；重复请求返回原回执且不新增事件；相同 ID 改内容被拒绝。

地图以轴向坐标生成稳定格、点、边 ID；显示名、工作译名及摄像机变化不影响 ID。地块、道路、船和建筑均按 ID 保存。道路与船共享边占用限制，路船切换只可经己方建筑；最长航线按连续边而非屏幕距离计算。

## 待决流程

蛇形开局后进入掷骰与行动。布匹剧本使用正序、逆序、正序三轮开局，只在第三处建筑领取初始资源；海盗群岛预放建筑、船与要塞，之后再执行通常的两轮开局。新世界先轮流放置十个逐一翻开的港口，再进入蛇形开局。

金矿和海盗战胜奖励使用显式选择队列。权威状态保存每位受益者、数量、返回阶段和原先待决决定。探索发生在船或道路提交后，可能中断免费道路/船的放置；选择资源后恢复原决定。海盗舰队先结算攻击和奖励，再执行本次骰点产出或七点弃牌。港口奖励可暂存，出现合法港位时必须安置，放置后立即适用兑换比例。

## 信息权限

权威存档包含完整手牌、发展牌顺序、迷雾抽取池顺序、随机继续状态与私密成功命令，只存本机。`M3LocalGameHost` 私有持有规则会话；`M3App` 与渲染器只读当前席位的 `PlayerView`。

`PlayerView` 展示本人资源和发展牌、其他席位的公开数量、公开棋盘、村庄布匹、要塞、奇迹与合法操作。迷雾格只有占位类型和几何，尚未抽取的地形、号码及边上赠送发展卡的种类不投影。公开事件不记录弃牌构成、抽得/偷得发展卡或资源、金矿选择、随机数种子和牌库内容。新世界仅展示本次翻开的港口，剩余港口顺序属于权威状态。

换座时撤销拿取与选择，丢弃原席位私有视图，要求新席位确认后显示手牌；载入后也重新执行遮蔽。完整对局测试策略的输入只有 PlayerView，不将测试驱动当作 M6 AI 产品。

## 保存与验证

格式 3 保存规则、剧本及内容指纹、种子、随机状态、资源/棋子/布匹/港口供应、全部地图揭示、特殊得分、船龄、当回合移动标记、要塞和奇迹状态、待决队列与成功命令。载入重新生成同一场景并重放命令，完整比较权威序列化结果，拒绝错误版本、篡改和不可重放的夹具。

自动化规则测试覆盖独立固定预期、非法操作原子性、资源和组件守恒、信息边界及完整局。Unity 验证使用固定 Editor `6000.3.25f1`、URP `17.3.0` 和 Windows x64 Mono；结果见 [验收记录](M3_ACCEPTANCE.md)。

## 表现资产

新增可辨识船体、桅杆、帆、军舰标记和海盗使用运行时实际网格占位，生成配方在 `M3BoardRenderer.cs`；海域、迷雾和金矿用不同颜色区分。没有把生成位图声称为 3D 模型。沿用 M1 山地 FBX 与估算尺度，不声称已取得用户实物尺寸或收藏版成品美术确认。

船体估算尺寸为 9 × 24 × 5 mm（宽、长、高），逻辑边中点为摆放基准，水面基准为 Y=8 mm，船底在该平面；桅杆和帆由相对尺寸生成。地图格边长仍为估算 40 mm。重建 Windows 客户端即从同一源代码重建这些占位组件；详细参数登记在 `art/recipes/m3-v001/runtime-pieces.json`。正式收藏版资产及其独立 Blender 源文件、导出与四视图验收留在 M8，不以占位替代美术验收。
