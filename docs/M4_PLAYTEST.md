# M4 城市与骑士试玩

启动已经构建的 Windows 程序：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\development\Play-M4.ps1
```

场景为 `Unity/Catan/Assets/M4.unity`，程序为 `.local/m4/Builds/Windows/CatanM4.exe`。M2、M3 的入口与独立程序保留。重新构建和运行独立进程验收：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\development\Build-M4.ps1 -VerifyPlayer
```

## 本地席位

默认四人；右下角「新开一局」可选三人或四人。所有席位由本机用户轮流操作，尚未提供 M6 产品 AI 或 M7 联机。

确认「我是 Pn」后查看该席位资源、商品及进步卡。回合或待决所属人改变时自动遮蔽手牌，点击右下角席位也可切换；未确认前不会显示窥看信息或上一个人的选择。公开棋盘仍可观察。设备由多人共用，需要其他人遵守移开视线的提示；本地权威存档不是防止设备所有者作弊的加密系统。

## 开局与回合

核心通过正常掷骰决定先手，地图采用规则书允许的随机基础棋盘。第一轮顺序放定居点和道路，第二轮逆序放城市和道路；第二轮只获得相邻地块各一张资源。选择右侧「目标 · 点棋盘」，点击交点或边，再点击「确认执行」。城市开局沿用「开局建筑」入口自动放城市。

掷骰后先结算事件骰，再结算生产骰。事件为蛮族船时前进一格，第七格发生攻击；否则符合改良等级和红骰范围的玩家抽对应进步卡。顶部显示红骰、白骰、事件和蛮族进度；右侧显示活跃骑士总防御与城市总数。

城市的森林、牧场、山地分别产一张资源和一张纸、布、币；田地和丘陵仍产两张资源。首场蛮族攻击前强盗不在棋盘，七点仍会要求弃牌。强盗启用后正常移动与随机偷取资源或商品。

## 操作面板

右侧面板可以滚动，五个页签提供以下操作：

- **行动**：掷骰、结束回合、道路、定居点、城市、城墙。选择目标后确认；红色预览或核心错误提示表示不能执行，不会扣费。
- **骑士**：招募、晋升、激活、移动、驱离较弱敌骑士、驱逐强盗。移动/驱离先选起点，再选目标。等级用一至三层圆环表示，金色头标表示活跃，深色表示休眠。
- **改良**：选择贸易、政治或科学，按新等级支付对应商品；取得大都会时再选择自己的可用城市。轨道颜色依次为金、蓝、绿。
- **交易**：银行/港口交易可选择八种牌、交出及取得张数，面板显示当前最优比例；玩家交易逐项加减资源和商品，指定对手并提出报价，由对手接受或拒绝。
- **进步卡**：点击所持卡查看效果与所需参数。可在合法阶段使用任意张；炼金术只可在掷骰前使用。选择卡后也可弃置，回合结束必须最多留下四张。印刷术和宪法抽到自动公开。

牌名为官方 2025 英文条目的中文工作译名，未确认与用户持有的实体中文印刷版一致。全部 25 种卡的来源、数量和预期见 [规则清单](M4_RULES_CHECKLIST.md)。

商业港口先打出卡，再点击「商业港口 · 提供资源」选择对手及资源；对方自行选择交出的商品。发明选择两个地块；锻造最多选择两名不同骑士。间谍和行会征费在出牌后才显示被授权查看的牌；只有当前待决的所属席位能看到。

## 待决、保存与恢复

蛮族毁城、大都会、防御奖励、水渠、骑士撤退和多种进步卡会暂停行动。面板显示待决所属人和数量。选择选项或牌的数量，再确认执行；婚礼、破坏、行会征费需用加减按钮配足资源与商品总数。可选效果才可勾选「放弃可选效果」。进步卡超限时选择要弃的卡。

「保存」包含随机状态、三个进步牌堆、所有待决、有限供应和规则/场景版本；「恢复」在验证完整存档后才替换当前局。正常存档名为 `m4-authority-v4.json`，位于 Unity 的 `Application.persistentDataPath` 下，旧副本保留 `.bak`。M2/M3 存档不能当作 M4 加载。

自己的回合达到 13 分时立即获胜。得分包含建筑、最长路、商人、大都会、公开进步胜利卡和防御点；本扩展没有最大军队。

Tab 切换俯视/斜视，棋盘区滚轮缩放，「地形显隐」减少山地遮挡；Esc 或右键取消棋盘目标选择。新增组件为可复现的实际网格占位，配方见 `art/recipes/m4-v001/manifest.json`，尺寸均为估算，尚不是收藏版成品美术。

实际验证与尚未验证的用户试玩、完整 UI 像素和长期性能项目见 [验收记录](M4_ACCEPTANCE.md)。
