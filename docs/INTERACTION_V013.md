# 金矿、出牌、交易与棋子动画 v013

2026 年 10 月 17 日，按六项试玩反馈调整共用桌面交互。工作区构建沿用内测版1.5；本轮没有发布新版本或重新打包 Android。

## 实际行为

1. 航海家及双扩展组合的金矿待决使用居中面板，上下各四张实体卡面。点击资源牌增加数量，减号撤回，支持清空；显示每种资源的已选数量、银行库存及领取总数。超额、空库存或点击商品牌会明确提示。三个商品位置灰显，金矿领取仍由原规则入口检查。
2. 发展／进步卡从左侧滑入中央，显示玩家头像、姓名和卡名，停留后向右滑出，再刷新展示快照并衔接收牌、建造等效果。规则结算已经完成，动画期间不提交后续玩家或本地 AI 操作。垄断等卡牌的公开资源转移从失去资源的玩家处飞出，不冒充银行产出；私有偷取不展示资源正面。加载已有存档不重播历史出牌。
3. 发起和收到玩家交易时，左侧始终是自己，右侧是对方，配头像和姓名；广播报价显示所有玩家。己方需交出的资源不足时，整张卡面及数量变红，阻止不足库存的报价或接受。移除两侧“我给予／我获得”标题。操作面板打开时隐藏居中回合提示，避免遮挡卡牌。
4. 骑士从原位置浮起，沿己方公开道路／船线的顶点路径经过拐点，再落入目标位置；对手建筑和骑士阻断中间路径。船及移动道路提供浮起迁移；无法唯一识别的合并网络增量不猜测原棋子来源。
5. 定居点升级城市、城墙／大都会形态替换，以及骑士晋升，保留旧模型抬起缩小，再让新模型落入同一位置。人类和 AI 共用展示逻辑。动画只复制公开模型，不更改规则棋子、费用或存档。
6. 游戏菜单的保存按钮改为“保存并返回主页”，保存成功后释放当前对局，主页不再提供该局的即时继续入口，可从“加载游戏”恢复；保存失败保留当前对局。原“规则 / 新开一桌”改为“返回主菜单”。Android 后台自动保存保留原有行为。

## 启动与构建

当前 Windows 程序：[CatanM6.exe](../.local/interaction-v013/Builds/Windows/CatanM6.exe)。标准试玩、AI 与联机启动脚本均指向本轮目录，随包提供自包含房间服务。

```powershell
./tools/development/Play-M6.ps1
./tools/development/Build-M7.ps1 -OutputRoot .local/interaction-v013 -VerifyPlayer
```

动画专项使用独立显示夹具和隔离存档；只在显式参数下运行，不读取或覆盖用户常规存档。实际窗口捕获需要正常图形窗口，隐藏／批处理窗口缺少重绘时不将空图计入视觉验收。

```powershell
.local/interaction-v013/Builds/Windows/CatanM6.exe --interaction-verify D:/Project/catan-true-to-tabletop/.local/interaction-v013/runtime-review
```
