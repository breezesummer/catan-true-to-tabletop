# 庭院模型制作与验收

2026-10-29。交付目录为本文件所在的 `model_v001`。基于整院参考图及 A01—A42 三视图，以整院图决定比例与摆放；三视图原有的比例漂移不作为精确测量依据。所有建模、材质节点、灯光、导出和渲染均通过 Blender MCP 执行。

## 交付

- `courtyard.blend`：仅一个庭院场景、43个独立组件；贴图已打包，含灯光与正交相机。
- `courtyard.fbx`：供游戏引擎导入的单网格资产，嵌入贴图。
- `courtyard.glb`：单网格资产，嵌入贴图，便于跨工具预览。
- `textures/`：两张ImageGen原始图集、六组颜色／法线贴图。
- `renders/front.png`、`rear.png`、`left.png`、`right.png`、`top.png`：实际模型渲染。
- `validation.json`：拓扑、UV、贴图及组件面数检查。
- `roundtrip_validation.json`：在独立Blender进程重新打开源文件、重新导入FBX／GLB后的检查。

整院 **5,998 tris**，包含底座、地面、所有建筑及摆件；源文件和两个导出文件面数一致。导出为1个静态网格、14个材质槽，原点在圆形底座底部中心。米制美术估算，底座直径14.5米，可按棋盘场景统一缩放。未接入Unity场景或执行真机性能测试，不更改游戏版本。

## 结构和制作选择

三座建筑分别构建墙体、台基、柱梁、封闭门窗、曲面屋顶、朱漆屋脊；围墙、台阶、石柱、石狮、灯笼、陶罐、水缸、木箱、石桌、四石凳、三草捆、井圈、辘轳、水桶、旗杆、双面厚度旗面和四个脊兽独立制作，再按资产ID归并。43组件包含42项立体资产及地面。

整体图优先于分件漂移：A29分件目录是水桶，但整院石桌旁为四凳布局，本模型A29用作第四只石凳；井边水桶为A35。为360度观察补全后墙、后窗及后左围墙转角，属于合理补全，不声称为参考图不可见区域的精确结构。

首轮13,424 tris；将窗格、门板雕刻和细砖瓦交给贴图，采用低段数旋转体、连续屋脊条及单段倒角，最终5,998 tris。未用全局自动减面破坏建筑直线。屋面采用闭合放样网格；小附件使用规则四边面或有规律的三角扇，导出时明确三角化。

## 材质与UV

使用ImageGen内置工具生成材质与门窗两张图集，原始提示词存于 `imagegen_prompts.json`。颜色图保留细像素簇与暖木、白墙、灰瓦、朱红配色；整体仍属于低面数风格化三维模型，不等同于纯二维像素画。

屋瓦、石材使用512像素／1.6米的重复尺度，约320纹素／米；木材、白墙约256纹素／米。门窗使用完整独立256×512图，不平铺门窗图案。屋顶主坡按坡向展开，侧坡单独投影，已修正首轮檐口拉伸。砖瓦采用规则重复，避免每一块都增加几何面。颜色贴图使用最近邻采样，实际Unity项目可依最终缩放调整过滤与mipmap。

瓦、石、木、灰泥的法线由颜色图亮度梯度估算，强度0.35，仅用于细表面变化，并非高模烘焙法线；门窗使用中性法线，窗格和雕刻主要体现在颜色图中。ImageGen没有提供物理真实高度数据。草捆复用木质纤维纹理与金色绳带，小尺度下表达束状轮廓，近看不具备逐根草茎细节。

## 十项核查

| 要求 | 检查与结果 |
| --- | --- |
| 1. 整体形态和风格 | 保留圆底座、主殿、侧屋、前门楼、院墙、旗帜与主要摆件布局；四向与顶视渲染已检查。石狮、脊兽、斗拱和草捆等细雕刻作面数预算内简化，非逐细节复刻。 |
| 2. 规则布线 | 建筑采用放样和规则闭合网格，圆形物采用有限段旋转体；无全局自动塌陷减面。 |
| 3. 适当倒角 | 台基、石盖、木箱等采用单段竖边倒角，底座与器物口沿用轮廓截面转折表现圆角；并非所有边全倒角。 |
| 4. 不超过6000 tris | 源文件及FBX／GLB重新导入均为5,998。 |
| 5. 材质和UV密度 | 六组颜色图、弱细节法线；统一世界尺度，门窗独立UV；主坡檐口拉伸已修正。未进行Unity画面滤波验收。 |
| 6. 360度完整 | 实际检查前、后、左、右及顶视；补全后墙、后窗与围墙转角。 |
| 7. 可见室内需建模 | 门为闭合木门，窗为不透明窗纸，无可见室内；未制作不可见的完整室内。井、罐、桶均具有口沿厚度和内壁，井底封闭。 |
| 8. 镂空或瑕疵 | 所有构件非流形边0、零面积面0；门窗及建筑封闭。器皿开口为有内壁的正常结构。 |
| 9. 明显穿模 | 已调整主殿山墙与侧坡、厢房门阶、箱罐间距；五视图未发现明显可见穿插。柱墙、屋脊、石基存在必要的隐藏构件嵌接；未声称通过全局实体布尔无交集检查。 |
| 10. 重合面／闪烁 | 完全相同世界坐标面0；后左围墙转角加石盖遮蔽交接，门窗与墙面存在深度偏移。没有执行游戏运行时摄像机闪烁测试。 |

## 重建

保留 `textures/material_atlas.png` 与 `textures/joinery_atlas.png`。使用带Pillow的Python运行 `prepare_textures.py`；随后通过Blender MCP依次执行 `build_courtyard.py`、`finalize_courtyard.py`，执行命名空间中的 `__file__` 指向脚本绝对路径。最终源文件只包含新庭院场景，不包含制作过程草稿。

模型、贴图及渲染依仓库既有忽略规则保留本地；脚本、提示词和检查记录提交版本库。重建需要上述两张本地图集。
