# 庭院高细节版 v002 制作与验收

日期：2026-10-29。按用户最新要求取消 6000 tris 限制，以接近整院参考图的形态与材质为优先。旧版 model_v001 保留。本版使用 Blender MCP 建模、渲染及导出，未接入游戏、未发布版本。

## 交付文件

- courtyard_high.blend：源文件，贴图已打包，灯光和相机单独组织。
- courtyard_high.fbx、courtyard_high.glb：模型导出，不包含摄影棚。
- renders/front.png：2048×2048 成品主图。
- renders/rear.png、left.png、right.png、top.png：1400×1400 多向检查图。
- renders/lion.png、ornament.png：1200×1200 细节图。
- manifest.json：文件大小、摘要及纹理尺寸。
- validation.json、roundtrip_validation.json：实际几何检查与独立导入验证结果。

模型共 978,520 tris，47 个网格组件，29 个导出材质。底面中心为原点；米制美术估算，整体约 14.46×14.46×7.37 米。源文件仅一个场景。模型、纹理、渲染图按项目忽略规则保留本地，脚本及文字记录入库。

## 本次重做

重新制作正殿歇山屋顶、侧坡与山墙，逐块生成带厚度和搭接的弧形筒瓦，增加瓦当、滴水、檐椽与梁架；曲线红脊增加倒角和分缝。正殿、厢房和门楼均补齐背面结构。

门窗改为实体窗格、窗纸、双门门芯、金钉与门环。地面、台基、台阶和院墙分块成形；底座加厚，并调整建筑、平台及摆件位置。木纹重新生成，采用低反差细纹，避免粗条纹抢夺建筑轮廓。

石狮身体、头、腿融合为连续石雕，增加鬃毛、爪、面部和胸饰；金色脊兽增加四肢、角须、鳞片与卷尾。灯笼增加肋条、吊环和流苏；草捆增加独立草茎；井具增加砖圈、内壁、水面、辘轳绳；红旗增加厚度、褶皱及缝边。

发现并修复了柱体穿围墙、曲线截面转向突变、旗面重复厚化以及屋脊下瓦场端面重合。屋脊盖条内保留构造缝，各侧瓦壳仍封闭。

## 贴图与验证

使用内置 ImageGen 生成 textures/wood_basecolor.png，1254×1254；完整提示词及来源见 imagegen_prompt.json。木构采用每约 2 米一个 UV 单元的投影尺度，约 627 texels/m。textures/plaster_normal.png 复用旧版 512×512 轻微表面法线，同尺度约 256 texels/m；法线强度 0.14。雕塑曲面投影不是手工独占烘焙图集；细节主要由几何承担。

源文件重新读取，FBX 和 GLB 在独立 Blender 进程重新导入，三者网格数、三角面数、UV 与包围盒一致（FBX 有浮点误差），缺失图片为 0。GLB 图像内嵌。未执行 Unity 实机性能或联机验证，也未制作 LOD；这是视觉优先的高细节母版。

## 重建

通过 Blender MCP 按顺序执行 build_courtyard.py、finalize_courtyard.py、render_courtyard.py，各次执行命名空间中的 __file__ 应为该脚本绝对路径。辅助模块为 geometry.py、architecture.py、props.py，需保留 textures 目录。重建会覆盖本版本的对应交付文件。不要直接用系统 Python 执行依赖 bpy 的建模脚本。
