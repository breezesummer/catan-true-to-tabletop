# 庭院 v003：形体重做与材质烘焙

日期：2026-10-29。按用户要求先修正屋顶、石狮和脊兽，再制作材质与烘焙；不设面数上限。通过 Blender MCP 执行建模、体积融合、雕刻修整、Cycles 烘焙、渲染和导出。v001、v002 保留。

## 形体阶段

对照整院参考及 A01、A18、A38 原图与部件参考，先进行灰模与局部形体检查，过程图保存在 renders。

- 屋顶：正殿进深由 3.30 调整到 2.95，柱墙高度由 2.35 调整到 2.50，屋顶升高量由 1.63 调整到 1.47；均为美术估算米制参数。主坡筒瓦改为直列，山墙博风脊与下段角脊分离，侧坡与主坡共用边界高度，避免旧版整片瓦列弯向两侧。俯视检查后将台阶进深从 1.085 调整到 1.30，使台阶与缩短进深后的平台重新连续衔接。
- 石狮：重建胸肩、臀腿、前掌、口鼻、耳部及卷鬃；融合连续主体，布尔刻出实际口腔，保留犬齿、眉卷、项圈及吊铃。通过局部渲染修正耳部尺寸和眼窝。
- 脊兽：重建身体、面部、足爪与卷纹，尾巴改为侧面宽厚、横向收薄的 S 形截面，鳞片贴合身体包络面。
- 渲染：调整主光面积与补光强度，并重新匹配主图观察角度和构图；未把参考图或 AI 效果图冒充模型渲染。

## 材质与实际烘焙

material_baking.py 将石材、石雕、木材、金属、红漆、瓦、灰泥七类程序材质烘焙成 1024×1024 的 Base Color、Roughness、Normal，共 21 张图。木纹基底复用 v002 的 ImageGen 输出（提示词见 ../model_v002/imagegen_prompt.json），本轮没有新增图像生成。其余图像由 Blender 材质烘焙获得。

sculpture_baking.py 为石狮、脊兽分别保留高模源：在完整雕塑上细分并施加亚毫米真实位移，选中高模源向成品网格烘焙切线空间法线。石狮位移强度 0.0009 米，脊兽 0.00035 米；投射外扩 0.001 米，最大射线距离 0.003 米。没有以减面为目的改变雕塑轮廓，也没有将主要雕饰压成平面贴图。

两套雕塑图集最终为 4096×4096，每套包含颜色、粗糙度、法线三张图，成品采用唯一 UV；左右及大小不同的对应雕塑复用图集。颜色和粗糙度从原始材质 DetailUV 采样到唯一图集；法线使用真实高模到成品投射。源模型保存在“雕塑高模源_不导出”集合，不计入运行时导出。

本轮发现并修复了：金属漫反射烘焙变黑（颜色改用不含灯光的 EMIT 烘焙）、交叠部分射线污染、细小 UV 区域黑点。最终图集使用 24 像素边缘扩展与中性背景填充；石狮面中心采样的未覆盖纯黑区域由 399 处降至 0，并重新检查近景。

## 交付

- courtyard_high.blend：单场景源文件，材质贴图打包；保留高模源、摄影棚、相机。
- courtyard_high.fbx、courtyard_high.glb：只导出庭院成品组件，排除高模源、灯光及摄影棚。GLB 内嵌贴图。
- renders/front.png：2048×2048 主图；lion.png、ornament.png：1600×1600 近景；rear.png、left.png、right.png、top.png：多向检查。
- material_bake_report.json、sculpture_bake_report.json：材质及烘焙参数。
- validation.json、roundtrip_validation.json：拓扑及导出重新导入验证。
- manifest.json：主要文件摘要与尺寸。

成品网格统计为 3,288,092 tris、45 网格组件、27 个 GLB 材质。此数字仅记录实际结果，不作为质量证明或优化目标。高模源不包含在这个导出统计中。本版为视觉优先资产，没有制作 LOD，也未进行 Unity 真机性能测试、游戏接入或发布。

## 验收范围

几何检查：非流形边、零面积面、六位小数世界坐标判定的完全重合面均为 0；缺少 UV 和缺失贴图为 0。完全重合面检查不等同于全局实体无相交证明，梁柱、瓦脊及雕饰保留隐藏结构嵌合。

门为闭合实心门，窗格后有不透明窗纸，没有透视室内的开口；井、罐、桶的可见内部保留实体内壁。背面按建筑结构补全。倒角、曲面与雕刻细节均由模型承担，细微表面质感由烘焙贴图补充。

形体与材质较 v002 有实质调整，但仍是依照参考的风格化重建。石狮的脸型、鬃毛雕法、脊兽局部比例及纹样仍与参考存在差异，不宣称扫描级复刻或已取得用户美术验收。

## 重建顺序

在 Blender MCP 中依次执行 build_courtyard.py → material_baking.py → sculpture_baking.py → finalize_courtyard.py → render_courtyard.py。每次执行须为 __file__ 传入对应脚本的绝对路径，textures/wood_basecolor.png 和初始 plaster_normal.png 需可读。旧版源文件不受影响，本目录交付文件会被覆盖。

rebake_sculptures.py 可以复用已确认雕塑和 UV 重新烘焙。validate_roundtrip.py 应通过 Blender MCP 后台接口打开本版 .blend，在独立进程中执行；它会导入 FBX、GLB 并比较网格数、面数、UV 和包围盒。

模型、纹理和渲染图按项目忽略规则留在本地；制作脚本、参数与验收记录提交仓库。
