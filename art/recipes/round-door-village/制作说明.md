# 圆门木构村庄

村庄按玩家提供的四视原型建模，去掉圆盘，建筑直接落在石砌墙脚上。正面以双扇圆门、两扇格窗和主山墙为定位，右侧低附屋的屋脊与主脊垂直。背墙沿用正面的木构与灰泥工艺。灰模的色彩由本轮设定，四色席位釉色只施于陶瓦。

## 复建

1. 用含 Pillow 和 NumPy 的 Python 运行 `surfaces.py`，固定种子为 211719。脚本从木、陶、灰泥和石材四个区域派生端木纹、拱石、釉色瓦、氧化金属和玻璃等 16 个色样，同步写入 Unity 的材质贴图。
2. 在独立 Blender MCP 会话内将 `__file__` 设为 `build.py` 的完整路径并执行。脚本组合十四个分件展开整屋 UV，按角点写回所有分件，再以 0.96 毫米的遮蔽距离烘焙接触图。构件分组写入[源文件](../../source/round-door-village/圆门村庄.blend)，游戏使用的 [FBX](../../../Unity/Catan/Assets/Art/NaturalPieces/v001/village.fbx) 只导出建筑。此次使用 Blender 5.2.2 LTS。
3. 在独立 Blender MCP 后台会话执行 `finish_source.py` 保存毫米工作区，执行 `verify.py` 回读正式 FBX，核对落地面、退化面、两套 UV、烟口与铜扣的取样位置和五张贴图打包。
4. 在 Blender MCP 执行 `render.py`。全局变量 `VIEW` 取 `hero`、`views`、`roof` 或 `icons`，分别输出四分之三视角、正交三视图、蓝方交叉屋顶特写和四色缩略图。
5. 在 Unity 执行「Catan／美术／导入圆门村庄」或批处理入口 `NaturalPiecesImport.ImportVillage`。它更新四色正式预制件，并用 Unity 相机从各席预制件导出库存图。

## 第一轮屋面细化

主屋和附屋共用五种平瓦弧度。各排沿坡压住下排瓦头，瓦唇厚度、尾翘和两侧角的收分略有差异。少量断角露出粗糙的褐陶胎，四色釉料在断面处让开。

烟囱上坡的背水盘收进上一排瓦，侧面三段泛水依次搭接，下坡的围裙带有回折边。主附屋交线两侧的瓦分别裁切，露出的金属谷槽一直通到檐口。铅皮有细轧纹与氧化色，门铰保留锻铁表面。

整屋接触图沿檐口、窗洞、圆门石套与砌缝记录遮蔽，局内与库存共用这张图。烟灰沿方烟口压顶偏向一侧，门板下缘有轻微返潮，双铜扣握持处提高光滑度。本轮新增 3,690 个三角面和一张共享接触图，单枚棋子仍用一个渲染器、两个材质槽。

## 棋盘检查

Windows 内测版 2.1.17 读取四人穿越沙漠验收存档，启用双扩展、三国、海港与捕鱼。在现有 `--player-colors` 检查中附加 `--village-views`，从已落子的村庄中选出连接道路最多的一处，检查墙脚高度并拍摄路口。本轮通过 448 项检查，输出 16 张棋盘画面。四席均加载一个共享网格、一份归属色材质，两个材质槽正确读取整屋接触图，建造预览复用同一网格。四色库存图正面的木门与灰泥取样逐像素一致。
