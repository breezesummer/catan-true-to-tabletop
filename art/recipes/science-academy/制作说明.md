# 穹顶观星学宫

科学大都会根据玩家提供的四视图制作。正门朝向 Blender 的 −Y。前厅屋脊横向，两层立面按三开间布置。八角观测塔在左后方，浑仪圆鼓楼在右侧。两楼之间的庭院保留日晷、短栏墙和入口石阶，建筑墙脚直接接触棋盘。[四视原型](../../../assets/references/inbox/建筑/穹顶观星学宫四视原型.png)

穹顶使用两片独立的曲壳。内衬、折边、板缝和快门导轨都有截面，开口到顶部逐渐收窄。折射镜包含回转台、俯仰耳轴、伸缩镜节、寻星镜、物镜压圈和凸面镜片。侧楼的两道主星环分别刻角度和罗马数字，中央星球的经纬线、黄道与星位按球面展开。庭院日晷单独刻制时圈与三角晷针。[望远镜特写](../../previews/science-academy/开缝穹顶与物镜.png) · [星仪特写](../../previews/science-academy/黄道浑仪.png)

石窗背后有实际退入墙体的窗膛。横向风撑位于铅接玻璃前方，深色门扇分出嵌板、锁眼、门带与铆钉。每级踏步单独做出前缘和侧面。第二套 UV 保存通过整栋建筑计算的局部天光可见度和近地风化值。[四分之三视图](../../previews/science-academy/穹顶观星学宫.png) · [正视](../../previews/science-academy/正视.png) · [右视](../../previews/science-academy/右视.png) · [俯视](../../previews/science-academy/俯视.png)

## 复建

1. 玩家原型的 SHA-256 为 `274969bfadadfc16b8c3521d82602483767ba0c0c9c0d38e5aa810d5189606c4`。准备项目内的王城石工配方、建筑纹理和材质母图。仪器使用母图的青铜与橡木样本，程序按种子 21171931 制作氧化、车纹、铅接玻璃与刻线。[王城材质来源](../gothic-royal-city/制作说明.md)
2. 用安装 NumPy 与 Pillow 的 Python 执行本目录的 `finishes.py`。在独立 Blender MCP 后台会话内，将 `__file__` 指向 `build.py` 并执行，生成分件源文件、正式 FBX 和当前扩展棋子的尺寸记录。制作版本为 Blender 5.2.2 LTS。[可编辑源文件](../../source/science-academy/穹顶观星学宫.blend) · [正式 FBX](../../../Unity/Catan/Assets/Art/ExpansionPieces/v001/metro-science.fbx)
3. 通过同一 MCP 执行 `verify.py`，回读网格并检查枢轴、三角面、UV 和物镜到穹顶外的光路。执行 `studio.py` 输出各视角；`VIEWS` 可选 `hero`、`views`、`instruments` 和 `book`。百科图使用蓝席材质。[模型回读](../../previews/science-academy/模型回读.json)
4. 在 Unity 6000.3.25f1 选择「Catan／美术／导入穹顶观星学宫」，或执行批处理入口 `ExpansionPiecesImport.ImportScience`。棋盘与建造预览共用 `ExpansionPieces/v001/metro-science-{席位色}`。带墙时以原有城墙围合模型。[百科词条配图](../../../Unity/Catan/Assets/Resources/Encyclopedia/规则示意/大都会.png)

## 棋盘核查

Windows 内测版 2.1.17 读取四人穿越沙漠存档，同时启用双扩展、三国、海港与捕鱼。在已有城市交点临时显示科学大都会，核对了墙脚落点、穹顶位置的鼠标拾取、带墙方向及四席建造预览。公开投影结束后，对局状态与进入核查时一致。[学宫棋盘近照](../../previews/science-academy/学宫棋盘近照.png) · [城墙围合](../../previews/science-academy/带墙学宫.png) · [全盘视距](../../previews/science-academy/棋盘全景.png)

红、蓝、金黄和米白四席共享网格，各自的遮罩保留石面、镜头与星环原色。学宫专项通过 35 项检查；另一次全套四色棋子核查通过 446 项。正式程序、程序集及三份资源文件与实机验收副本的 SHA-256 逐一相符。[四色同场](../../previews/science-academy/四色棋盘.png) · [四色俯视](../../previews/science-academy/四色俯视.png) · [构建核查记录](../../previews/science-academy/棋盘核查.json)
