# 桌面与实体摆放 v004 配方

本轮桌面色彩贴图为确定性程序生成的 **8192×8192 位图**，三维桌面、薄卡片网格与倒角骰子由 Unity 代码提供。玩家备件使用既有实体网格；生成位图不被登记为三维模型。

## 复现与来源

使用项目已有 Python 环境、NumPy 2.3.5、Pillow 12.3.0：

```powershell
python tools/art/generate_tabletop_oak_v004.py --output .local/ui-v004-oak-rebuild
```

脚本使用种子 20261012，在原生 8K 像素网格中计算宽拼板、弯曲年轮、细导管与微观噪声，不采样或放大旧 1254×1254 图片。保留旧图；新源图和清单位于 `art/source/ui-tabletop-v004`，Unity 的逐字节副本位于 `Assets/Resources/TabletopUI/v004`。两次独立生成的 PNG SHA-256 相同：`87a455a556cea521622b16c1426bcca815546f0bc069b2e77b4df616be71a69a`。

`TabletopTextureImporter.cs` 固定 Windows 8192 上限、BC7 高质量压缩、MipMap、三线性过滤和 16 倍各向异性。材质每 1.6 米使用完整贴图，UV 密度保持固定。独立 `TabletopPipeline-v004.asset` 使用 1:1 渲染比例、4 倍 MSAA，质量设置不主动降低纹理等级。实际视口按窗口尺寸渲染。

## 桌面物件

固定基准坐标一次转换为米制位置，缩放／切换视角只移动相机。地图和物件共用相机，不根据当前屏幕尺寸重新放置备件。薄卡片底部位于桌面，纸边厚度为工作估算 0.36 毫米；拿起状态的短暂抬升仅用于显示。既有棋子保留模型尺度、材质与底面中心轴心。相机射线和显示命中只选择玩家意图，规则入口继续决定合法性。

城市建设卡使用现有 `guidance-upgrade-front.png` 三色完整板作为底板。三色 UV 分界为 0、0.337、0.668、1；每张板内五个小翻板的位置固定在 `TabletopWorldObjects.FacilitySlots`，未建面使用等级正面，已建面使用等级背面。原始照片中的文字仅作为外观，升级成本和顺序读取现有操作快照。源照片和 v001 导出不改写。

本轮没有重新确认实体尺寸、板厚或纸面颜色。整板照片的真实细节仍受原件分辨率限制，8K 桌面贴图不会补充照片缺失的细节。原始模型来源与导出规范沿用 `docs/ART_PIPELINE.md` 和既有实体转化记录。
