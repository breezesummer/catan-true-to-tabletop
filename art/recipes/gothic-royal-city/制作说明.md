# 哥特幻想王城

以玩家提供的[四视原型](../../../assets/references/inbox/建筑/哥特王城四视原型.png)制作城市棋子。面对正门，最高的方形钟塔在左后方，次高尖塔在右侧，八角采光塔位于中殿与横厅交汇处。东南瞭望塔和阶前两座矮塔围合入口。正门八级石阶、扶壁墩和墙脚直接落地。俯视图的正门朝下。

石灰岩墙按卧缝错砌，刻槽与凿面取自不同的石料分区。窗洞、窗膛、石梃和尖拱线脚建成实体，铅接菱格落在后退的玻璃上。门板逐块沿木纹开料，门带、铆钉和门环分别取铁与铜的表面。飞扶壁以分段拱石连接翼廊墩帽。板岩的搭接唇入模，瓦缝与岩层劈理同时写入底色和法线。四席的屋面用色沿用游戏设置，石墙、窗玻璃和门扇保留自身材质。

每个顶点按所在面的半球发出 28 条短射线，以整城实体求拱下、窗膛和檐下的局部天光可见度。可见度与石脚潮痕写入第二组 UV，王城材质据此呈现背光墙面的天光、凹处的阴影与近地面的石色变化。

## 材质来源

玩家原型的 SHA-256 为 `4b92df42cf00889317c076fb8f0247e517da2b05c4a2e9f94a51ea793c9e7a28`。[表面母图](../../source/gothic-royal-city/王城材质母图.png) 使用内置 ImageGen 生成，SHA-256 为 `72a58a3453ddbd6894016ad6451141a936042d29f4f89b788c099ef6d2d8bed0`。制作时使用的完整提示词如下。

> 用途是为哥特王城棋子的真实 PBR 表面取样。正方形 2048×2048，严格的 2×2 同尺寸象限，以画幅正中划分，四区从边到边紧贴，无缝隙边框文字。正交、正面、均匀交叉偏振的文物材质扫描摄影，真实尺度约20厘米，画面从头到尾都在焦内，记录固有色、丰富细密组织，无投影或高光。左上是一块浅蜂蜜灰、奶油暖灰色中古法国石灰岩板，细小压实贝壳碎屑、层理、细针孔、散落矿物包体、淡色云斑，雨水漂洗细纹；没有砌块接缝。右上是一片深铅蓝灰色威尔士天然板岩劈面，劈理薄片、轻微铁锈渗线、细微银灰层层纹路，小幅颜色变化，无瓦片轮廓和拼缝。左下是陈年深褐橡木心材四分之一径切面，细直纤维水平方向贯穿，小木射线、斑纹与少量自然收缩干裂，不拼板，不要钉子。右下是自然氧化的教堂老青铜板的特写，深巧克力褐、旧黄铜的温润磨痕，分散而稀疏的灰绿色铜锈、手锻锤痕，绝不整片亮绿色。高清博物馆文物材料档案质感，非插画，不含建筑模型、摆件或任何文字。

## 复建

1. 准备材质母图，在带有 NumPy 和 Pillow 的 Python 中运行 `surfaces.py`。固定随机种子为 21171902，十个表面分区共用一套 UV。
2. 在独立的 Blender MCP 后台会话中执行 `build.py`，将 `__file__` 设为脚本的绝对路径。脚本使用 Blender 5.2.2 LTS，保存[可编辑源文件](../../source/gothic-royal-city/哥特王城.blend)，再生成[游戏 FBX](../../../Unity/Catan/Assets/Art/NaturalPieces/v001/city.fbx)。建筑坐标的正面是 −Y。
3. 在该会话中执行 `verify.py` 回读导出的 FBX。随后执行 `render.py`，可用全局列表 `VIEW` 指定 `hero`、`detail`、`views`、`icons` 或 `book`。百科的城市词条使用 768 像素的红席四分之三视图。摄影棚地面只在拍摄时创建。
4. 在 Unity 6000.3.25f1 执行「Catan／美术／导入哥特王城」，或运行批处理入口 `NaturalPiecesImport.ImportCity`。四色预制件保持原资源地址。导入时生成各距离的网格细节，最后从正式模型更新库存图。

## 棋盘实拍

Windows 内测版 2.1.17 读取四人穿越沙漠存档，双扩展、三国、海港与捕鱼同时开启。在实局交点检查墙脚高度，在同一局面的城市与城墙预览中核对四色共用的网格、材质和屋面归属色。四张库存图分别由对应席位的正式预制件导出。干净目录复建后，四张材质贴图与模型回读记录逐字节一致。
