# 田园桌游音频 v001

原始声纹为本项目原创的确定性程序合成，配方保存在 `Unity/Catan/Assets/Scripts/TabletopAudioSynth.cs`，事件映射保存在同目录 `TabletopAudioModel.cs`。原声没有外部录音来源，不借用现成游戏、影片或商业音效。

Unity 启动时生成 35 种独立单声道音效与一段 12 秒海浪、草地风、远处鸟鸣环境循环。生成只使用音色专用的固定种子，不访问规则权威状态、牌库、隐藏手牌、Unity 随机数或游戏随机数。音频不是 3D 网格资产。

在项目根目录运行以下命令可导出试听 WAV 和 SHA-256 清单；运行时与导出使用同一配方：

```powershell
pwsh -NoProfile -File tools/art/Export-TabletopAudio.ps1 -OutputDirectory .local/audio-v001
```

WAV 为 24 kHz、单声道、16 bit PCM，Unity 运行时使用同源浮点采样。`manifest.json` 记录版本、源文件校验值、每片段时长、峰值、RMS 与导出校验值。单片段峰值不超过 0.70、首末采样为零；10 声部按活跃声部数量平均分配 0.78 效果总线，环境总线为 0.30，即使所有声部峰值同号，理论总峰值上界为 `0.70 × (0.78 + 0.30) = 0.756`，保留混音余量。

| 收资源、交易、抽牌与打牌 | 纸张、木质细碰、轻铃与金属零钱声 |
| 道路／村庄／城市／城墙 | 木锤、木料、低石击、石材连续落定 |
| 造船／移船／港口 | 木料、水声与港口金属铃 |
| 骑士招募／晋升／激活／移动／战斗 | 护甲金属、上行铃、短甲片、四组蹄声、刀剑碰击 |
| 强盗、海盗与海盗群岛自动侵袭 | 低木弦紧张音、低号角与水声 |

音量、静音保存在 Unity `PlayerPrefs` 的 `catan.audio.v1.*` 键下；不改变权威存档。程序化声音的听感仍需用户在实际扬声器／耳机上确认，不将样本结构检查等同于人工听觉验收。
