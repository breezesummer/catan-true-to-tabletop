# 商人棋子

商人以右手摊掌迎客，左臂夹住条纹羊毛布卷。帽箍、翻领、腰带和靴口各有独立的厚度，双肩带从牛皮行囊绕过肩峰。靴底直接接触地块。彩色三分之四视图用于取色和定位磨损，灰色视图用于核对侧影、发量和行囊结构。背面的皮具、呢料沿用正面的颜色。[四视原型](../../../assets/references/inbox/单位/商人四视建模原型.png) · [成品四视图](../../previews/travelling-merchant/商人四视图.png)

| 项目 | 规格 |
| --- | --- |
| 棋盘尺寸 | 宽 8.04、深 8.47、高 15.76 毫米，枢轴位于靴底中心 |
| 可编辑母版 | 19 组分件，双手各含一级可编辑细分，求值后共 230,818 个三角面，内嵌三张贴图 |
| 棋盘网格 | 一个网格、一个材质槽。Unity 的五档网格分别为 74,000、37,621、18,992、9,797、6,427 个三角面 |
| 纹理 | 三张 2048 × 2048 图集，分别记录固有色、切线空间法线，以及金属度与光滑度。后者以红色通道存金属度，以透明通道存光滑度 |
| 游戏入口 | 棋盘和落点预览共用 `NeutralPieces/v001/peddler-stall`。百科的商人棋子图取自 Windows 客户端 |

面部的鼻梁、眼眶、唇线和颌部由连续截面塑形。布卷由一幅有厚度的毛料盘绕而成，露出的螺旋端面和手掌下的布头属于同一卷布。呢料保留经纬、暗花和局部褪色；肩带、钱袋及靴面分别处理皮纹、边缘包浆与线迹。肩带按衣袍表面贴合，袖口里布沿弯肘收回。[面部与衣料近景](../../previews/travelling-merchant/面部与衣料.png) · [侧面](../../previews/travelling-merchant/侧面.png) · [俯视](../../previews/travelling-merchant/俯视.png)

右手按原型做掌心向上的邀请手势，左手依布卷的实际曲面屈指。两手共用 MakeHuman HM08 的 CC0 人体裁片，保留虎口、指蹼和原生甲板。每只手有五个独立指组，腕缘与袖内前臂共用一圈顶点。手背、掌面用平光皮肤母图分别展开，甲板另作粗糙度和甲尖色。[双手原型与转面对照](../../previews/travelling-merchant/双手原型对照.jpg) · [人体裁片与出处](../roadside-bandits/制作说明.md) · [摆姿配方](merchant_hands.py)

## 复建与核对

1. 恢复原型 PNG，核对 SHA-256 为 `7f59b3b0b4b5295e084dd617f0bf3d6d328ecd651ceb81e7d2de3f684a42e178`，并恢复人形棋子共用的平光手部母图。纹理使用固定种子 `211720`。[手部母图](../../source/roadside-bandits/手掌手背与前臂母图.png)
2. 在独立的 Blender 5.2.2 LTS 后台 MCP 会话中用 `runpy.run_path` 执行同目录的 `build.py`。Blender 的 Python 环境需能导入 NumPy 和 Pillow。脚本先制作分件和三张图集，再生成减面网格。全部导出成功后替换游戏资源。要在空目录复建，可通过 `init_globals` 传入 `art_dir` 和 `source_file`。[Blender 母版](../../source/travelling-merchant/行商.blend) · [游戏 FBX](../../../Unity/Catan/Assets/Resources/NeutralPieces/v001/peddler-stall.fbx)
3. 通过 Blender MCP 执行 `photograph.py`，从正式 FBX 回读尺寸、双靴接触区和材质槽，再拍摄四视图。摄影棚接影纸只参与拍摄。空目录复建的三张纹理逐字节一致，网格坐标、三角索引与 UV 摘要一致。[模型回读](../../previews/travelling-merchant/模型回读.json) · [复建核对](../../previews/travelling-merchant/复建核对.json)
4. Windows 客户端使用 `--ocean-view-verify <输出目录> --expansion-pieces --neutral-pieces` 进入四人双扩展、三国、海港、捕鱼、穿越沙漠的基准棋盘。验收将商人摆至麦田，核对棋盘与拖动预览的网格、落点、朝向、材质及拾取，再由游戏相机拍摄百科图。[棋盘视距](../../previews/travelling-merchant/棋盘视距.png) · [百科实拍](../../../Unity/Catan/Assets/Resources/Encyclopedia/棋子示意/商人.png) · [客户端验收](../../previews/travelling-merchant/实机验收.json)
