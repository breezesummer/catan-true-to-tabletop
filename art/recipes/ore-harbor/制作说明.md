# 矿石港 · 原矿商港

高仓开券门，屋脊垂直于岸线。右侧低仓沿岸展开，正立面为弧顶双扇门和两扇尖券窄窗。坡面漆牌上的黄铜字和三块矿徽均为立体件。正面吊机由斜撑、木臂、双颊滑轮、卷筒、吊钩与四角挂索组成，斗底悬在主埠上方。大箱与分级浅盘摆在临海一侧，左侧短桥伸出一跨。

## 尺寸与落位

尺寸依原型和棋盘岸边两个交点之间的空间估算。正式模型宽 22.78、深 16.99、高 20.07 毫米，含水下桩段。Blender 的正 Y 轴指向陆地。右侧重货区由五皮块石胸墙和侧向回墙承托，顶面分块铺石。左侧桩承短桥与仓下格栅梁透水。

岸面为本地高度零，静水面低 3.50 毫米，最深桩脚再入水 1.75 毫米。后部面板跨过岸线 0.27 毫米。码头左侧桥趾距模型原点向海 6.80 毫米。渔网避让使用宽埠和短桥两块轮廓，船位取短桥的海侧边缘。

## 材质与生产

原型是单色多视图，实物配色取旧橡木、蓝灰劈理板岩、凿面灰岩、铁锈与含石英的灰蓝矿石。对每块矿坯按固定种子切出大小不同的断面，沿相同方向投影矿脉。梁板 UV 沿木纹展开，横断面使用端木样本。图集根据矿面的氧化与石英占比控制金属度，窗券、石板瓦的叠缝、钢箍铆头和三股绳均有几何厚度。

三张 2048 × 2048 图集供六个正式网格共用一个 URP 光照材质。固有色按 sRGB 导入，切线法线与表面属性按线性数据导入。表面属性的 R 通道为金属度，A 通道为光滑度。第二套 UV 保存 Blender 针对整座港口烘焙的天光可见度和潮湿程度，拱膛与货箱内壁保留阴影，水线附近的块石和木桩颜色加深、表面变湿。最高精度共 98,606 个三角面，远景使用 Unity 的视距细节级别。拾取使用另存的 240 个三角面，平面轮廓为 4 个三角面。

1. 用安装 NumPy 和 Pillow 的 Python 执行 [surfaces_ore.py](surfaces_ore.py)。母图使用的完整[生成提示词](材质提示词.txt)随配方保存。
2. 将 Blender MCP 接入独立的 Blender 5.2.2 LTS 后台会话。通过 `execute_blender_code` 以 `runpy.run_path` 执行 [build.py](build.py)。需要可导入的 NumPy、Pillow 与 Windows Georgia 字体。母版保留十七个可编辑分件和三张内嵌贴图。[分件母版](../../source/ore-harbor/原矿商港.blend) · [游戏 FBX](../../../Unity/Catan/Assets/Resources/PaintedMap/Coast/ore-harbor.fbx) · [拾取 FBX](../../../Unity/Catan/Assets/Resources/PaintedMap/Coast/ore-selection.fbx)
3. 在同一 MCP 入口执行 [inspect_port.py](inspect_port.py)。在 `init_globals` 中依次将 `view_name` 设为「海侧斜视」「正面」「右侧」「俯视」。摄影场景回读正式 FBX，输出[四视图](../../previews/ore-harbor/原矿商港四视图.jpg)与[几何核对](../../previews/ore-harbor/模型回读.json)。
4. Windows 客户端以 `--ocean-view-verify <输出目录> --ore-port` 运行四人双扩展、三国、海港、捕鱼与「穿越沙漠」的验收对局。矿港参数之后也可传入同一配置的存档，复核周围已有建筑的岸线。
5. 商船验收从[第八回合存档](../../../docs/verification/direct-input-2112/穿越沙漠四人验收起点.json)载入规则会话。在 P1 当前三国操作窗口向矿石港所在海岸边发送 `BuildShip` 命令，再保存会话。用 `--ore-port <造船后存档> --ore-berth` 验证已落子的商船、船身朝向和艉部水线。[实机记录](../../../docs/verification/ore-harbor-2117/实机验收.json)
