# 自然棋子第二轮精修

本轮依据玩家视角的评议继续优化，沿用 2.1.11 与现有四色资源入口。全部几何、材质烘焙、透明缩略图均通过 Blender MCP 在独立场景内完成；保留上一版配方与概念图供对比。

- 主城从七组屋顶收敛为中央主塔、左右副塔与低门厅四组屋顶。前部改为矮连廊，增加完整石墙露出面积与塔楼高差；门前台阶逐级展开。
- 村庄保留大小双屋结构和烟囱。两类建筑减少细碎瓦片，消除坡面重叠造成的碎缝，屋脊提亮、檐口压暗，并加入轻微瓦片与石材深浅变化。
- 道路减少细碎分段，边石和铺石保留小幅高低、位置变化，四色仍集中在两侧边石。
- 复用上一轮生成的天然石木底图，在 Blender 内独立展开 UV，烘焙材质色差与环境遮蔽。主城使用 2048² 贴图，村庄、道路使用 1024² 贴图。门窗暗部合入石木贴图。
- 贴地柔影以三圈渐隐顶点透明度直接并入网格，占第三材质槽。每件仍为一个网格、三个材质，四色共用几何；没有新增运行时贴图生成、碰撞或逐帧脚本。
- Unity 中用烘焙遮蔽代替建筑接收实时阴影，避免厘米级模型的瓦边产生阴影黑斑；方向光的表面明暗和独立接地柔影保留。

按顺序经 Blender MCP 执行 `build_models.py`、`render_models.py`，再运行 Unity 编辑器入口 `NaturalPiecesImport.Run`。游戏资源仍写入 `Unity/Catan/Assets/Art/NaturalPieces/v001` 与 `Assets/Resources/NaturalPieces/v001`，保持既有资源地址与调用链稳定。

源场景为 `natural-pieces.blend`；`city-inspection.png`、`village-inspection.png` 为 Blender 检查图，不冒充实际游戏截图。实际客户端证据见 `docs/verification/natural-pieces-refine-2111`。
