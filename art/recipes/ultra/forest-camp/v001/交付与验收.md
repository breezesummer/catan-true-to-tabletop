## 量化结果

| 项目 | 实测结果 |
| --- | --- |
| 整块LOD0 | 5990 tris，包括全部摆件、人物、叶簇与倒角 |
| LOD1导出 | 4738 tris；单独提供，Unity预制体暂使用LOD0 |
| 地块／树林／地被 | 142／2632／624 tris |
| 营地／人物 | 1920／672 tris |
| 尺度 | 米制，六边形外接半径39.5毫米；对应现有草原样板工程尺度，不是实物测量 |
| 材质 | 14个；叶簇使用双面Alpha Clip阈值0.5，GLB导出为MASK |
| 拓扑 | 退化面0；完全重复三角形0；非植被实体非流形对象0 |
| 资源 | 打包贴图3张，缺失外部文件0，UV坐标异常0 |
| 运行环境 | Blender 5.2.2、Unity 6000.3.25f1、Windows Player、AMD Radeon RX 9070 XT |

原始面数8524，先缩减被遮挡枝段、截面与次要结构，再将大块树冠改为多方向叶簇卡片；没有通过隐藏对象或不统计实例规避6000面上限。保留规则四边面网格作为建模结构，导出时统计真实三角形。人物为静态姿态，未绑定骨骼，不宣称适合直接蒙皮动画。

独立审计发现早期叶簇超边约3.7毫米，已将装饰水平布局内收至82%，并将“距离六边形边界至少3毫米”设为检查断言。实际结果见 [独立审计](../../../../exports/ultra/forest-camp/v001/independent-audit.json)。这只证明几何边界，不替代道路、交点和拾取的完整棋盘验收。

## 用户十项要求逐项检查

| 要求 | 结果与界限 |
| --- | --- |
| 1. 形态、细节和风格 | 保留厚六边形、繁茂森林、右前营地、双红棚、旗帜、围栏、木料及两名工人。按本次要求采用细密像素贴图。人物面部、针叶树枝层、绳结与散落物明显简化，未宣称逐细节等同参考图；外观仍由用户验收。 |
| 2. 游戏布线 | 柱木使用规则环截面，棚顶有序四边网格，封闭底座，植被为有意使用的双面裁切卡片；模型用于静态环境。 |
| 3. 倒角 | 土层实体收边，铁斧等重点硬边单段倒角，圆柱轮廓用于木材；小件没有统一增加高成本多段倒角。 |
| 4. 面数 | Blender独立读取和Unity导入均为5990 tris，低于6000。 |
| 5. 材质与UV | 树皮、年轮、布、林地、泥土和苔石分别分配图集区域；修正土层侧面拉伸；点采样与MipMap保留像素风。近景仍可识别复用叶型，未声称完全无重复。保留几何法线，本版无需额外生成法线贴图。 |
| 6. 360度 | 同模型正、侧、背、顶与反向渲染；所有实体有背面，叶簇双面裁切。背面枝干与不可见结构为设计补全。 |
| 7. 可见内部 | 两座敞开棚均有四柱、横梁、支撑与实体储物，棚布有厚度；不是棚内照片贴片。 |
| 8. 镂空瑕疵 | 非植被实体开放边界检查通过；草叶和树冠的透明间隙是预期植被结构。 |
| 9. 穿模 | 检查营地近景、顶视和反向，修正边缘叶簇越界。枝干、树根和支架接合采用合理嵌接；未作全部三角形之间的碰撞证明。 |
| 10. 重合面 | 完全重复三角形为0；棚顶实体厚度，未铺设共面的地面覆盖片；渲染未见明显闪烁。完全重复检测不等于任意共面多边形覆盖的数学证明。 |

## 构建和范围

Windows构建位于 game version/1.7/Catan1.7.6-Forest-Camp/Builds/Windows/Catan1.7.6.exe。使用原项目构建入口，版本与窗口名为Catan1.7.6；旧内测按现有保留脚本保留最近5次。此次没有正式发布，也没有要求安卓发布，因此未生成新的正式发布目录或APK。

通过显式参数 `--forest-camp-verify 输出目录` 启动资产验证。它加载独立展示场景，导出四个真实Player视角后退出。未修改规则、权威状态或现有棋盘地形选择；正常游戏保留原森林。构建包含本次独立预制体，便于后续接入。

尚未验收：用户外观确认、邻接地块与拥挤交点的操作测试、正式棋盘局部开发逻辑、完整地图性能、Android真机、动画和LOD自动切换。19块此类LOD0仅三角形合计113810，此算术估算不包含其他棋子，也不能代表最大地图或帧率。ROADMAP阶段保持原状态。
