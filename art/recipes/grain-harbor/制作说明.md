# 谷物商港

按玩家提供的四视灰模制作。左侧是带进货拱廊的高仓，右侧是双扇门的长仓，两道屋脊互相垂直。临海屋坡镶三穗麦徽和立体 2:1 商号牌。悬臂吊机从左仓挑出，滑车吊起三只小粮袋。装卸廊另摆两只直立大袋、一只横袋和盛满麦粒的柳编量斗。[原型](../../source/grain-harbor/谷物商港四视原型.png) · [成品四视图](../../previews/grain-harbor/谷物商港四视图.jpg)

仓身和码头在海侧受力。塔下的桩桥与右侧的石驳岸相接，水面透过桥下桩间。模型沿棋盘公开海岸边摆放，原点在岸外 9.90 毫米，+Y 朝岸，米制 Z=0 对齐岸面。后墙越过岸线约 0.22 毫米，挑桥外缘离岸 15.35 毫米，桩端入水 1.87 毫米。棋盘提供海水、陆地和邻接渔场。建筑没有独立展示底座。

## 表面与制作

灰模没有指定配色。板岩取灰蓝和石青色，仓墙用浅灰暖色石灰岩，结构和栈板分别采用深橡木与海风漂灰的旧木。切角漆牌衬出铜字和鎏金麦穗。谷物袋采用本色、褪红条与靛灰条三种麻布。凿面、板岩片理、湿木色带、麻布经纬和金属氧化均来自固有色与表面数据。麦粒腹沟、柳条、绳股、粮袋侧缝、窗口与券石在模型中成形。

1. 在可导入 NumPy、Pillow 的 Python 环境运行 [grain_atlas.py](grain_atlas.py)。几何沿用[海港木作](../lumber-harbor/joinery.py)及[砌石工艺](../common-harbor/quay_craft.py)，麦港自己的纹理、屋面、货载和吊机参数均保存在本目录。
2. 在独立的 Blender 5.2.2 后台会话中，通过 Blender MCP 的 `execute_blender_code` 调用 `runpy.run_path` 执行 [build.py](build.py)。字模使用 Windows Georgia Regular。米制 FBX 使用 −Z 朝前、Y 朝上，携带 UV、法线和切线。[可编辑母版](../../source/grain-harbor/谷物商港.blend) · [正式模型](../../../Unity/Catan/Assets/Resources/PaintedMap/Coast/grain-harbor.fbx) · [拾取简模](../../../Unity/Catan/Assets/Resources/PaintedMap/Coast/grain-selection.fbx)
3. 通过同一 MCP 执行 [inspect_port.py](inspect_port.py)，在 `init_globals` 中分别赋予 `view` 值「海侧斜视」「正面」「右视」「俯视」。摄影场景回读游戏 FBX，使用母版内嵌纹理，棚拍海水和岸滩仅用于摄影。

## 棋盘复核

Windows 客户端的 `--ocean-view-verify <输出目录> --grain-port` 入口按四人双扩展、三国、海港、捕鱼和「穿越沙漠」开局。也可在 `--grain-port` 后传入[四人验收存档](../../../docs/verification/direct-input-2112/穿越沙漠四人验收起点.json)复核已有对局。验收检查装卸构件的水线、后墙贴岸、简模泊位、贴图绑定、视距细节和不同机位的交易拾取。[实机近景](../../previews/grain-harbor/谷物商港实机.png) · [实机记录](../../../docs/verification/grain-harbor-2117/实机验收.json)

同边船局面使用地图种子 47。四席完成选将后，起始席在麦港交点 V4:14 依次执行开局聚落和同边造船命令。传入该存档并追加 `--grain-berth`，可以核对商船沿岸朝向和船身到挑桥外缘的距离。[实际靠泊](../../previews/grain-harbor/同边商船靠泊.png) · [船舷与挑桥之间的水面](../../previews/grain-harbor/挑桥与船舷俯视.png)
