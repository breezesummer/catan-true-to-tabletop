# 哥特商会之都

按玩家提供的四视原型制作贸易大都会。三座商馆沿街并列，中央山墙略高，商会大厅横跨后院。最高方钟楼位于左后，八角货栈塔位于右后。人物面对正门时，吊货架在右。石墩、商馆和布卷直接接触棋盘，拱廊内的石铺地面收在柱线以内。[原型图](../../../assets/references/inbox/建筑/哥特商会四视原型.png) · [成品四视图](../../previews/trade-guildhall/商会四视图.png)

| 项目 | 成品规格 |
| --- | --- |
| 棋盘尺寸 | 宽 27.140、深 22.061、高 27.920 毫米，按原贸易棋子的占地和原型正视比例定标 |
| 枢轴与方向 | 枢轴位于包围盒底面中心，Blender 正门朝 −Y |
| 可编辑原件 | 11 组构件，4 张内嵌贴图 |
| 棋盘模型 | 四席共用一个网格和两个材质槽。近景 85,505 个三角面，四档远景依次为 42,752、21,376、10,688、5,375 面 |
| 表面图集 | 13 个分区。固有色与切线空间法线均为 2048 像素，金属度／光滑度为 512 像素，屋面归属色遮罩为 1024 像素 |

三座敞廊均有独立拱腹和径向楔石，拱口至内铺约 3.97 毫米。两口铜钟从横梁悬入贯通钟室。表盘有六十道分刻、罗马时标和两根铆接的指针。临街的铜秤盾徽另有秤梁与双秤盘，吊货架通过斜撑、滑轮、吊索和四点吊带承接木箱。[拱廊与商货特写](../../previews/trade-guildhall/交易拱廊与吊货架.png)

石灰岩、板岩、橡木和青铜沿用项目王城材质的原始采样。商会单独调整石料和岩片色调，用定向 UV 铺设卧缝、页理与顺纹。每排板岩下唇入模。亚麻布有交替经纬、织边与卷端螺纹，钟面依据 Windows Times New Roman 字模制版。金属度和光滑度分别写入红色与透明通道。整座建筑的短程天光遮蔽及墙脚潮痕保存在第二组 UV，玩家色仅覆盖屋面。

## 复建

1. 使用装有 NumPy、Pillow 和系统字模的 Python 运行 `guild_maps.py`。输入为王城的固有色、法线、表面属性图和板岩遮罩。纤维纹理的种子为 `21171907`。原型 SHA-256 为 `2d95a0e3a146fbf9142ceba7b57715702af10e3126f213458490e2f1608a289b`。
2. 在独立的 Blender 5.2.2 LTS 后台 MCP 会话中执行 `build.py`，将 `__file__` 设为该脚本的绝对路径。脚本先保存分件原件，再导出米制 FBX。[Blender 源文件](../../source/trade-guildhall/哥特商会之都.blend) · [游戏 FBX](../../../Unity/Catan/Assets/Art/ExpansionPieces/v001/metro-trade.fbx)
3. 在同一会话中执行 `verify.py`。脚本从 FBX 回读尺度、拱廊净深、材质、两组 UV 和三角面，并更新扩展棋子导入清单中的贸易条目。执行 `render.py` 可拍摄模型各视角。[模型回读](../../previews/trade-guildhall/模型回读.json)
4. 在 Unity 6000.3.25f1 运行「Catan／美术／导入哥特商会之都」，批处理入口为 `ExpansionPiecesImport.ImportTrade`。棋盘实体、带城墙形态和建造预览通过 `ExpansionPieces/v001/metro-trade-颜色` 取用相同网格。

空输出目录复建后，四张纹理逐字节一致。FBX 回读后，三角面绕序、构件坐标、材质分区和两组 UV 的规范摘要均与游戏文件一致。
