# 王城石墙

根据玩家确认的[四视原型](../../../assets/references/inbox/建筑/王城石墙四视原型.png)和[王城合围俯视图](../../../assets/references/inbox/建筑/王城石墙合围俯视.png)制作。建筑正面朝 Blender −Y，对应 Unity 预制件局部 +Z。游戏以首条相连的本方道路决定整组朝向，无路时用城市的默认朝向。

| 部位 | 成品 |
| --- | --- |
| 普通城市外围 | 宽 26.09、深 28.05 毫米。以棋盘面为零，墙垛高 5.32、圆塔高 6.07、门墩高 7.15 毫米。地下收分石基伸至 −4.05 毫米，供岸线顶点使用 |
| 庭院与道路 | 夯土地表高 0.77 毫米；错缝铺石穿过净宽 4.56 毫米的门洞。墙脚、拱脚与门前路面各有承托 |
| 石工 | 各石块有独立的长度、错缝、切角与细倒棱；两心尖券两圈错缝，拱腹贯通，跨中有整块锁石。角塔的内向垛口敞开，扇形石铺面接入墙顶走道 |
| 门旗 | 起伏的燕尾亚麻有经纬、双面布、卷边及四个挂耳。铜杆、端头和铁托与布面分材质处理。归属色遮罩只覆盖门旗 |
| 运行资产 | 一份网格、两个材质槽、五档细节。四个席位共用石料。双组 UV 分别记录定向材质和天光可见度／墙脚风化 |

## 材质与复建

1. 在带 NumPy 和 Pillow 的 Python 中运行 [wall_maps.py](wall_maps.py)。输入为项目既有的[王城材质母图](../../source/gothic-royal-city/王城材质母图.png)。随机种子为 21171122。十个分区分别处理卧石、旧石、修边石、基脚、铺石、石灰灰浆、庭土、亚麻、黄铜及铁件。固有色和切线法线为 2048 × 2048，金属度／光滑度和染色遮罩为 1024 × 1024。
2. 在独立的后台 Blender MCP 会话中，通过 `execute_blender_code` 用 `runpy.run_path` 执行 [build.py](build.py)。石作种子为 211722。19 组构件保存在[可编辑母版](../../source/royal-curtain-wall/王城石墙.blend)，内嵌四张贴图。[正式 FBX](../../../Unity/Catan/Assets/Art/ExpansionPieces/v001/wall.fbx)只导出合并的游戏网格。导出后同步扩展棋子的几何清单。
3. 通过同一 MCP 入口执行 [verify.py](verify.py) 与 [render.py](render.py)。回读检查两组 UV、着色区域、退化三角面、贯通门洞与四套合围。逐个检查建筑与地上墙体的三角面有无相交，另以射线检查拱门能否贯通。[合围回读](../../previews/royal-curtain-wall/合围回读.json) · [整墙](../../previews/royal-curtain-wall/王城石墙.png) · [券石与门旗](../../previews/royal-curtain-wall/券石与门旗.png)
4. 在 Unity 6000.3.25f1 选择「Catan／美术／导入王城石墙」，批处理入口为 `ExpansionPiecesImport.ImportWall`。此步骤生成四席预制件及库存图。近至远五档三角面数为 97,956、49,022、24,512、12,287、6,144。

## 城内装配

墙身在棋盘平面等比展开，四座角塔保持圆形。普通王城向门前移 0.25 毫米。商会和学宫采用 1.40 倍平面围墙，各自向门前移 2.35、1.70 毫米。议政宫沿用入城后的 76% 宫体尺度，围墙平面取 1.21 倍，宫体前移 0.25 毫米。三座大都会的围墙高度都取普通城墙的 1.14 倍。

两张原型的 SHA-256 分别为 `392e01bd39a557660aba3692a5b4746a4cd3bec5cec41d2925c3062704f1f365` 与 `8fab5f9c8d53998dc5ef03df42e7f9ab26caf257986e6c823f971d9f056da431`。
