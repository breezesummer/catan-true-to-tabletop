# 羊毛港口 · 毛料商港

以玩家提供的灰模四视图确定双仓高差、屋脊方向、起重梁、屋面招牌和码头货位。正面朝海，左侧尖拱通入高仓，右侧长仓有两扇拱窗和双开板门。后墙的门槛石贴岸，装卸通道由临水石驳岸和挑出的桩桥承托。水面及岸线来自对局棋盘。[原型](../../source/wool-harbor/羊毛港四视原型.png) · [四视图](../../previews/wool-harbor/羊毛港四视图.jpg)

| 项目 | 成品 |
| --- | --- |
| 棋盘尺寸 | 宽 25.13、进深 16.10、全高 20.20 毫米。接岸石搭入规则岸线 0.52 毫米，桩底低于平均水线 1.62 毫米 |
| 可编辑母版 | 5 组、15 个网格。羊毛港与矿石港图集均内嵌在母版中 |
| 运行资源 | 仓房、屋牌、栈桥、岸上毛包和吊机共 5 个网格，羊头和港仓共用羊毛港材质，铭牌与铸字共用矿石港材质。最高精度合计 109,750 个三角面，导入时生成视距级别 |
| 拾取与靠泊 | 独立简模用于港口点选和渔场投影。桥头在港根节点海侧 5.68 毫米，同边商船沿外缘平行靠泊 |

灰模配色按实物材料补全。灰蓝板岩逐片搭接，橡木顺构件方向展开，湿桩在潮线附近转深。前墙留出真实券洞，窗石、门环和码头压顶建有侧面。卷端螺旋、纤维纹理和羊毛脂色差进入毛包的固有色与切线法线。每道麻带的两边分别投到毛包表面，随压痕收紧。羊头以浅色雕刻件表现，耳窝、口鼻、额卷与黄铜镶边在斜视下均有起伏。

## 复建

1. 准备[通用港石木图集](../../../Unity/Catan/Assets/Art/PaintedMap/CommonHarbor/)、[驳岸石作](../common-harbor/quay_craft.py)及[木构工法](../lumber-harbor/joinery.py)。用带 NumPy 和 Pillow 的 Python 执行 [wool_surfaces.py](wool_surfaces.py)，生成三张 2048 × 2048 图集。固有色使用 sRGB，法线与表面属性使用线性采样。属性图的红通道存放金属度，透明通道存放光滑度。
2. 在独立的后台 Blender 5.2.2 会话中，通过 Blender MCP 的 `execute_blender_code` 以 `runpy.run_path` 执行 [build.py](build.py)。脚本固定随机种子，铸字取自 Windows Georgia。导出采用米制，前方 −Z、上方 Y，保留 UV 和切线。[Blender 母版](../../source/wool-harbor/羊毛港.blend) · [正式 FBX](../../../Unity/Catan/Assets/Resources/PaintedMap/Coast/wool-harbor.fbx) · [拾取 FBX](../../../Unity/Catan/Assets/Resources/PaintedMap/Coast/wool-selection.fbx)
3. 用同一 MCP 执行 [inspect_port.py](inspect_port.py)。脚本回读正式模型，检查贴图、尺寸、接岸石与水线，输出临海斜视、正面、右侧与俯视样片。原型文件的 SHA-256 为 `89fe080abac937faabb80b8d7772b5102dd7618e16b5c795454796de2c231e05`。

## 实机复核

Windows 内测版 2.1.17 以四人双扩展、三国、海港、捕鱼和「穿越沙漠」开局。用 `--ocean-view-verify <输出目录> --wool-port <存档>` 取景并检查三种俯角、四个方位下的点选。种子 41 用于拍摄森林岸线的完整港楼，同边已通过规则入口放置商船的存档另加 `--wool-berth`。[棋盘近景](../../previews/wool-harbor/羊毛港实机.png) · [接岸俯视](../../previews/wool-harbor/接岸俯视.png) · [商船靠泊](../../previews/wool-harbor/羊港商船靠泊.png) · [验收记录](../../../docs/verification/wool-harbor-2117/实机验收.json)
