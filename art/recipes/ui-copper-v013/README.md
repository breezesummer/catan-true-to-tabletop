# 铜木桌游 UI 素材配方 v013

日期：2026-10-28。参考为用户本轮附图，本地副本 `参考界面.png`。棋盘、棋子、卡牌插画与头像沿用已有资产，只制作和替换 UI 外观。

## 交付素材

- `Unity/Catan/Assets/Resources/TabletopUI/v013/walnut-inlay.png`：使用内置 imagegen 工具生成的胡桃木内衬，原始输出 1254×1254，已复制进工程，运行时通过 Resources 加载并缓存。未使用 CLI 或外部 API。
- `Unity/Catan/Assets/Scripts/CopperTabletopSkin.cs`：可重建的铜质倒角、圆盘、角铆钉、透明九宫格边框、数字底板、卡牌选中框及铜色滚动条。边框与圆盘各 128×128，滚动条 16×16，仅首次使用时生成纹理；所有尺寸共用缓存，非每帧生成。
- 库存图标复用 `OperationPieceAssets` 中现有模型的透明缩略图，无新增棋子建模，仍按不透明轮廓接收拿取操作。

## 最终生图提示词

> 游戏UI用单一无缝纹理素材：1024方形，正面平面视角，深暖棕红胡桃木与细腻皮革质感，低对比度精细水平木纹，均匀柔和暖光，参考经典铜边桌游界面的面板内衬。整张仅材质，不要边框，不要物品，不要文字，不要图标，不要明显暗角，不要透视。供米白中文叠加阅读，精美写实手绘质感。

提示中的1024为目标，工具实际交付1254方形；工程导入按Unity纹理设置处理。面板内衬作为单张缩放纹理使用，未把“无缝”提示当作平铺检验通过。

## 实现约束

- 玩家名、数字、规则文字均独立实时绘制，不烘焙进素材。
- 铜边四角固定，边条伸缩；骰盘只覆盖透明边框，不盖住已有三维骰子。
- 色值在线性项目中转换，避免木面与铜边被抬亮成浅黄。禁用态保留背景和数字可读性，操作权限仍由原逻辑控制。
- 保留三国模式武将、技能与直接选牌区域，在参考图分区上兼容这些已有功能。
- 无规则、网络协议、权威存档变更。新增素材已纳入 PC 构建贴图检查。
