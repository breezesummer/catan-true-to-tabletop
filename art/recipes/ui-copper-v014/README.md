## 接入

`CopperTabletopSkin` 缓存四张正式素材；面板、矩形按钮和卡牌框使用各自的九宫格，固定四角尺寸，仅拉伸边条中段。圆按钮等比显示独立贴图。卡牌选中态沿用同一美术框并提高金色亮度，不再叠画两层程序细线。

移除原 `Make` 中的圆盘、铜边和铆钉逐像素生成代码。胡桃木面板内衬仍使用v013贴图；细滚动条及功能图标沿用现有实现。骰盘原金色外沿改为深棕，使美术铜框成为主要外轮廓，模型几何未修改。文字、数量、玩家名保持独立实时绘制。

PC导入保留原图比例，不使用有损纹理压缩，不保留CPU像素副本。构建资源清单登记四张新图，供之后正常构建使用。
