# 海港与捕鱼组件 v001

2026-10-30。通过 Blender MCP 的 `execute_blender_code_for_cli` 制作，独立场景不覆盖输入文件。首个筹码和渔场先通过 Unity 尺寸、枢轴、URP、无碰撞体及 GameView 操作检查，再批量制作。

13 件资产：1／2／3 鱼、统一背面、旧靴、海港奖励牌、4／5／6／8／9／10 六渔场和湖泊。FBX 为米制底面中心枢轴，每件合为一个网格；图标由同源模型离线透明渲染。共 27,284 个三角面，包含倒角；实际桌面只实例化六渔场及公开湖泊，手牌、头像、奖励和鱼池使用图标。纹理均为256×256，加载后缓存。

这些尺寸属于开发估算：鱼筹码直径24毫米，渔场28×18.48毫米，湖泊与现有尖顶六边形对齐、主要表面8毫米高。没有宣称与用户实体组件等大。所有几何与材质由配方生成，不提取官方插图。组件规则依据已锁定的 TB25.pdf 第4、9—10页；渔场位置按各模式公开视图，不按模型碰撞判断规则。

复建时在 Blender MCP 后台接口指定一个现有 `.blend` 作为启动文件，在执行代码中设 `STAGE='sample'` 或 `STAGE='all'` 后执行本目录的 `build.py`；脚本顶部 ROOT 为仓库路径，迁移工作区时调整此路径。脚本新建场景，保存 `art/generated/harbor-fishing-v001/components-all.blend`，导出至 `Unity/Catan/Assets/Resources/HarborFishing/v001/`。源场景各件资产逐件渲染后隐藏，可在 Blender 中取消隐藏检查；原输入文件不保存。

[资产清单](资产清单.json)记录尺寸、最终网格面数和导出文件SHA-256。导入由 `FishingAssetImport` 统一使用 URP 材质、禁用碰撞体和动画，不修改其他美术资源。`FishingF6SampleVerification.VerifyAll` 检查全部组件的尺寸、网格、图标、材质与底面。
