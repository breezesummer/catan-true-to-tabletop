## 可复现生成

`Unity/Catan/Assets/Scripts/TabletopScene.cs` 在运行时生成木桌与海框：

1. 公开地图顶点计算凸包，向外扩展海框；海框只用于显示，不增添规则地块。
2. 通过固定数学函数生成 1024 × 1024 木纹和 256 × 256 海纹。无在线服务、随机素材下载或图片模型参与。
3. 生成桌面和海框实际网格及材质。尺寸沿用项目的估算米制坐标，原棋子轴心与正式地图标识不变。
4. 相机根据地图公开边界适配整桌视野，兼容斜视、俯视与窗口尺寸变化。蛮族行进板移动到上方桌边。

`TabletopUI.cs` 与 `OperationDock.cs` 绘制筹码、骰子、纸片、卡牌和备件；二维物件精确命中与棋盘稳定标识拾取配合，仍由共同规则入口决定能否执行。没有用照片或本轮概念图推导费用、权限或隐藏信息。

在已配置工具链的仓库运行 `tools/development/Build-M6.ps1` 重新构建，不需要重新导出历史美术。后台验证见 `tools/validation/Test-TabletopUi.ps1`。图形验证用独立渲染纹理，不读取用户屏幕。
