# 政治大都会 · 冠冕议政宫

南面宽阶通入铺石前庭。两座方塔分守入口，每侧四跨尖拱回廊连接后方主殿。殿门上方依次是鸢尾盾、月桂枝和王冠，最高处是带窗的四坡采光楼。双塔、宫翼和主殿各自落地，铺装止于前庭和廊道边缘。

外廊的柱础、鼓形柱身、拱腹、楔石和交叉拱肋均有实体厚度。双联窗的玻璃退入石框，门板、门带和铜环有各自的材质响应。屋顶沿坡铺瓦，实体瓦唇与贴图中的错缝对齐。宫门上的月桂带叶脉，盾沿与冠带从门楣石面起凸。第二组 UV 记录整栋建筑的局部天光可见度和石脚潮痕。

## 材质与复建

1. 参考为玩家提供的四视图，SHA-256 为 `f5d569f0bec6a0c2530354464e4af1616154a3a8f4b3104429cebb5bf545ad7c`。石灰岩、板岩、栎木和铜材复用项目已有的[材质母图](../../source/gothic-royal-city/王城材质母图.png)，SHA-256 为 `72a58a3453ddbd6894016ad6451141a936042d29f4f89b788c099ef6d2d8bed0`。
2. 在安装 NumPy 和 Pillow 的 Python 中执行 `finishes.py`，生成议政宫专属的十区图集。纹理随机种子为 191117，前庭板材排布种子为 112319。
3. 通过 Blender MCP 的 `execute_blender_code` 在独立后台会话执行 `build.py`，将 `__file__` 指向脚本绝对路径。此配方使用 Blender 5.2.2 LTS，复用哥特王城的石作、门窗与天光采样工具。脚本保存分件源场景，再以米制导出合并网格，更新扩展棋子的导入尺寸。
4. 在同一 MCP 会话执行 `verify.py` 回读正式 FBX，复核轴向、图集分区、穿廊视线以及带墙装配。执行 `render.py` 拍摄四视与门楼特写，再以 Pillow 运行 `plate.py` 拼成对照图。
5. 在 Unity 6000.3.25f1 选择「Catan／美术／导入冠冕议政宫」，或执行批处理入口 `ExpansionPiecesImport.ImportPolitics`。棋盘摆放与建造预览都读取既有的 `ExpansionPieces/v001/metro-politics-颜色` 预制件。

## 棋盘验收

在 Windows 内测版 2.1.17 读取四人「穿越沙漠」存档，同时开启双扩展、三国、海港与捕鱼。在同一城市路口临时投影政治大都会，检查普通摆放、带墙组合、建造预览和屋顶拾取，再恢复对局。实机高度为 25.22 毫米，四个席位各使用一个宫体网格和一个着色屋面。下列画面取自游戏的棋盘相机。
