# 橡木桌面与交互修复 v003

本轮橡木材质使用内置 `image_gen` 生成的色彩位图，不是用户实物照片或新三维模型。原始生成文件保留在 `art/source/ui-tabletop-v003/oak-table-albedo-v001.png`，Unity 使用同哈希的资源副本。桌面的实际网格仍由 `TabletopScene.cs` 生成，材质采用 URP Lit、零金属度与 0.38 平滑度。木纹均匀照明，运行时由游戏灯光照亮。

原图实际尺寸 **1254×1254**，SHA-256：`E6133B0A6B36618739A10E791E0D01F9A21D77B105716FD8B7144D661974124C`。图片模型不能逐像素复现；确定性导入以保留的原图和校验值为准。运行 `install_oak.ps1` 可从原图重建资源副本与稳定 GUID 的导入设置；2048 纹理上限、sRGB、MipMap、8 倍各向异性过滤、夹取边缘。贴图以中央 0.8 米估算范围为起点，按相机四角在桌面的投影扩大覆盖并留 5% 余量。以覆盖宽度 `span` 设置缩放 `8/span`、居中偏移 `(1-8/span)/2`；扩大后不随缩近收缩，避免木纹来回变化、重复接缝和可见范围的边缘拉伸。

生成工具：内置 `image_gen`，2026-10-12，非 CLI。完整提示词如下：

> 用途：photorealistic-natural，Unity 桌游的橡木桌面色彩贴图。
> 主体：非常有高级质感的天然欧洲橡木大桌子的桌面，精选整洁宽拼板，温暖沉稳的烟熏蜂蜜棕色，精致哑光清漆，真实细密木孔、少量自然猫眼年轮与橡木木射线，有高档实木家具的细腻质感。
> 构图：正交垂直俯拍，只包含平整木材表面，整幅由实木纹理填满，四条宽拼板，木纹横向自然延伸。2048×2048 方形高分辨率材质摄影，细节清晰，照片级真实。
> 照明：均匀柔和中性光，适合作为 albedo 材质，不烘焙强阴影和镜面光斑。
> 限制：没有桌沿、桌腿、房间、物品、棋盘、牌、人物、文字、标志、水印、边框；没有脏污、裂缝、夸张节点、重复波纹、卡通感和浓烈橘黄色。表面平整，横向拼板缝细且克制。

棋子沿用已有真实网格渲染的 32 张缩略图；仅开启其可读透明通道，用于单枚轮廓命中。重建旧缩略图的导入脚本已同步此设置。骰面、事件船与三色城堡符号由代码绘制，不含图片模型生成的规则文字；事件骰结果只读取当前 PlayerView。尺寸仍为估算。
