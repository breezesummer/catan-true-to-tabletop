# 原木商港

左侧木构吊楼下设尖拱装卸通道，右侧石仓的双扇门与铅条细窗面海。高楼的屋脊垂直岸线，低仓的屋脊沿岸展开，海侧屋坡上嵌着黄铜「2:1」和三根原木浮雕。桩承短栈桥从左侧伸出，吊臂下悬一捆短木，右侧货道上分别码放带皮原木与锯成的板材。

| 部位 | 制作与使用 |
| --- | --- |
| 贴岸与水线 | 模型宽 24.83、深 17.50、高 21.12 毫米。棋盘局部坐标以岸面为零，静水面低 3.50 毫米，桩底低 5.25 毫米。仓后墙抵达岸线，前方驳岸与建筑各自入水。海水与沙岸由棋盘提供 |
| 承重构造 | 石拱按洞口裁切砌块和楔石，转角交替砌丁石。石墙上架设木构楼层，瓦片错缝搭接。吊索由绞盘经臂端滑轮垂至吊钩，分腿吊索从捆木两端受力 |
| 材质 | 板岩保留劈理和缺角，石灰岩拱券有凿痕，潮线附近的石料与桩脚变暗。木构顺纹展开，原木切面与树皮分别取样。屋面切角漆牌嵌铜边，铸字与木雕有真实厚度 |
| 游戏资源 | 17 个母版分件合为 5 个可见网格，牌身和铸字共用矿石港材质，捆木浮雕与港仓共用木材港图集。最高精度 134,872 个三角面，Unity 导入时生成视距细节级别。独立拾取简模提供点击和渔网避让轮廓，玩家商船沿短栈桥外缘靠泊 |

灰模原型给出四个视角。制作时按棋盘边长定尺，采用蓝灰板岩、暖灰石灰岩、风化橡木和旧黄铜配色。[玩家原型](../../source/lumber-harbor/原木商港四视原型.png) · [模型四视图](../../previews/lumber-harbor/木材港四视图.jpg)

## 输入与复建

| 原件 | 来源 | SHA-256 |
| --- | --- | --- |
| 原木商港四视原型 | 玩家提供的灰模正视、右视、俯视和四分之三视图 | `3f34a62f17cf909ea5f7da64a4e616ee643cbf438fb5faa55caf15c403d0f15d` |
| 木料母图 | 本地木材港的橡木纵纹、松树皮、端面与劈木样本 | `0dd5aeda54e256f62c081507e82e4394150802f261cd47368182e59c1d12201a` |
| 王城材质母图 | 本地哥特王城的石材、板岩与金属样本 | `72a58a3453ddbd6894016ad6451141a936042d29f4f89b788c099ef6d2d8bed0` |

1. 用带 NumPy 与 Pillow 的 Python 执行 [surfaces.py](surfaces.py)。木材长纹沿 U 轴，法线使用切线空间，表面属性图的红通道保存金属度，透明通道保存光滑度。
2. 在独立的后台 Blender MCP 会话中，用 `execute_blender_code` 通过 `runpy.run_path` 执行 [build.py](build.py)。母版为米制，配方使用毫米、固定种子与 Georgia Regular 字形。模型按前向 −Z、上向 Y 导出三角网格、UV 和切线。[可编辑母版](../../source/lumber-harbor/原木商港.blend) · [正式模型](../../../Unity/Catan/Assets/Resources/PaintedMap/Coast/lumber-harbor.fbx) · [拾取与避让简模](../../../Unity/Catan/Assets/Resources/PaintedMap/Coast/lumber-selection.fbx)
3. 在同一 MCP 中执行 [inspect_port.py](inspect_port.py)，在 `init_globals` 中依次给 `view_name` 传入「海侧斜视」「正面」「侧面」「俯视」。摄影回读正式 FBX，材质使用母版内嵌图集。最后一帧拼成四视图。[模型回读数据](../../previews/lumber-harbor/模型回读.json)

## 棋盘验收

Windows 内测版 2.1.17 使用四人「双扩展＋三国＋海港＋捕鱼模式＋穿越沙漠」。用 `--ocean-view-verify <输出目录> --timber-port --board-art-views` 获取新开局的实机相机帧，在 `--timber-port` 后传入四人存档可复核邻岸聚落。用 `--pier-views <存档> --wood-berth` 核对同边商船的朝向、吃水与泊位。[实机近景](../../previews/lumber-harbor/木材港实机.png) · [邻岸聚落](../../previews/lumber-harbor/邻近聚落俯视.png) · [同边商船](../../previews/lumber-harbor/同边商船靠泊.png) · [实机验收数据](../../../docs/verification/lumber-harbor-2117/实机验收.json)
