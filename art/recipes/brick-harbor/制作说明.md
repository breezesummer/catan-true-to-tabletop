# 砖材商港

高仓的石拱通廊和低仓双扇门朝海，桁架悬臂将一托窑砖吊到露天货位上。屋坡深青色贸易牌以浅金铸字和六块嵌陶表示砖材 2:1。港岸就是承托仓楼和装卸区的挡浪墙。海水使用棋盘本身的水面，木桥下方保持通水。

| 项目 | 规格 |
| --- | --- |
| 外廓 | 宽 24.50、深 16.14、高 19.38 毫米。相对岸面，桩底为 −4.99 毫米，最高的脊瓦为 +14.39 毫米 |
| 位置 | 正式港口枢轴指向陆地时，岸线在局部纵坐标 +9.90 毫米。港岸后沿搭入 0.90 毫米，两侧回墙向内收斜，栈桥前沿位于 −5.34 毫米 |
| 母版与网格 | 19 个可编辑网格，导出为仓楼、屋坡交易牌、货垛、吊架、木桥、石岸六件。最高精度共 84,734 个三角面 |
| 材质 | 牌身和铸字共用矿石港材质，嵌陶与建筑共用砖港图集。固有色、切线法线、金属度与光滑度图集均为 2048 × 2048。金属度放在 R 通道，光滑度放在 A 通道 |

## 分件与材料

高仓和低仓的屋脊互相垂直。尖拱和弓形券切开各层砌石，门洞内保留侧墙、阴影和木箱。前窗、山墙侧窗、双门拉环、脊瓦套接和吊架滑轮均有实体厚度。板岩从檐口向上逐皮叠压，屋牌下方保留露在四边的瓦片。备货区有两盘不同高度的砖垛，第三盘悬挂在四角吊索上。

石工表面采用凿痕、矿物颗粒、灰缝和潮线以下的深色苔衣。旧橡木沿构件长度排纹，切口另取端面。窑砖的砂粒、烧失孔与缺角同时影响颜色和法线。铁件带有局部氧化，交易牌有黄铜边、浅金色铸字和独立的深青漆面。材质配色依据灰模补定，尺寸依据棋盘海岸和交点间距估算。

1. 在装有 NumPy、Pillow 的 Python 中运行 [kiln_atlas.py](kiln_atlas.py) 生成三张图集。纹理直接读取两张母图。
2. 在独立的 Blender 5.2.2 后台会话中，通过 Blender MCP 的 `execute_blender_code` 用 `runpy.run_path` 执行 [build.py](build.py)。屋坡铸字使用 Windows 的 Georgia Regular。导出按前方 −Z、上方 Y 写入显式 FBX，保留米制比例、UV 和切线。[分件母版](../../source/brick-harbor/砖港.blend) · [正式 FBX](../../../Unity/Catan/Assets/Resources/PaintedMap/Coast/brick-harbor.fbx) · [拾取 FBX](../../../Unity/Catan/Assets/Resources/PaintedMap/Coast/brick-selection.fbx)
3. 经同一 MCP 执行 [inspect_port.py](inspect_port.py)，依次传入 `view_name`「海侧斜视」「正面」「侧面」「俯视」。脚本从正式 FBX 回读网格与材质，核对木桩、岸线和拾取边界，然后输出[四视图](../../previews/brick-harbor/砖港四视图.jpg)。
