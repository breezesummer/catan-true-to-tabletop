后续迭代新增 `v002` 等版本目录，保留旧图；不要覆盖原件。外部参考仍保存在 `assets/references`。

## 来源与核对

- 使用内置 `image_gen` 生成；草地由文字生成，森林与麦田使用草地图作为系列风格参考。生成原始 PNG 已原样复制到仓库，未裁切、缩放或重绘；工具输出原件也保留。
- 完整提示词见[生成记录](v001/terrain/PROMPTS.md)，图片尺寸、文件大小及 SHA-256 见[文件清单](v001/terrain/manifest.json)。图片未包含规则文字或数字，不作为规则资料。
- 已逐图查看主体、六角边界、中央留白、风格及无文字水印情况。三张均为单视角概念图，尚未提供真实网格的顶视、侧视及拥挤节点预览。
- 当前中央留白偏宽、森林轮廓较规整，后续需结合数字牌实际大小调整密度与自然度；边角净空尚未通过几何测量。风动、羊群运动、相邻地块拼接、遮挡、拾取和双端性能均待真实模型接入后验证。
- 本次不改变 U0／U1 状态，不视为 U2 三维样板完成；不修改代码、版本号或游戏构建。
