- 砖土：未经开发时为赭红黏土丘陵；开发后局部出现取土面、传统砖窑、木模、砖坯与砖垛。
- 铁矿：用冷灰黑岩体、自然裂面与铁锈色矿脉表现；开发后增加小矿口、木绞盘、运矿车和矿筐。“铁矿”是本轮用户要求的矿石地形美术表现，不新增规则资源或更改规则 ID。
- 金矿：用暖灰褐岩体、白色石英与局部金色矿脉区别于铁矿；开发后局部增加采掘口、木质淘洗槽和碎矿处理。金色脉络属于游戏辨识用的美术强化，不作地质比例依据。
- 海岸图展示同类原始陆地与相邻海块：砖土为红褐低土岸与沙砾滩，铁矿为冷灰岩岸，金矿为暖岩岸与窄沙滩。
