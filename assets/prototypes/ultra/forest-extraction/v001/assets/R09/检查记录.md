# R09 苔石检查记录

日期：2026-10-22。

四张主图依次按原场景角度、正视、+X右侧视、+Y顶视生成，并逐张目检；派生图以本组原角度图固定圆钝灰岩、裂纹与黄绿苔藓的身份。源提示词位于 ../../prompts/R09/，实际提交词位于本目录。

| 项目 | 结果 |
| --- | --- |
| 原角度 | 单独完整岩石，不带树根、营地棚柱或土块；被遮挡部分采用合理补全。 |
| 正视 | 无场景，保留宽扁低矮轮廓和灰绿配色，底部近水平；局部顶面可见，严格零俯仰尚不能仅凭轮廓确认。 |
| 右侧视 | 使用右侧相机描述，岩面裂隙、苔斑与宽度发生变化；这些变化并非逐纹理固定后的可验证90度旋转。 |
| 顶视 | 无地平基线，显示较完整的上方苔面和近圆/椭圆占地；局部边缘块面仍有厚度感，凸面最高位置并非精确居中。 |

四张候选已落盘，可作造型、色彩与材质参考。跨视图岩缝与苔斑有漂移；提示词规定的共同像素尺度、宽深比例与1024分辨率未完全满足。没有宣布严格投影验收通过，尺寸与透明度抽样详见总目录 image-metadata.json。
