| 类别 | 发现的问题与处理 |

| 木桶 | P04、P05正／侧初稿露椭圆桶口，改用严格水平静物描述，压缩桶口，保留完整桶底及三道箍带。 |
| 手工锯 | P06侧视把锯片长轴竖向展开，改为沿长轴观察，只露重叠的木握柄；顶视使用横向金属窄边。 |
| 木工铁器 | P07、P08侧视收窄金属宽面，顶视压缩长柄；P08顶视仍有较大的金属面，未完全满足规定厚度。 |
| 原木 | P09原稿误带锯马已剥离；P09、P13、P14、P15正视去除主端年轮，侧视改为端面，顶视以横向树皮为主。不同视图的枝结与木纹仍漂移。 |

| 树桩 | ST01–ST05均针对顶视露前侧树皮追加修订；年轮面更圆、前壁减弱。部分下缘仍有厚度感，ST05侧视又与正视过近，不能宣称严格三视图全部通过。 |
| 草蕨 | G01多轮修订后仍有直立叶的立面感。最后一稿反而拉长上部叶簇，已拒用，恢复前一版较圆候选。 |
| 岩石 | 生成水平前／右立面和无地平基线的顶面，R06–R08顶视追加返工；裂缝和苔斑仍未逐点锁定，部分边缘块面显出厚度感。 |
| 土层与地面 | D01完整底座四图及GT01地面平面图均已保存。两者共边未像素级校准，不能直接当作无缝贴合的模型／贴图组合。 |
