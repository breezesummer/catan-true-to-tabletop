## 本轮调整

- 高山：矿石对应 Mountains，以高耸锐峰、相连山脊与深谷为主体，最高处少量残雪；开发设施放在局部山麓。文件沿用 `iron` 标识以对应前版，不新增规则资源。
- 丘陵：砖对应 Hills，以开阔、圆润、连绵的低丘为主体，草坡与赭红黏土露头结合，和高山的尖锐轮廓明确区分。
- 草原：采用新疆大草原般的鲜绿连续草毯、舒展草坡与小白羊群；原始态和海岸态均保留羊群，开发态增加局部围栏牧场。草地与沙滩不放石头。首稿去除过密杂草和小花，并定向修正偏黄光色。
- 麦田：浓密金黄麦海、饱满低垂麦穗与自然麦浪，突出秋天丰收。原始态即有成熟麦海，开发后才加入局部规整麦垄、麦束、农具及收割活动。
- 森林：更丰盈的树冠与林下植被，鲜绿、翡翠绿及深绿分层；定向减少黄褐滤镜，提升清新感。开发区保留局部伐木设施。

所有图继续采用微缩沙盘、六角低底座和斜俯视。玉牌单独制作，地形中央无点数留白。开发区以暗朱红棚布和小旗示范玩家归属，三分之一为构图目标。
